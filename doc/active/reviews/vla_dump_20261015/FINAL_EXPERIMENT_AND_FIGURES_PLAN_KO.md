# 최종 실험 시나리오 · 논문 figure 계획 (사용자 지시, 2026-10-18)

작성: 2026-10-18 KST, IFG 분석 세션. 진행 중인 선별 없는 재평가(`IFG-CL3`)는 그대로 끝까지 돌리고, 그 다음 작업부터 이 문서를 기준으로 한다.

## 사용자 지시 원문 요약

1. storage 폴더 이름만 보고 무슨 실험인지 알 수 있어야 한다.
2. pick 상황의 장애물 실험은 **target을 가리거나(가림 약 30%, 범위 5–60%) 기존 궤적을 방해하는 위치**일 때만 의미가 있다. 그렇지 않은 장애물 배치는 필요 없다.
3. **최종 실험 = 아래 사슬을 모두 통과하는 시나리오를 찾는 것.** 반드시 찾아야 한다.
   - ① VLA checkpoint 단독 성공
   - ② 장애물 없이 AG3S 적용 성공
   - ③ 허들 장애물 + AG3S 적용 성공
   - ④ 허들 + pick을 방해하는 장애물 + AG3S 적용 성공
4. **Fig. 1 teaser:** target을 부분적으로 가리는 장애물이 있다. 그래도 target을 정확하게 segmentation하고 올바르게 선정하는 장면이 필요하다. 이것을 시각화한다.
5. pick · place 장애물 때문에 **수정된 궤적**을 그래프와 실제 장면 양쪽으로 시각화한다.
6. **task phase를 나눈다**는 것을 시각화 또는 그래프로 보인다.
7. 성능만큼 **논문 figure 제작이 중요**하다. 최대한 아름답고, 독창적이며, 흥미를 끄는 방법론과 표현으로 진행한다.

## 반영 계획

### 1. 폴더 이름
- 지금 바로 한 것: `results/development/RUN_INDEX_IFG.md`에 IFG run 폴더별 실험 설명을 정리했다
  - 기존 폴더 이름은 로그 안 절대 경로 때문에 바꾸지 않는다
- 다음에 할 것: `common/run_output.py`에 **선택적 label**을 추가한다
  - 형식: `<KST>_<commit>_<uuid>_<label>`. label은 영문 소문자, 숫자, `-`만 쓴다. 예: `ifg-cl3-paired-40`
  - label을 주지 않으면 지금과 같다(하위 호환). 다른 세션도 쓰는 공용 모듈이라 implementer가 test와 함께 구현한다
- 그 뒤 모든 새 run에 label을 붙인다

### 2. 장애물 배치 기준 (pick)
- 장애물이 의미를 가지려면 다음 중 하나여야 한다
  - (a) head camera에서 target 가림 약 30%(허용 5–60%)
  - (b) 기존(장애물 없는) pick 궤적과 간섭한다. 궤적 경로 위나 그 근처에 놓인다
- 지금까지의 adjacent 배치(가림 ≤ 5%, 궤적 비간섭)는 이 기준으로 보면 **pick 장애물로서 의미가 약하다**. 진행 중인 CL3는 승인된 설계 그대로 끝내되, 다음 실험부터 이 기준을 쓴다
- 성공 여부로 장면을 거르지 않는다(CL3 원칙 유지). 배치는 기하 기준으로 고정한다
  - (a)는 렌더 가림률로 정한다
  - (b)는 장애물 없는 기준 궤적의 경로로 정하되, 기준 궤적의 성공 여부를 보지 않는다

### 3. 최종 실험: 4단계 사슬 시나리오 찾기
- 같은 장면(episode · seed)에서 ①→②→③→④ 순서로 조건을 하나씩 더해 간다
  - ① VLA 단독(`--no-safe`)
  - ② AG3S(장애물 없음)
  - ③ 허들(T43 P2 배치 규칙)
  - ④ 허들 + pick 방해 장애물(위 2번 기준)
- 찾는 방법: 후보 장면 풀을 미리 정한 규칙으로 고정한다. 각 단계 통과 여부를 기록하고, 네 단계를 모두 통과한 장면을 최종 시나리오로 삼는다
  - 이 "찾기"는 시연 · figure용 시나리오 선정이다. **성공률 평가(CL3 방식)와는 목적이 다르다**고 문서에 명시한다
  - 통과율(몇 개 중 몇 개)도 함께 보고한다
- 사슬의 각 단계를 같은 장면에서 비교하는 영상과 figure를 만든다

### 4. Fig. 1 teaser
- 장면: target을 부분적으로(약 30%) 가리는 장애물이 있는 pick 장면
- 보일 내용
  - VLA noun attention
  - attention + depth로 복원한 target 표면(정답과 겹침 표시)
  - 장애물과 이웃 물체가 target에서 정확히 빠지는 모습
  - 올바른 target 선정(기억과 신뢰도 경보)
- 형식: 실제 장면 위 overlay와 3D 표면 inset

### 5. 수정된 궤적 시각화 (pick · place)
- 그래프: 정책 원래 궤적 vs AG3S/TrajOpt가 수정한 궤적
  - 관절과 손끝 위치의 시간축
  - 장애물까지의 거리
  - 단계 구간을 음영으로 표시
- 실제 장면: 두 궤적의 손끝 경로를 3D 장면에 겹쳐 그린다. 장애물 주변을 확대한 inset을 둔다
- 기존 자산: `replay_avoidance_arrow.py`(회피 화살표 영상), `--viz-avoidance-arrow`

### 6. task phase 시각화
- 시간축 띠 그래프: HSR 단계(pick / place / home)와 잡기 상태(접근 / 쥠 / 놓음)
  - 같은 축에 3D 관계(손–target 거리, target 높이)와 장면 썸네일을 둔다
- 기존 자산: `ifg/exp/exp-R12-phase-3d.png`, T59 phase timeline 그림(`figures/ppt-1013/`)

### 7. figure 품질 원칙
- 논문용 figure는 실제 장면을 중심에 둔다. 보조로 그래프와 도식을 쓴다
- 색은 `figstyle` 하나만 쓴다. 각 figure에 sidecar `.json`을 둔다
- 약어는 그림 안에서 풀어 쓴다(사용자 지시: C1a / SURF 같은 코드를 설명 없이 쓰지 않는다)
