# AG3S 연구 범위 — 한 페이지 결정문

작성: 2026-10-23 15:04 KST · 상태: **연구 범위·평가 후보 고정 / 성능 미검증 / 실행 manifest 작성 전**.
근거: 사용자와 본 세션에서 합의한 목표 및 [문서 검토](../reviews/AG3S_SCOPE_DECISION_20261023_KO.md).
아래 수치 기준은 이번에 정한 **연구 의사결정 기준**이며 기존 측정 결과나 분야 표준이 아니다.

**목표와 가설.** Frozen VLA의 내부 task signal을 관측된 3D target 표면과 연결하고, 이를 링크별 접촉 제약으로 변환하면, pick-and-place의 작업 수행 능력을 유지하면서 불필요한 접촉을 줄일 수 있는가? 핵심 기여는 **의미 단서 → 표면 경계 → 접촉 허용 범위 → 실제 실행**의 연결이다. 모든 파지 실패의 해결, 모든 모듈의 독립적인 우수성은 목표가 아니다.

**이번에 평가할 방법.** 기존 noun attention + depth-continuous surface graph + 링크별 target 제외 + attached-object 검사 + 기존 chunk refinement를 핵심 후보로 선택한다. VLA와 기존 phase/grasp 처리·optimizer는 공통 기반으로 고정한다. 표면 graph에 feature를 억지로 더하지 않는다. Feature identity 전환·confidence 경보·추가 grasp rule은 본 평가에서 끈다. 기존 학습된 phase probe는 남으므로 시스템 전체가 학습 없는 방법이라고 주장하지 않는다.

**적용 범위.** 첫 결정은 RB-Y1 MuJoCo, 현재 16-D checkpoint, 사과 target의 pick→carry→place 및 place 뒤 2.5초에 한정한다. 주변 과일·접근 방해·운반 장애물·목적지 주변 장애물을 포함한다. 검사 모델은 양손과 손목(`gripper_wrist`)으로 두 보정 구성에 동일하게 적용한다. 전신 보호·실시간성·다른 물체/로봇/실물 일반화는 미입증이다. 공개 benchmark와 실물 시연은 후속 외적 검증이며 이 단계의 완료와 논문 전체의 완료를 구별한다.

**본 평가의 세 구성.** ① VLA 단독 ② 같은 noun attention·robot mask·상태 처리·제어기를 쓰는 기존 `ball-owned` 제외 ③ ②의 미세 target 제외를 관측 표면 방식으로 바꾼 핵심 후보. 최근 9/10 구성은 진단 reference로 보존한다. 손목 가중치 0.1·이웃 접촉 20 mm 허용·복구·파지점 고정은 세 구성의 비교에 가져오지 않는다. 고정 구형 추종은 별도 진단으로 남긴다. 후보 ③은 이 조합으로 검증된 적이 없으며 9/10 또는 7/10을 성능으로 인용하지 않는다.

**무엇을 증명할 것인가.** 같은 관측·identity에서 표면 경계가 잘못된 obstacle 삭제와 target 잔류를 어떻게 바꾸는지 측정한다. 내부 신호의 역할은 같은 RGB-D에서 instruction/attention 대응을 바꾼 진단으로 확인한다. 링크별 허용의 역할은 같은 공간 질의에서 허용 손가락과 비허용 손목을 비교한다. 이 진단들은 최종 closed-loop 성공률의 대체물이 아니다.

**성능 목표.** 모든 시험 실행을 분모로 task success, 금지 접촉 발생률, 금지 접촉 없는 성공을 함께 평가한다. 이웃 과일 접촉도 금지 접촉에 포함한다. 핵심 후보 대 VLA의 목표는 task success 손실 **5 percentage points 이내**, 금지 접촉 발생률 **5 percentage points 이상 감소**, 접촉 없는 성공 **5 percentage points 이상 증가**다. 점추정뿐 아니라 사전 고정한 scene 단위 불확실성 기준도 통과해야 “작업 유지와 접촉 감소”를 주장한다. 후보 대 공 모양 제외도 같은 기준으로 별도 판정하며, 미통과를 우수성으로 포장하지 않는다.

**모듈 완료 기준.** 입력·출력과 관측/권한 계약이 일치하고, 오류가 발생하는 조건을 측정했으며, 고정된 평가를 마치면 본 단계는 완료다. 211·954·1668의 전부 성공이나 10/10은 종료 조건이 아니다. AG3S가 파지를 깨는 현상은 결과에 포함하되 파지 복구를 새로 개발하지 않는다.

**개발 상한.** 평가 준비와 원인 층의 일관성 수정은 최대 2 working days·1회 수정 묶음으로 제한한다. 이후 개발 pilot 1회, 확정 test 1회만 한다. 새로운 feature·threshold 탐색·장면별 예외 추가는 중단한다. 예산과 표본·판정 절차는 [실행 설계](../../../AG3S/ag3s/docs/handoff/AG3S-CORE-EVALUATION.task.md)에 고정한다. 실행 가능한 manifest가 완성되기 전 GPU를 시작하지 않는다.

**종료와 다음 질문.** 근거 충족 → 방법 고정·독립 확장 평가·집필. 기하만 개선 → “실행상 접촉 감소”를 주장하지 않고 기하 기여 범위로 마무리. 정확한 관측 기하에서도 보정이 필요한 파지를 훼손한다는 진단 근거 확보 → 기존 버전을 종료하고 “접촉 조건을 보존하는 행동 수정”을 별도 연구로 시작. 불확실성/예산 부족 → 판정 보류로 완료하고 같은 test에 seed·규칙을 계속 추가하지 않는다.

**현재 바로 할 일.** [실행 설계 §8](../../../AG3S/ag3s/docs/handoff/AG3S-CORE-EVALUATION.task.md#8-바로-다음-작업과-산출물)의 CPU 평가 준비부터 진행한다. 기존 수치의 분모와 접촉 정의를 정리하고, 같은 mask·검사 링크의 세 구성 manifest와 evaluator를 고정한다. 또 하나의 211 전용 수정을 시작하지 않는다.
