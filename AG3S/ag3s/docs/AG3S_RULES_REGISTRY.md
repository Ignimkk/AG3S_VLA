## 0. 문서 목적 · 갱신 규칙

**목적 (사용자 지시 2026-11-01):** "각 모듈에서 무언가 규칙을 만들면 그것은 대강 기록해야 합니다. 새로운 환경에서 작업 수행할 때 그 규칙이 실패로 이끌 수도 있기 때문입니다."

- 이 문서는 AG3S 각 모듈이 쓰는 **사람이 정한 규칙** (threshold · 발동 조건 · 반지름 · 창 · 예산 · 휴리스틱 판정) 을 한 곳에 모은다. 새 환경 (다른 장면 · 다른 prompt · 다른 VLA checkpoint · 다른 로봇 · 실물) 에서 일이 틀어지면 가장 먼저 열어 보는 목록이다.
- **갱신 규칙:** 새 flag · 새 threshold · 새 휴리스틱을 넣는 STEP 은 해당 모듈 표에 **한 줄을 추가**한다. 규칙을 채택 · 폐기하면 "구성" 열을 고친다. 새 환경에서 실제로 실패하면 "새 환경에서 실패할 수 있는 경우" 열에 "관측됨 (STEP)" 을 쓰고 맨 아래 "관측된 규칙 실패" 표에도 한 줄 더한다.
- **완전한 목록이 아니다.** 주요 규칙을 정확히 적은 것이다. 빠진 규칙은 아래 "표에 없는 것" 에 범위를 적었다.

## 10. 용어

| 용어 | 뜻 |
|---|---|
| chunk | VLA 가 한 번에 내는 action 묶음 (50 행). 앞 8 행만 실행하고 다음 chunk 를 받는다 |
| HOLD | 서버 verdict 가 collision · uncertified 등이면 client 가 로봇을 그 자리에 세워 두는 것 |
| TrajOpt | chunk 를 SQP (순차 이차 계획) 로 고치는 최적화. 충돌 clearance 를 선형화한 행으로 건다 |
| E0 | chunk 마다 표준 SQP 풀이 하나만 (여러 초기값 · GPU 초기값 batch 없음) |
| ball / ball-owned | target 점구름을 담는 가장 작은 공 안을 거리장에서 지우는 방식 / 공 안에서도 이웃 물체 쪽 voxel 은 남기는 방식 |
| attention-surface | prompt 명사 attention 의 seed 에서 depth 연속 표면 (graph) 으로 target 표면 영역을 만들어 지우는 방식 (T78) |
| manipulated object | 지금 조작 대상으로 잠긴 물체 (ATS 의 target) |
| authorized link | target 이 빠진 거리장을 보도록 허락된 링크 (쥐는 손의 손바닥 · 손가락) |
| vacancy (비어 있음) | 마지막으로 보인 target 점들의 옛 위치가 이번 depth 에서 광선이 지나 뒤에 닿는 상태 (T81) |
| latch | 쥠 상태 기계 (searching → latched → closing → held → placed) |
| A4 / G1 / A6 | 쥐기 목표 항 / 기하 grasp 보정 / 쥐는 순간 이웃 접촉 허용 (각각 ADOPTED_KO 의 항목 번호) |
| 손 층 | 손 swept 창 안에서 5 mm 로 만드는 미세 target-free 계층. 손이 읽는 거리장이다 (LTE-01) |
| 지지면 guard (`z_floor`) | 손 층에서 이 높이 아래 seed 는 지우지 않는 규칙. 지지면 + 미세 voxel 1 개 (LTE-16) |
| 오목 꺾임 끊기 (crease cut) | 표면 graph 에서 두 노드의 표면이 오목하게 (n_i − n_j)·(x_i − x_j) < 0, 각 20° 이상 꺾이는 edge 를 끊는 규칙 (LTE-17) |
| 작은 조각 붙이기 | 오목 끊기로 떨어져 나간 성분 중 선택 영역의 0.25 배 이하를 다시 붙이는 규칙 (LTE-17). 폐기된 hull 기준 '조각 붙이기' (LTE-15) 와 다르다 |
| target 유지 기억 (sticky) | 표본 기억의 칸이 한 번 target 이면 깎이기 전까지 target 인 규칙 (LTE-18) |
| hull 채우기 | 쥐기 직전에 마지막 채택 영역의 convex hull (+ pad 1 미세 voxel) 안 seed 를 모두 지우는 규칙 (LTE-13) |
| 접촉 영역 · 쥐기 직전 · 떨어진 / 맞닿은 장면 | LTE-18 뒤 '평가 정의' 절 |
| T-번호 | `AG3S/ag3s/docs/handoff/T*.task.md` 의 STEP. 옛 STEP 은 `AG3S_T0T6_LOG.md` |
