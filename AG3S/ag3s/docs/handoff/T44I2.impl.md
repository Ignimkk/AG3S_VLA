# T44 I2 — 구현: target permission 일관성 (`--target-permission-strict`)

## 무엇을 했나 (평이한 요약 먼저)

waypoint margin 밖의 target 예외 세 곳 — look-ahead tail drop, `obstacle_margin` 면제 class, sweep path 행 제외 —
에 link 필터가 없었다. 새 flag `collision.target_permission_strict` (기본 off) 를 켜면 그 세 곳의 target 판정이
**target 에 닿아도 되는 link 의 행** (`SceneSnapshot.target_contact_rows`) 에만 적용된다. 같은 자리의 forearm 은
이제 검사를 받고, finger 는 예외를 유지한다. 같은 flag 에서 AG3S 가 `ball_owned` 로 지웠다고 stats 가 말하면
target membership 을 ball 대신 `d_free − d_main > voxel` 로 본다 (ball 안에 남긴 이웃 과일을 target 으로 보지 않음).
P3 (`obstacle_margin > 0` 이 `target_volume` 을 지우던 것) 는 flag 와 무관하게 고쳤다 — V11AB 설정에서는 snapshot 이 같다.

## 남은 결함 · 판정이 필요한 것

1. **waypoint E1 margin 은 바꾸지 않았다** (task 범위대로). 비권한 행은 이미 `manipulated_link_margin` 의 full margin 을
   받으므로 waypoint 에서는 문제가 없다고 보았다. strict 에서 비권한 행이 `obstacle` class 가 되면 `max(full, obstacle_margin)`
   이라 값은 그대로다.
2. **권한 행 (exclude_authorized) 의 E1 우연 일치**: look-ahead tail 의 E1 test 는 target-free 계층을 읽는 권한 행에도
   돈다 (`|d_free − d_object| ≤ coarse` 가 우연히 참이면 drop). 기존 동작이고 strict 에서도 권한 행에는 그대로 둔다.
3. **`relax` 에서 권한 = `manipulated_link_margin < max`**: 모든 구가 권한 link 이거나 TRANSIT (scale 1.0) 이면 아무 행도
   권한이 없다 → strict 에서 target 예외 0. TRANSIT 에서는 원래 margin 완화도 없으므로 일관된다고 보았으나, 판정 필요.
4. `layer_diff` 는 task 문구대로 ball 판정을 **대체**한다 (ball ∧ membership 이 아님). 이론상 membership ⊂ 제거 seed ⊂ ball 이라
   차이는 계층 간 수치 차이뿐이다. 더 보수적으로 ball 과 교집합을 원하면 한 줄 변경.
5. `layer_diff` 는 query 점에서 두 계층 거리를 한 번 더 읽는다 (strict + ball_owned + target_volume 일 때만). 시간 측정 안 함.
