## 무엇을 했나 (평이한 요약 먼저)

명사 query 행을 T51 의 같은 절차에 넣을 수 있도록 **새 파일 두 개** 를 만들었다. 기존 파일은 고치지 않았다.

1. `t51b_noun_extract.py` 는 T49 의 명사 추출기를 **수정 없이** 써서 추가 calibration run (`ep0` · `ep500` · `ep1200`) 의 명사 행을 뽑는다. 출력은 T51 run 의 `verify/T51b/noun_extract/orig/<ep>.npz` 이고, 형식은 T49 `orig` 추출과 같다. GPU 단계는 verifier 가 돌린다.
2. `t51b_study.py` 는 T51 의 stage 함수 (`t51_study.stage_*`) 를 **그대로 호출** 한다. 그 전에 `t51_study` 의 이름 7 개를 이 process 안에서만 다시 묶는다. 그래서 다음이 가능해진다.
   - T47 record 의 명사 행은 T49 run 에서, 추가 run 의 명사 행은 T51b 출력에서 읽는다.
   - Ω 를 명사만 (a) 또는 action + 명사 (b) 로 바꾼다.
   - 출력을 `verify/T51b/` 아래에 쓴다.
   - 3D row 는 T51b cache 를 먼저 보고, 없으면 T51 의 것을 읽기만 한다.

   (c) held-out 비교 stage 와 (a)–(c) 를 query 별로 묶는 `summary` stage 도 더했다.

T51 verifier 가 `t51_*` 를 실행 중이므로 `t51_*.py` 는 **byte 하나도 바꾸지 않았다** (mtime 08:09–08:44 그대로). GPU 와 checkpoint load 는 하지 않았다.
CPU smoke 는 1 process 로만 돌렸고, 출력은 scratchpad 에 썼다.

## 설계에서 정한 것 (lead 확인 필요 표시 ★)

- **Ω.** (a) `noun` = `noun_target` × L2–17 × 8 = 128 cell. (b) `combined` = action 3 agg + 명사 = 512 cell (Ω 순서는 query-major 이고 명사가 마지막이다 → 동점 tie-break 에서 action 이 앞선다. T51 의 `pr.omega` 규칙 그대로).
- **명사 행 = T49 `target` query** (prefix 1 회, denoise 없음, raw σ=0). T51 의 `NOUN_QUERY` 와 같은 정의다 (`t51_study.py:146-147`). `basket` · `last_text` 행은 Ω 에 넣지 않았다.
- ★ **forced cell.** T51 의 2D → 3D 선별에서 forced (L8H2 + T47 oracle top-3) 는 action cell 이다. 그래서 (a) 에서는 forced 가 **없다**. (b) 에서는 T51 과 같다. T49 의 명사 선택 cell 을 forced 로 넣지는 않았다 (사전 고정 규칙에 없다).
- **명사 행 검사.** 실패 frame (`ok=False`) 이 하나라도 있으면 그 record 를 거절한다 (zero map 으로 조용히 돌리지 않는다). T49 의 7 개 `orig` 는 오류 0 이다. 추가 run 은 tokens smoke 에서 339 frame 모두 명사가 정확히 1 회였다 (아래).
- **row 재사용.** action cell 의 3D row 는 (record, source, replay option) 이 T51 과 같으므로 다시 돌리지 않는다. 어떤 학습 집합에서든 (b) 의 top-16 에 든 action cell 은 action-only top-16 에도 든다 (명사 cell 을 빼면 순위가 올라갈 뿐이다; P1 판정은 query 별로 독립이다). 그래서 (b) 의 action 후보는 T51 후보의 부분집합이다. 같은 논리로 (b) 의 명사 후보는 (a) 후보의 부분집합이다 (공유 cache). 새로 replay 하는 것은 (a) 의 명사 후보와 ksel 의 혼합 합 (`sum[...]`) 뿐이다.
  `summary.json` 의 `score3d_row_origin` 과 `heldout_compare.json` 의 `row_origin` 에 출처 (`t51b` / `t51`) 를 적는다.
- **self label** 은 Ω 와 무관하므로 T51 `selflabel/` 을 읽기만 한다.
- **(c) 정의.** `action_best_<label>` = T51 `<label>/ksel/ksel.json` 의 `selected`, `noun_best_<label>` = (a), `combined_best_<label>` = (b) 다. `l8h2` 를 함께 둔다.
  - 모두 held-out 4 record 에서 **GT 3D `identity_correct`** 로 잰다 (T51 P5 와 같다).
  - record 별 값, scene 묶음 (same/new) 평균, `t47b_metrics.summarize` 를 낸다.
  - 쌍 비교 (noun − action, combined − action, noun − L8H2, action − L8H2, combined − noun, self 의 noun − action) 는 frame 짝 (`both` · `only_a` · `only_b` · `neither`), 차이, exact McNemar p 를 낸다. **frame 단위 p 는 exploratory 다** (같은 record 의 frame 은 독립이 아니다). protocol 수치는 record 단위다.
