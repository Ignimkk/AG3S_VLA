## 4. GPU 여러 초기값 경로 — 선택지 (b)

- cuRobo seed 문제 (`gpu_seeds.CuroboSeedBatch`) 는 바꾸지 않았다.

  - 후보마다 full-resolution 검사 뒤의 궤적에서 도달 행 hold-link 의 축별 상자 초과를 잰다 (`_reach_excess`).

- 기록 (`to.metrics.multi_seed`):
  - `reach_selection` (문구)
  - 후보마다 `reach_excess_mm` · `selection_violation_mm`
  - `gpu_goal_note` = "T72 reach box: not in the cuRobo seed cost …"
- 발동 조건 (표준 해에 충돌 위반이 남을 때) 은 그대로다. 도달 초과만으로는 여러 초기값을 돌리지 않는다.
