## 0. 왜 (T79 · 회귀 211 기록, `outputs/2026-10-31_T79_ATS시간추적_hidden재탐색/`)

- 손가락이 사과를 약 10 cm 밀었는데 (요청 12–14), target 이 끝까지 옛 자리 (사과에서 약 105 mm) 에 남았다. 관측 (밀린 사과 점 38–117 개, 로봇 자기 제거 뒤에도 남음) 과 noun attention (35 요청 중 20 번 밀린 사과) 은 새 위치를 보고 있었다.
- 교체를 막은 규칙: 요청 15–19 = "손이 target 을 가린다" (밀린 사과가 손에서 12–13 mm → 가려진 원래 target 으로 해석, 교체 횟수 안 셈) · 옛 기하 따라가기 실패 (옛 자리 근처 점 2 개). 요청 20– = **쥐는 중 고정 (latch closing → frozen)**, 빈손으로 닫아 latch 가 closing 에서 못 벗어나 끝까지 고정. 24– 일부 = 작업 단계 gate (place · home).

## 1. 규칙 (flag `--target-vacancy-release`, 기본 꺼짐)

1. **적용 조건:** 쥐는 물체가 물리적으로 붙지 않은 동안 (latch 가 HELD 가 아니고 attach 없음 — searching · latched · closing 포함).
2. **옛 위치:** 마지막으로 "보임 (visible)" 으로 확정된 target 점들 (base frame, 최대 N 개 표본).
3. **비어 있음 판정 (요청마다, 카메라마다):** 옛 점을 head · 쥐는 손 손목 카메라에 투영. 이미지 안 · depth 유효 · 로봇 pixel 이 아닌 점만 센다. 점마다:
   - **비어 있음:** 관측 depth > 점 depth + δ (광선이 옛 위치를 지나 뒤에 닿음)
   - **가려짐:** 관측 depth < 점 depth − δ, 또는 로봇 pixel
   - **있음:** |차| ≤ δ
   - 카메라 중 판정 가능한 점이 가장 많은 것을 쓴다. 판정 가능한 점이 M 개 미만이면 "판단 불가".
4. **결정:** 비어 있음 비율 ≥ p_empty ∧ 있음 비율 ≤ p_present 가 **연속 2 요청** → target 놓음 (release). 가려짐 · 판단 불가 · 있음이면 유지 (기존 규칙 그대로).
5. **놓은 뒤:** 정체 · 고정 (frozen) · 손 가림 · 유지 기하를 이 target 에 대해 풀고, 이번 요청의 target 선택 (noun attention + grounding) 으로 다시 고른다. 옛 위치에서 가까운 후보 (200 mm 안) 를 먼저 본다. 후보가 없으면 target 없음 (지우지 않음).
6. **우선순위:** 이 규칙이 "손이 target 을 가린다" 규칙 · 쥐는 중 고정 · 잠근 정체 유지보다 먼저. 작업 단계 gate (place · home 이면 새 대상 금지) 는 이 규칙이 놓은 경우에 한해 건너뛴다 (아직 쥐지 않았으므로).
7. **작은 이동:** 옛 위치에 점이 아직 "있음" 이면 놓지 않는다 → 기존 옛 기하 따라가기가 맡는다.

- 문턱 δ · p_empty · p_present · M · N 은 **결과 전에** lead 가 정한다: 구현이 만든 측정 도구로 회귀 211 (T71 R0) · T80 실험 C 2 run · 성공 run 2 개 (T71 R0 회귀 119 k1, 가림 121) 의 요청별 (비어 있음 / 가려짐 / 있음 비율) 을 재고, 성공 run 에서 놓는 요청이 0 이고 211 · T80 C 의 이동 뒤 요청에서 놓는 값으로 고른다. 정한 값은 이 문서 §4 에 적고 나서 closed-loop.

## 4. 문턱 (lead 2026-11-01, 측정 뒤 · closed-loop 전, 결과 전 고정)

- **δ 20 mm, 비어 있음 비율 ≥ 0.45, 있음 비율 ≤ 0.30, 판정 가능한 점 ≥ 20, 옛 위치 표본 ≤ 200, 연속 2 요청.**
- 근거 (`verify/T81/measure/`, δ 20 mm): 이동 · 밀림 뒤 비어 있음 0.58–0.96 · 있음 ≤ 0.16 (회귀 211 · T80 C 앞 · 뒤), 사과가 제자리에 있는 요청의 비어 있음 최대 0.26 (성공 회귀 119 · 가림 121 포함). 이 값으로 모의하면 첫 놓기 = 사과가 떠난 두 번째 요청 (211 seq 17, C seq 16), 성공 run 놓기 0, 사과가 있는데 놓음 0.
- 구현 확인 사항 (lead 판정): 로봇 pixel 은 가려짐으로 셈 · PLACED 뒤에는 적용 안 함 · **놓은 뒤 옛 중심 200 mm 안 후보만, 없으면 target 없음** (구현의 "가장 높은 후보" 대체는 되돌림).
- offline 재생 (회귀 211, T76 고정 입력 재생 도구): 꺼짐 = seq 16–75 옛 자리 (사과에서 90–119 mm), 켜짐 = seq 17 에 놓고 같은 요청에 밀린 사과를 다시 고름, 이후 target 이 사과 중심 28.5–29.8 mm (`verify/T81/replay/compare.md`).
