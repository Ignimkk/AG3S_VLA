## 무엇을 했나 (평이한 요약 먼저)
`serve_safe --subtask-from-latch` (기본 꺼짐) 를 넣었다. 켜면 3 단계 gate (pick · place · home) 의 label 을 kv_L4_v1 probe 가 아니라 **이번 요청의 grasp latch phase** 에서 만든다: SEARCHING · LATCHED · CLOSING → pick, HELD → place, PLACED → home (phase 를 모르면 label 없음). `_scene_fn` 이 latch 를 먼저 진행한 뒤 `set_subtask(self._subtask_gate_input())` 를 부르므로 같은 요청의 phase 가 쓰인다. AG3S 의 debounce 는 그대로다. 꺼짐이면 `_subtask_gate_input` 은 한 줄 (`if self.subtask_from_latch`) 만 더 거치고 이전과 같은 값을 낸다 · 기록 키도 없다.
