# T72 — 충돌 고려 기하 grasp 후보 집합 + grasp 도달 제약 TrajOpt (목적함수 = VLA 추종 · 부드러움 + grasp quality + VLA 쥐기 의도 차이) (결과 전 고정)

> writer: lead (세션 cc) · 작성: 2026-10-30 00:40 KST · 상태: **사전 고정.** 구현: ag3s-implementer. closed-loop: lead (cc).
> 사용자 판정 (2026-10-30 ~00:20 KST):
> 1. 충돌 조건은 필요하다. grasp 후보는 충돌이 고려된 것이어야 한다.
> 2. 목적함수는 **최종 구성에서 쓰는 항 중 VLA 추종 + 부드러움만** 남기고, 여기에 **grasp quality 항 · VLA 쥐기 의도와의 차이 항**을 더한다. grasp pose 도달은 제약으로 넣는다.
> 3. GPU closed-loop 로 하되 아주 조금만: 평소 쥐기 문제로 실패한 2–3 장면 × 4 회.
> 참고 (사용자 제시): GPD (atenpas/gpd) — 점군에서 6D grasp 후보를 만들고 quality 로 고르는 방식.

## 0. 왜 지금 이것인가

- 최종 구성 (ADOPTED_KO.md A8 확정 6) 의 쥐기 목표 항 (A4) · 기하 보정 (G1) 은 HSR 규칙 ④ 때문에 32 run 동안 0 회 작동했다 (T68). 그래서 "기하 grasp 가 쥐기를 돕는가" 는 최종 구성에서 아직 재지 않았다.
- 기존 G1 은 (가) grasp 하나를 최적화 밖에서 VLA 근접 순으로 고르고 (나) 추종 비용을 0.25 배로 낮추는 보상 장치를 썼다. G2 (기하 grasp 를 접근 목표로) 는 VLA 를 대체해 손을 엉뚱한 곳으로 끌어 실패했다.
- T72 는 이를 **goal-set 형태** 로 다시 쓴다 (Dragan et al. 2011 goal-set trajectory optimization 의 이산 후보판): 후보 집합 G 위에서, 고른 후보의 quality 와 VLA 의도와의 차이가 목적함수의 일부이고, 도달은 제약이다. VLA 의도 차이 항이 G2 의 실패 (VLA 대체) 를 막는다.

```
카메라 depth → 로봇 마스크 → ATS target 점군 ─→ [충돌 고려 grasp 후보 집합 G (quality Q_i)]
                         → TSDF/ESDF ───────────────────┘            ↓ 선택 i* (목적함수 J 최소)
VLA chunk (닫기 행 c, 의도 자세 T_v) ─→ TrajOpt: 추종 + 부드러움 + grasp 도달 제약 (+ 충돌 제약 그대로)
```

## 2. 구현에 요청하는 것 (→ implementer)

### 2a. 후보 집합 G (충돌 고려)

- 생성기: 기존 `AG3S/ag3s/grasp/candidates.py::generate_candidates` (μ = 0.8, 관측 점만 접촉, 생성 상한 150 ms, 최대 8 개, IK 필수). 입력은 G1 과 같다 (ATS target 점군, 자기 필터된 장면 점군에서 target 을 뺀 것).
- **충돌 검사 (둘 다 통과해야 후보):**
  1. 기존 점 검사: 손바닥 · 손가락 상자 (열린 폭 + `scene_margin`) 안의 장애물 · 지지면 점, sphere 로 채운 target, pre-grasp → grasp 접근 선분.
  2. **TrajOpt 와 같은 충돌 모델 검사 (새로)**: 후보 IK 자세 (grasp 와 pre-grasp) 에서 TrajOpt 의 손 · 손가락 구 (손바닥 껍질 구 포함) 를 **TrajOpt 가 그 요청에 쓰는 거리장 · 여유 · target 제외 규칙 그대로** 조회해 d − r − margin ≥ 0. → TrajOpt 가 충돌로 볼 grasp 는 목표가 되지 않는다 (도달 제약과 충돌 제약이 서로 싸우지 않게).
- 후보마다 어느 검사에서 떨어졌는지 기록.

### 2b. grasp quality Q_i ∈ [0, 1] (고정)

`Q_i = (q_fric + q_centre + q_support) / 3`

| 성분 | 식 | 뜻 |
|---|---|---|
| q_fric | clip((alignment − cos θ_μ) / (1 − cos θ_μ), 0, 1), θ_μ = atan(0.8) | 두 접촉 법선이 마찰 원뿔 안에 얼마나 깊이 있나 |
| q_centre | 1 − min(ρ, 1), ρ = `geo_grasp.chord_offset` (sphere fit 없으면 0.5) | 닫는 축이 물체 중심을 지나나 |
| q_support | min(min(support₁, support₂) / (2 · `min_support`), 1) | 패드 크기 관측 표면이 받쳐 주나 |

### 2c. 목적함수와 선택 (goal-set, 블록 좌표 풀이)

- VLA 의도 자세 T_v = (p_v, R_v): VLA chunk 가 닫기를 계획한 첫 행 c 의 손 hold-link 자세 (FK). closing 단계에서는 닫기 시작 때 값을 얼린다.
- 후보별 목적함수 값 (상수 부분 + 추종 비용 추정):

  `J_i = Δq_iᵀ W Δq_i / σ_q² + λ_I [ (‖p_i − p_v‖ / σ_p)² + (θ(R_i, R_v) / σ_θ)² ] + λ_Q (1 − Q_i)`

  - Δq_i = q_IK,i − q_VLA(c) (최적화 관절 14 개), W = 추종 가중 (손목 0.1 배 포함). 추종 항의 그 후보에서의 크기 추정이다.
  - 두 번째 항 = **VLA 쥐기 의도와의 차이**, 세 번째 항 = **grasp quality**.
  - 고정값: σ_q = 0.1 rad, σ_p = 20 mm (E3 닫기 순간 측정된 사과–패드 중심 어긋남 20–22 mm), σ_θ = 15°, λ_I = 1, λ_Q = 1. 회전 차이는 손가락 180° 바꿈을 같은 grasp 로 본다.
  - 자격: ‖p_i − p_v‖ ≤ 60 mm 이고 θ ≤ 30°. 자격 후보가 없으면 그 요청은 기능이 없는 것과 같다 (bit 동일).
- 선택 i* = argmin J_i. **흔들림 방지:** 이전 요청의 i* 가 아직 유효하면 새 후보의 J 가 0.8 배 미만일 때만 바꾼다 (같은 grasp 판정은 위치 6 mm · 축 15° 안).
- **TrajOpt (i* 고정 후 한 번 풀이):**
  - 도달 제약: 행 c … c+2 (닫기 행부터 3 행) 의 hold-link 위치가 g_{i*} 의 축별 ±5 mm 상자 안 (기존 `GraspAnchor.goal_box` 경로, slack 은 다른 제약과 같은 `w_slack`).
  - 회전: `w_rot · ‖Log(R_gᵀ R)‖²`, w_rot = 5 (G1 값), 손가락 바꿈 쌍 중 지금 손에 가까운 쪽.
  - closing 단계 (손바닥이 grasp 의 20 mm 안): 행 1 … 3 에 같은 도달 제약 (손가락이 닫히는 동안 손을 grasp 에 둔다, held 전 들기 없음).
  - 추종 · 부드러움은 그대로 (G1 의 0.25 배 · 연속성 끔 같은 보정 없음).
- **작동 창 (HSR ④ 와 독립):** grasp latch 가 latched · closing 이고, (VLA chunk 가 0 < c < H 에서 닫기를 계획하거나 closing 단계) 이고, 손바닥 site 가 사과 중심 60 mm 안 (A6 창, `_grasp_moment_window` 재사용). HSR ④ (`--hsr6-objective`) 는 이 항을 거두지 않는다 — ④ 는 이웃 허용만 계속 다스린다. (이유: T68 에서 ④ 때문에 A4 · G1 이 0 회였다. 같은 일이면 T72 는 아무것도 재지 못한다.)
- **GPU 여러 초기값 경로 (E3-b, `gpu_seeds.py`):** cuRobo seed 문제에 같은 도달 상자 · 회전 항을 넣거나, 넣지 못하면 seed 결과 선택 (`select_moving_first`) 이 우리 full-resolution 검사에서 도달 제약 위반을 위반으로 세게 한다. 어느 경로가 답을 냈든 기록 `reach_err_mm` 이 같은 정의여야 한다. impl.md 에 어느 쪽을 했는지 적는다.

## 6. 이 STEP 이 답하는 질문

충돌을 고려한 기하 grasp 후보 집합을 도달 제약으로 넣고, quality 와 VLA 의도 차이로 고르면 (추종 + 부드러움 목적함수 위에서), 평소 쥐지 못하던 세 장면에서 금지 접촉 없이 쥐는가.

## 7. 되돌아올 지점

- 기능이 작동하지 않으면 (자격 후보 0 이 대부분): 자격 반경 · 후보 생성기의 떨어진 이유를 먼저 본다 (반경은 사용자에게 묻고 바꾼다).
- 작동하지만 성공이 늘지 않으면: 원인 층이 LTE · CCR (거리장 · 여유) 이면 T69 경로 (그 층에서 고침) 로 돌아간다.
