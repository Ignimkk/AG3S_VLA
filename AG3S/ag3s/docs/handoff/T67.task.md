## 0. 왜

- 최종 구성 (A8 + 기하 보정 + HSR 6 단계 ② 수정 + 손바닥 이웃 허용) 의 쥐지 못함 8 / 32 run 은 같은 형태다.
  - 마지막 60 mm 에서 TrajOpt 가 손바닥을 VLA 계획보다 크게 밀었다 (한 요청 최대 밀림 중앙 19.9 mm, 쥔 run 7.8 mm).
  - VLA 가 밀린 자리에서 닫아 빗나갔다 (닫기 시작 손바닥–사과 중앙 44 mm, 쥔 run 19 mm, 같은 장면 VLA 단독 14–24 mm).
- 민 제약 (T66b, 서버 규약으로 정정):
  - 211 · 1345 · 가림 122: 손끝 ↔ 탁자 (사과 밑 접촉부 띠 포함). VLA 계획은 손끝을 탁자 위 4–7 mm 로 내린다.
  - 954: 손가락 ↔ 옆 바나나. VLA 계획은 1–4 mm 로 지나간다 (VLA 단독은 접촉 없이 들었다).
  - 거리장의 탁자 표면이 실제보다 약 5 mm 위에 있다 (§1). 이웃 과일 쪽은 치우침이 작고 여유 10 mm 가 주원인이다.
  - 같은 측정에서 쥔 첫 요청의 급변 (가림 121 흔들림 1) 은 정밀 거리장의 손 잔상 4 voxel 때문이었다. T67 범위 밖 (기전 지표로만 본다).
- 이 구간을 위해 있는 장치 (손가락 이웃 허용 IFG-NBC · 닫는 목표 A4 · 기하 보정 G1) 는 HSR 규칙 ④ 때문에 마지막 접근 요청마다 꺼졌다 (HSR6 = approach).

## 1. 거리장 표면 치우침 — 측정값 (결과 전, 보정값 고정의 근거)

- 측정: 최종 구성 18 run (FIN_k0 · FIN_k1 · OCC_FIN) 의 기록 요청 4 개마다 1 개, 정밀 거리장 (`esdf`, 5 mm) 을 서버 규약 (원점 = voxel 0 중심, 삼선형) 으로 읽었다.
- 사과 중심 150 mm 안의 물체 표면 (MuJoCo) 에서 바깥 10 · 15 · 20 mm 로 옮긴 점마다, 실제 최단 거리 (모든 비로봇 표면 · 로봇 표면) d 와 거리장 값 v 를 비교했다. d ∈ [8, 22] mm 이고 v > 0 인 점만, 프레임마다 중앙값 (d − v) → 프레임 중앙값.
- 결과 (`T67.bias.json`, 스크립트 `outputs/2026-10-29_최종구성_쥐기실패_원인진단/diag/biasall2.py`):

|---|---|---|---|

- 그래서 954 (바나나) 의 밀림은 거리장 치우침보다 **여유 10 mm** 가 주원인이다. VLA 계획이 실제 1–4 mm 로 지나가기 때문이다.

## 5. 판정 규칙 (결과 전 고정)

### 1 단계 → 2 단계에 올릴 구성

- 통과: 실패 집합 8 run 에서 **금지 접촉 없는 성공 ≥ 4** 이고 **금지 접촉 run ≤ 1** (최종 구성의 이 8 run 기준값 = 1, 허들 211 k0 의 이웃 바나나 접촉).
- 통과한 구성이 여럿이면 금지 접촉 없는 성공이 가장 많은 것. 차이가 1 run 이하면 **바꾼 항목이 적은 쪽** (C1 · C2 > C3). 그래도 같으면 C2 (관측 층 원인을 그 층에서 고침).
- 아무 구성도 통과 못 하면 2 단계를 돌리지 않고 결과와 원인을 보고한다.

### 2 단계 → 채택 (최종 구성 대체)

모두 충족해야 한다.
1. 금지 접촉 없는 성공 ≥ 최종 구성 32 run 값 + 3 (최종 = 9 장면 14 / 18 + 허들 6 / 14 = **20 / 32** → **≥ 23 / 32**).
2. **금지 접촉 run 이 최종 구성보다 늘지 않는다** (최종 32 run = 9 장면 0 + 허들 3 (허들 스침 2 · 이웃 과일 1) = **3** → **≤ 3**). 점 추정, 허용오차 없음.
3. 탁자 · 바구니 접촉 run 이 늘지 않는다 (최종 0).
4. 9 장면 · 허들 각각에서 금지 접촉 없는 성공이 최종보다 줄지 않는다 (14 · 6).

- 아니면 최종 구성 유지. ③ (허용량) 처럼 금지 접촉과 맞바꾸는 항목도 규칙 2 로 막는다.
- 장면당 2 번이라 통계 판정이 아니라 짝 비교다. 실패 run 마다 원인 층 (ATS · HSR · LTE · CCR) 을 적는다.
