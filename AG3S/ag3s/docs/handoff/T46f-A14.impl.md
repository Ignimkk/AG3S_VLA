## 무엇을 했나 (평이한 요약 먼저)

**목적.** DX-04 (link-specific exemption) 비교 전에 비권한 손목의 충돌 형상을 실제 MuJoCo 형상에 맞춘다. T46d 에서 두 문제가 나왔다.
- URDF `link_*_arm_5` capsule (r 75 mm, 축 z ∈ [−0.225, +0.025]) 의 구가 **손 영역 안**에 놓였다.
- MJCF `FT_SENSOR_*` (손목 F/T 센서) 에는 구가 **하나도 없었다**.

그리고 조건 ① "예외 없음" 정책을 넣는다.

모든 새 동작은 기본 off 다. `--links` 기본 `gripper`, `--target-field-policy` 기본 `relax` 이면 모델 · 동작이 비트로 같다.

**이전 대비.**

- 여기에 두 선택지만 더했다 (기본 `None` = 예전 계산 그대로).
  1. `target_mask`: 강체 이웃 (손바닥 · arm_6 · FT) 에 묻힌 면은 덮을 대상에서 뺀다. 아무것도 닿을 수 없는 면이다.
  2. `keep_out`: 권한 손 (손바닥 + 손가락) 의 MJCF collision 껍질. 반지름 상한을 그 껍질의 지지 평면 거리로 둔다. 그래서 비권한 구가 손 형상 안으로 **정확히** 한 점도 들어가지 않는다.
- 손가락 keep-out 은 prismatic 이동 전 구간을 쓴다 (열림 ∪ 닫힘 정점의 볼록 껍질 = 정확한 sweep). arm_5 는 arm_6 joint (z 축) 가 손을 돌리므로, 손의 z 최대값 아래 반공간 전체를 keep-out 으로 둔다.
- **arm_6 도 고쳤다.** task §4.2 는 arm_5 만 적었다. 그러나 §4.4 의 "보정 arm_5 · arm_6 · FT sensor" 와, arm_6 겉면 96 % 가 구 밖인 실측 때문에 같이 고쳤다 (판정 필요 3).

## 4. `--target-field-policy none` (예외 없음) — 정책별 의미

쥐지 않은 target 에 대해 (쥔 뒤의 규칙은 네 정책 모두 같고, 바꾸지 않았다):

| | relax (기본) | exclude_authorized (③ LTE) | exclude_all (② global) | **none (①)** |
|---|---|---|---|---|
| target-free 계층을 만드나 (`excludes_target_from_field`) | 아니오 | 예 | 예 | **아니오** |
| target-free 조회 행 (`target_field_exclude`) | 없음 | 권한 행 | 전 행 | **없음** (필드에 계층이 있어도) |
| 권한 행의 target 마진 완화 (`manipulated_link_margin`) | phase 완화 | phase 완화 | phase 완화 (exempt) | **없음 — 전 행 `full_margin(TARGET)`** |
| `--nonauthorized-target-margin obstacle` 이 걸리는 행 | 비권한 행 | 비권한 행 | 비권한 행 | **전 행** |
| trajopt 의 target 접촉 허용 행 (`target_contact_rows_of`) | 권한 행 | 권한 행 | 권한 행 | **없음** |
| verdict 의 허용 접촉 (`SafePolicy._authorized_links`) | 권한 link | 권한 link | 권한 link | **없음** |
| 기록 `target_permission` | policy relax, authorized = 권한 link | … | … | policy `none`, `authorized_links = []` |
| FT sensor (`PROTECTED_LINKS`) | 비권한 | 비권한 | target-free 조회는 받는다 (global 의 정의) | 비권한 |

- 구현은 한 함수다: `clearance.target_permission_context(ctx, policy, attached)`.
