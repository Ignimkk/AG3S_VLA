## 1. 구현 (→ `ag3s-implementer`)

### 1.1 `--surface-solid-shadow-mm L` (기본 꺼짐, `--surface-solid-owned` 필요)

- **정의:** 손 층 미세 tier 의 seed `x` 가 다음을 모두 만족하면 target 소유 (지운다):
  1. 직전 채택 영역을 고른 요청의 카메라 중 하나에서, `x` 를 투영한 pixel 의 code 가 target (= 채택 영역 pixel) 이고,
  2. `x` 가 그 pixel 의 관측 표면 **뒤** 에 있다: `0 < depth_cam(x) − depth_pixel ≤ L` (L = `--surface-solid-shadow-mm`, 권장 80 — 손에 쥘 물체 크기의 상한. 사과 전용 값이 아니라 그리퍼 최대 폭 근처의 범용 상한),
  3. `z ≥ z_floor` (지금 guard), `d_N > τ` (T96 의 이웃 보호, D28 의 받침면 제외 그대로), `d_T ≤ d_N` 은 **적용하지 않는다** (뒤쪽 voxel 은 보인 target 표본에서 멀어도 target 의 그림자 안이다 — 대신 2 와 τ 가 범위를 묶는다).
- 뜻: 카메라가 target 을 보고 있는 방향으로, target 표면 뒤 L 안의 관측되지 않은 공간은 target 이 차지한다고 본다 (닫힌 물체 가정의 광선판). 이웃 관측 표면 τ 안은 지우지 않는다.
- 필요한 것: 채택 영역을 고른 요청의 code 영상 · depth · 카메라 (K, T_base_cam) 를 영역과 함께 저장 (지금 `_surface_solid_store` 가 영역 node 만 저장한다면 그 옆에). 여러 카메라면 하나라도 조건을 만족하면 소유.
- 기록: `solid` 블록에 `n_removed_shadow` · `shadow_mm` · 카메라별 기여 수.
- 시간: 추가 p95 ≤ 20 ms (CPU, 후보 = S 를 L 만큼 키운 상자 안 seed 만 투영).

### 1.2 T96 solid δ 0 에서 안 보인 잔여가 늘어난 원인 확인 (코드 변경은 원인이 버그일 때만)
