## develope_PLAN 에서의 위치 — 왜 이것만 하는가
- `doc/plans/develope_PLAN.md` §0.10.1: **target identity 와 extent 를 분리하고, 필요한 target 접촉은 허용하면서 인접 장애물 경계를 보존하는 3D 방법 하나를 집중 개발**한다. T46 F1 (non-target 근거에서 target 자신의 표면 점을 빼는 surface 근거) 이 그 **후보**다.
- CL3 (`T46-CL3.verify.json`): F1 은 grasp 직전 HOLD run 12 → 6, 이웃 과일 접촉 run 4 → 1 로 **목적한 경계 효과**를 보였지만, task success 는 14 → 13 으로 같고 **close 이후 uncertified HOLD 가 107 → 183** 으로 늘었다.
- §1.2 DC-1 · DC-4: 방법이 "잘못된 접촉 허용/차단을 줄인다" 와 "task 와 forbidden contact 의 trade-off 를 개선한다" 를 보여야 한다. 늘어난 stop (HOLD) 은 safe success · completion time 을 해친다.
- 그래서 T46b 는 **F1 을 §0.10.1-3 의 방법으로 채택할 수 있는가** 에 답하는 데 필요한 진단만 한다. 원인 추적을 넓히지 않는다 (§0.4 중단 기준).
