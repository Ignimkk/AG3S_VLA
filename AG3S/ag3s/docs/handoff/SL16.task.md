## 1. 근거 (SL15, `outputs/2026-11-06_SL15_변환D/`, `doc/active/experiments/SL_AUTONOMOUS_DECISIONS_20261106_KO.md` F7 · F11 · F14)

- 제약 기록(DREC J1, LIBERO seed 8, 변환 D)에서 가까운 표면의 주인:

## 2. (다) 판 HSC — 쥔 동안 받침면 접촉 허용

**flag:** `--held-support-contact`(기본 꺼짐). 값 `--held-support-contact-finger-mm`(기본 10).

**언제:** 이 call에서 실제로 쥐고 있을 때 — latch HELD(개도 규칙 판에서는 개도 · 명령 attach가 HELD로 만든 것 포함). HSR6 단계(lift · transport · placement)는 묻지 않는다. CLOSING은 HSR6 ⑤와 같은 조건(closed ∧ blocked)일 때만 같이 받는다.

**무엇:**
1. **쥔 물체 구 행**: 가장 가까운 거리장 표면이 그 아래에 있으면(HSR6 ⑤와 같은 기하 시험: 단위 기울기 ĝ_z ≥ cos 45° ∧ 최근접 표면점이 쥔 물체 xy 발자국 + 1 voxel 안) margin −1 m(막지 않음). 또는 `_obstacle_rows`가 class `support`로 부르는 행이면 같다. 즉 ⑤를 모든 쥔 단계로 넓힌 것이다.
2. **쥔 손의 손가락 · 손바닥 행**(권한 contact link: `panda_leftfinger` · `panda_rightfinger` · `panda_hand`, palm shell 포함): 가장 가까운 표면이 같은 '아래' 시험을 통과하거나 class `support`이면 margin = −`finger_mm`(기본 10 mm 겹침까지 허용). 발자국은 쥔 물체 발자국 ∪ 손가락 구 xy 원판이다.
3. 그대로 두는 것: 팔 link 행, 옆 · 위 표면, class `obstacle`이면서 '아래' 시험을 통과하지 못한 행, 쥐지 않은 call 전부.

**기록:** call마다 `held_support_contact`: {applied, latch, held_rows_exempt, finger_rows_allowed, n_rows}. 꺼짐이면 키 없음(비트 동일).

**판 이름(implementer가 등록):**
- `AG3S-final-panda-v3-e0to-pc-openrule-hsc` = 개도 규칙 판 + `--held-support-contact`
- 실행 변환: D

**기제 시험(결과 전 고정):** LIBERO 27에서 실제로 쥔 call(HOLD 제외)의 누적 EE 경로 변화 **p90이 D(105 mm)의 절반 이하(≤ 52 mm)**. 그리고 DREC와 같은 J1 기준에서 쥔 뒤 손가락 대 탁자 binding 행이 0이다. 기록은 `--record-constraints full` 없이 call 표(`scripts/rowdev.py`)로 잰다. 기제를 통과하지 못하면 "의도대로 동작하지 않음"으로 적고 성공은 읽지 않는다.

## 3. (가) 판 HVC — 거리장 voxel 단계 손 지우기

### 3.1 먼저 원인을 가린다 (CPU, GPU 불필요, 결과 전 규칙)

입력: SL15 DREC run `20261106T023436_5bccd363ef5d_sl15-DREC-libero9-pc-convD-seed8-...`(제약 기록 · geomsnap 있음). 도구는 `panda_sfhand_leak.py` 옆에 새로 만든다(읽기만).

CLOSING · HELD call마다, 손 · 손가락이 주인인 fine 점유 voxel(`d < 0`) 하나하나를 다음 셋 중 하나로 나눈다.
- **현재**: 지금 관절 상태의 `panda_hand` · 손가락 self-filter 구까지 sd ≤ 4 mm
- **잔상**: 현재는 아니고, 직전 8 요청(약 1.6 s) 중 어느 요청의 관절 상태에서 손 구까지 sd ≤ 4 mm
- **번짐**: 둘 다 아님

**규칙:** 잔상 비율 ≥ 0.5이면 HVC 모드 = `trail`, 아니면 `current`.
- `current`: 지금 관절 상태의 손 · 손가락 self-filter 구를 r만큼 키운 부피 안의 fine voxel을 free로 만든다. r = 손 voxel sd의 p90, 상한 20 mm.
- `trail`: 직전 8 요청의 손 · 손가락 구(키움 4 mm) 합집합 안의 fine voxel을 free로 만든다. 단, 현재 손 구에서 20 mm보다 먼 voxel은 빼지 않는다(먼 과거는 이미 다시 관측됐다고 본다).
- 두 모드 공통 안전 조건: 지지면 평면 아래 voxel과 현재 manipulated target 부피(`target_volume`) 안의 voxel은 지우지 않는다. 쥔 물체 구 안쪽은 원래 규칙대로다.

**RB-Y1 비교(가능할 때만):** `${AG3S_STORAGE_ROOT}/results/rby1*` 또는 development run에 fine 거리장 · 관절 상태 기록이 있으면, 같은 분류를 RB-Y1 손(`ee_*` · 손가락 link)에 적용해 같은 표를 낸다. 없으면 "기록 없음"으로 적고 넘어간다. 사용자 질문("RB-Y1에서는 되는데 Panda에서 안 되는 이유")에 대한 측정 답이다.

### 3.2 구현

**flag:** `--hand-voxel-carve {off,current,trail}`(기본 off), `--hand-voxel-carve-mm`(current의 r; 3.1의 결과로 정해 등록). 거리장 builder 단계(fine 계층, TSDF → ESDF 전)에서 한다. RB-Y1 서버는 거절한다(Panda 전용, 기본 꺼짐).

**기록:** 요청마다 `hand_voxel_carve`: {mode, r_mm, n_voxels_freed}. 꺼짐이면 키 없음(비트 동일).

**판 이름:** `AG3S-final-panda-v3-e0to-pc-openrule-hvc`(개도 규칙 판 + 3.1에서 정한 모드 · 값). 실행 변환: D.

**기제 시험(결과 전 고정):** LIBERO 27에서 쥐는 중(CLOSING) call의 누적 EE 경로 변화 **중앙값이 D(15.1 mm)의 절반 이하(≤ 7.6 mm)**(SFD와 같은 시험). 그리고 SafeLIBERO 11에서 지운 voxel 중 MuJoCo GT 주인이 로봇이 아닌 비율을 세어 보고한다(진짜 장애물 지우기 위험; 기제 판정에는 넣지 않음, 0.05를 넘으면 lead가 사용자에게 알린다).
