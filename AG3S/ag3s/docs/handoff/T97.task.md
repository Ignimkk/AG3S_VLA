## 0. 왜 · 지금까지 (출처 링크)

- 증거: 회귀 211 · 954 의 남은 실패가 붙은 바나나 (T87 재생: 추가로 지운 이웃 과일 voxel 대부분이 회귀 211 의 사과에 붙은 바나나). SafeLIBERO Level I 은 target 바로 옆 장애물과의 접촉을 충돌로 센다 (D1).
- **이미 있는 것 — T78d (`--surface-crease-cut` · `--surface-crease-reattach-ratio`, 기본 꺼짐):** 2.5 mm node + 오목 · 20° 이상 edge 끊기 + 끊긴 작은 조각 (선택 영역의 R = 0.25 배 이하) 다시 붙이기. 영역 판정 (T78c §8 의 487 요청) **통과**: 맞닿은 장면 정밀도 중앙 0.63 → 1.00 · 덮음 0.988, 떨어진 장면 덮음 1.000 → 0.992 · 다른 물체 0 (`AG3S/ag3s/docs/handoff/T78d.task.md` §5).
  - 붙여 주신 진단 "꼭지 · 잎 덮음 2.5 %p 손실" 은 T78c (다시 붙이기 없음, 0.975) 의 값이다. T78d 의 다시 붙이기로 영역 단계 손실은 0.8 %p 다.
- **남은 문제 (손 층, 서버 재생):** 떨어진 장면 쥐기 직전 사과 지움 77.0 → 73.2 %, 손가락 접촉 영역 잔여 중앙 0 → 0.167. 원인 = 손이 가까울 때 2.5 mm node 가 손가락 mask 누락 node 를 더 끊음 (`outputs/2026-11-01_T78d_T78e_오목끊기_target유지기억_재생비교/README.md`). 그때 제안된 "손이 가까운 구간에서는 손이 멀 때 고른 영역 유지" 는 사용자 판정 전에 멈췄다.
- 다시 붙이기의 한계 (T78d impl): 선택 영역의 R 배보다 작은 맞닿은 이웃은 붙는다 (크기 비율이 기하 근거가 아니다). 그래서 이번에 **"받침면 위쪽으로 솟은 작은 돌출" 조건** 을 크기 비율 대신 (또는 함께) 시험한다.

## 1. 구현 (→ `ag3s-implementer`)

### 1.1 돌출 보존 — `--surface-crease-protrusion` (기본 꺼짐, `--surface-crease-cut` 필요)

- 끊긴 edge 로만 선택 영역과 이웃한 성분 C 마다 (지지면 아님, 관심 영역 안):
  - `h_C` = C node 의 받침면 높이 (영역 아래 RANSAC 평면 normal 방향) 중앙, `h_R` = 선택 영역 node 높이 상위 10 % 경계.
  - `a_C` = C 를 받침면에 투영한 면적, `a_R` = 선택 영역 투영 면적.
  - **붙이는 조건:** `h_C ≥ h_R` (영역 꼭대기보다 위로 솟음) ∧ `a_C ≤ ρ · a_R` (`--surface-crease-protrusion-area` ρ, 기본 0.15) ∧ C 의 투영이 선택 영역 투영 convex hull 과 겹침 (몸통 위에 얹혀 있음).
  - 뜻: 꼭지 · 잎 · 손잡이 윗부분처럼 몸통 위로 솟은 작은 부분은 붙이고, 옆에 맞닿은 같은 높이의 이웃 (바나나 · 이웃 과일) 은 붙이지 않는다. 크기 비율 R 처럼 "작은 이웃이면 붙는" 한계가 없다 — 옆에 있으면 높이 · 투영 겹침 조건에서 떨어진다.
- `--surface-crease-reattach-ratio` 와 같이 주면 거절 (두 붙이기 규칙의 효과를 가른다).
- 기록: `crease` 블록에 성분마다 `h_C − h_R` (mm) · 면적 비 · 투영 겹침 · 붙임 여부.

### 1.2 손 가까울 때 영역 유지 — `--surface-crease-hand-freeze-mm D` (기본 꺼짐, `--surface-crease-cut` 필요)

- 쥐는 손 손바닥 점 (T78b `_grasp_palm_points`) 이 직전 채택 영역 중심에서 D mm 안이면 (latch searching · latched · closing 에서만) 이번 요청은 영역을 새로 고르지 않고 직전 채택 영역 (손이 멀 때 고른 것) 을 쓴다. 쥔 뒤는 지금 `--surface-grasp-hold` 그대로. 권장 D = 80 (hull fill 의 손바닥 창과 같은 값).
- 기록: `freeze` (적용 · 손바닥 거리 · 영역 나이).

## 2. 측정 · 판정 (결과 전 고정)

### 2.1 영역 판정 (T78c §8 · T78d §2.2 와 같은 487 요청 · 정답 · 지표, 서빙 CPU 경로)

- arm: C1 = T78d (끊기 + 다시 붙이기 R 0.25), C2 = 끊기 + 돌출 보존 (ρ 0.15), 기준 = 5 mm graph (P0m).
- **통과 (C2, 모두):** 맞닿은 장면 (간격 < 5 mm, 쥐기 전) 정밀도 중앙 **≥ 0.95**, 맞닿은 장면 덮음 중앙 ≥ 0.90, 떨어진 장면 덮음 중앙 손실 **≤ 2 %p** (기준 대비), 떨어진 장면 다른 물체 node 0. 붙인 성분의 정답 분류 (꼭지 · 잎 = 사과 · 이웃) 보고.
- C1 · C2 중 통과한 것으로 다음 단계. 둘 다 통과면 이웃을 붙인 성분 수가 적은 것, 같으면 C2 (크기 비율 문턱이 없는 쪽).

### 2.2 손 층 재생 (T87 재생 입력 · 정의, 허들 211 제외)

- arm: 기준 (P0m 손 층) 대 (2.1 의 선택) + `--surface-crease-hand-freeze-mm 80`.
- 보고 + 기준: 맞닿은 이웃 요청의 지운 이웃 과일 voxel 이 기준보다 줄고, 떨어진 장면 쥐기 창 남은 target voxel (바닥 띠 제외) 이 기준 + 1 %p 이내.

### 2.3 closed-loop (exclusive, `--stop-after-place 2.5`)

- 장면: 기존 9 run k0 · k1 (해 없음) + 맞닿은 이웃 장면 회귀 211 · 954 (각 seed 3).
- 판정: 9 run 합계 ≥ 16 / 18 · 금지 ≤ 1 · 탁자 0, 그리고 회귀 211 · 954 에서 쥐는 손–이웃 과일 접촉 step 이 P0m 보다 줄고 성공이 줄지 않음. **이웃 과일 면제 (D2) 를 끈 정의 (benchmark 정의) 로도 함께 낸다.**
- T96 이 먼저 closed-loop 을 쓰면 T97 은 그 뒤 (독점 lock 순서). T96 채택 여부가 정해지면 기준을 그 구성으로 바꿀지 사용자에게 묻는다.
- 채택은 사용자 판정.
