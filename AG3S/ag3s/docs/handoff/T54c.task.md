# T54c — 명사 grounding (N · B) 후속 확인: 한 번도 쓰지 않은 새 16 episode 에서

> writer: lead (A0) · 2026-10-13 KST · 읽는 쪽: implementer, verifier · 로그: `AG3S_T47_LOG.md`
> 근거: 사용자 판정 (2026-10-13, T54 결과 보고 후) "N · B 를 후속 후보로, 새 data 에서 확인".
> **후보와 기준은 새 data 를 열기 전에 고정한다 (이 문서).** T53 은 N · B 를 고른 뒤이므로 **이제 dev 다.**

## 왜

T54 에서 사전 고정 후보 A (L8H2 후보 + 명사 선택) 는 T57 진입 기준을 넘지 못해 **기각** 했다.
- identity −3.08 %p, 개선 근거 없음.
- 후보는 있었지만 명사가 잘못 고른 frame 이 7.4 % 로 L8H2 의 4.3 % 보다 많았다.

반면 비교 arm N (명사 단독) 과 원인 확인용 B (명사 seed + L8H2 split 비율) 는 현재 frame 조건에서 개선을 보였다 (identity +7.1 %p [+3.6, +11.1], coverage +6.8 %p, 이웃 혼입 −4.7 점).
- 이 방향은 dev 결과 (T49 · T51b: 명사 ≤ action) 와 반대다.
- N · B 는 T53 을 본 뒤에 후보가 됐다.

그래서 **새 data 에서 다시 확인한 뒤에만** T57 로 넘긴다.

## 사전 고정

| 항목 | 값 |
|---|---|
| 후보 | **N** (`noun_target:L10H7` raw σ0 k1 이 lifting · seed · split · 선택을 모두 맡음) 과 **B** (seed · 선택 = 명사, split 비율 = L8H2). T54 정의와 bit 단위로 같은 코드를 쓴다 |
| 기준 arm | L8H2 (서빙) |
| 함께 보고 (판정 아님) | A · L12H4 · N-k3 (T54 와 같은 정의) |
| 조건 | **현재 frame (주)** · **유지 포함 (T54b 로 고친 재생, 보조)** |
| 지표 · 집계 · CI | T54 사전 고정 3 · 4 그대로 (episode 평균, paired 차이, episode block bootstrap B = 10000, seed **5417**, moving block 5 민감도, phase 분해) |
| T57 진입 기준 | T54 사전 고정 5 의 표를 **N 과 B 에 각각** 그대로 적용한다. identity ≥ −3 %p · coverage ≥ −5 %p · 개선 근거 하나 이상 관측 · 유지 포함에서 같은 허용폭 · 시간 예산 (T54 `budget` 의 정의). 추가로 **새 data 에서 N − L8H2 의 identity 차이 방향이 T53 과 같아야 한다 (평균 > 0)** |
| 둘 다 통과하면 | **N 을 T57 후보로 한다** (구성 요소가 적다). B 는 보고만 한다. N 이 실패하고 B 만 통과하면 B 를 후보로 한다 |
| 표현 | 통과해도 "offline 개선이 새 data 에서 다시 관측돼 closed-loop 확인 대상으로 선정했다" 까지만 쓴다. 우월성 입증이라고 쓰지 않는다 |
