## 1. 요청 (프레임) 마다 판정 기준 (결과 전 고정, 사용자 제시안 그대로)

| 모듈 · 기능 | 판정 구간 | 통과 |
|---|---|---|
| ATS — target 찾기 | 쥐기 전 (정답 pick 단계, 두 손가락 접촉 전) | target 점 중 정답 사과 표면 5 mm 안 ≥ 80 % ∧ 다수 정답 물체 = 사과 ∧ 보이는 정답 표면 중심과 target 점 중심 차 ≤ 15 mm. target 없음 = 실패 |
| HSR — 작업 단계 | 전 구간 | 예측 pick / place = 정답 (사과가 손에 들려 20 mm 이상 올라간 뒤 = place). 전환 뒤 1 요청까지는 지연 허용 |
| HSR — 쥠 상태 | 전 구간 | 예측 held (latch held) ⇔ 정답 held (두 손가락 접촉 ∧ 들림 ≥ 20 mm). 전환 뒤 1 요청까지 지연 허용 |
| LTE — target 제외 | 쥐기 전 + 쥐는 중 (손 층이 있는 요청) | 쥐는 손 층에 남은 사과 표면 ≤ 5 % ∧ 사과 아닌 물체 (이웃 과일 · 장애물 · 탁자 · 바구니) 를 지운 voxel = 0 |
| LTE — 로봇 자기 점 | 같은 구간 | 손바닥 12 cm 안에서 정답 로봇 표면 8 mm 안에 있는 장애물 voxel (주 거리장 점유) = 0 |

- 정답 class 거리 8 mm, 사과 표면 5 mm 는 핵심 평가와 같다. 정답이 정의되지 않는 요청 (예: 사과가 화면 밖) 은 "판정 불가" 로 따로 센다.
- CCR 은 판정하지 않고 증거만 함께 그린다 (VLA 대비 수정량 · HOLD · 최소 여유).
