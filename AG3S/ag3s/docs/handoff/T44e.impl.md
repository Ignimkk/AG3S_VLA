## 무엇을 했나 (평이한 요약 먼저)

**A8.** coarse target-free 계층 (`coarse_no_target`) 을 만들 때 공 아래 지원면 (table) 의 seed 를 지우는 선택지를 더했다
(`esdf.target_free_coarse_support = "exclude"`, 기본 `"keep"` = A7 그대로). 지우는 seed 는 세 조건을 다 만족하는 것뿐이다 —
(1) 그 면에서 seed 띠 + 반 칸 (28 mm) 안, (2) 그 면의 **inlier 점** (관측 근거) 이 28 mm 안, (3) non-target 관측점이 18 mm 안에 없다
(A5 의 공유 규칙 그대로 — distractor · crate 와 voxel 을 나누면 보존). 테이블 seed 가 없으니 공의 seed guard (지원면 + 20 mm) 는 지킬 것이
없어 공의 `z_min` (미세와 같은 지원면 + 5 mm) 으로 내렸다. 지운 지원면 seed 는 부호 교정 (순수 판정) 에도 넣었다 — 안 넣으면 테이블 윗면
바로 아래 voxel 의 음수와 위 voxel 의 양수 사이 보간이 평면 근처에 영교차를 다시 만든다 (CPU test 로 확인). 합성식 `min(f, a, max(c, d), max(d, b))` 은
그대로다.

**A9.** `contact.nonauthorized_target_margin = "obstacle"` (기본 `"full"`) 이면 AG3S 가 접촉 권한이 없는 구 (`authorized_links` 밖) 를
`CollisionConstraintSet.nonauthorized_target_rows` 로 싣고, trajopt 는 그 행을 **margin 의 target 판정 두 곳** (`is_object` · `_obstacle_rows` 의
target class) 에서 뺀다. 그러면 그 행의 여유는 obstacle 행과 **같은 식** (`esdf_margin`, `obstacle_margin > 0` 이면 `max(esdf_margin, obstacle_margin)`)
에서 나온다 — V11AB 설정에서 50 mm → 10 mm. `manipulated_link_margin` 값 · 권한 link 의 phase 여유 · strict · carry · 접촉 금지 (`unauthorized_link`) 는 그대로다.

### reach (28 mm) 를 정한 이유

seed 띠는 `0.9 · vs` = 18 mm 이다. 반 칸 (10 mm) 을 더한 두 이유: (a) 테이블의 TSDF 영교차는 맞춘 평면보다 몇 mm 위에 선다 (`linearize._obstacle_rows`
docstring: 20 mm 계층 `|d − s|` 중앙 8.7 mm) — 띠만 쓰면 위쪽 seed 를 놓친다; (b) cloud 는 voxel 로 성겨 (5 mm) 발 밑 점이 옆에 있을 수 있다.
공유 판정 (non-target 점) 은 A5 그대로 18 mm 다.

### A8-3 — 덜 보수적이 되는 점 (`old` = coarse off)

- **구조적으로 0.** `c` 는 `max(c, d)` 로만 들어가므로 어떤 `c` 든 `min(old, d) ≤ new ≤ old` 다 (A5 의 성질; test `test_composition_stays_bracketed_with_the_exclude_tier` + GPU test).
- **smoke 실측 0** — 64 frame × D · T · TB · TA · q · grid **2,223,190 점**에서 `new > off` 0 · `new < min(off, d)` 0 (ball · bo_d3 둘 다). TB (지원면 아래 30 mm) 에서
  off < 0 → exclude ≥ 0 뒤집힘 0.
- **keep (A7) 대비** 로는 의도대로 덜 막는다 — bo_d3 에서 exclude > keep 인 점: TA 86,731 (높이 중앙 7.8 mm, 증가 중앙 5.0 mm) · TB 281,601 (지원면 아래, 증가 중앙 4.5 mm,
  그중 keep < 0 → exclude ≥ 0 인 점 52,591 은 **전부 off 도 ≥ 0** — off 대비 뒤집힘 0) · T 21,458 (93 % 공 안) · D 14,622 (높이 중앙 15.4 mm, 증가 중앙 1.8 mm). 창 밖은 `d` 라 변화 없음.

### A8-4 — sign floor (`plane`) 와의 관계

exclude 에서는 seed guard 가 공의 `z_min` 으로 내려가 `sign_z_min_m == z_min_m` → plane 띠가 **빈다**. 그래서 exclude 에서 `plane` 과 `guard` 는 같은 계층이다
(test `test_sign_floor_is_moot_under_exclude`: 값 · site_index `torch.equal`). plane 이 하던 일 (guard 아래 target 바닥 내부의 부호 교정) 은 공 후보가 `z_min` 부터
시작하므로 공 제외의 부호 교정이 한다. 측정: target 내부 음수 (67,361 점 중) ball off 2,021 · keep(plane) 2,302 · **exclude 2,124** · excl_g (지원면 제외 + guard 유지 = plane 띠 활성) 2,205;
bo_d3 2,257 · 2,694 · **2,550** · 2,558. → plane floor 는 exclude 에서 **필요 없다** (값을 바꾸지 않았다; config 기본 plane 은 그대로).

## 무엇을 했나 (평이한 요약 먼저)

(조건 1–3: 평면 띠 + 반 칸 · inlier 근거 · non-target 과 3D 공유 아님) 중에서 **target 발자국 안이고 non-target 발자국 밖**인 것만 지운다.
이웃 과일 · 기타 물체 아래와 그 밖의 테이블 seed 는 keep 처럼 남는다. 두 발자국이 겹치는 seed 는 남기고, 그 겹침 seed 는 공 규칙

## 발자국 정의 (m, 지원면 위 그림자)

| 발자국 | 증거 | seed 중심 `c` 가 안 | 파일:줄 |
|---|---|---|---|
| target | 공 (미세 계층이 지운 그 공, pad 포함) + target 점 (평면 위 `h_min` 초과) | 평면 거리 (`c`, 공 중심) ≤ `r + D` 또는 (`c`, 최근접 target 점) ≤ `D` | `ag3s/fields/curobo_builder.py:2113-2163` (`_coarse_support_footprints`) |
| non-target | non-target 관측점 (fused cloud − target − 지원면 inlier = `_nontarget_points`, 평면 위 `h_min` 초과) | 평면 거리 (`c`, 최근접 점) ≤ `D` | 같은 곳 |

- **`D = √2 · 거친 voxel` = 28.3 mm** (`COARSE_SUPPORT_FOOTPRINT_DILATION_VOXELS`, `curobo_builder.py:239-244`). 거친 계층은 trilinear 로 읽힌다 —
  한 query 는 축마다 한 칸 안의 voxel 중심 8 개를 읽고, 그 중심은 평면 방향으로 최대 대각 `√2 · vs` 떨어져 있다. 그래서 발자국 안 query 가 읽는
  지원면 voxel 은 모두 발자국 + `D` 안이다: target 은 그것까지 지우고 (공 아래 query 가 테이블 seed 를 안 읽게), non-target 은 그것까지 남긴다
  (이웃 과일 아래 query 가 keep 과 같은 seed 를 읽게). 둘이 같은 팽창이다.
- **`h_min` = `support_surface.distance_threshold` (8 mm, RANSAC inlier 문턱)** — 그 안의 점은 같은 규칙으로 테이블과 구별되지 않는다. 안 두면
  inlier 에 못 든 테이블 잡음이 target 둘레 전부를 non-target 발자국으로 덮는다 (test). pipeline 이 활성 값을 `support_seed_evidence["inlier_threshold_m"]`
  로 넘긴다 (`ag3s/runtime/pipeline.py:2636-2641`), 없으면 builder 기본 8 mm (`curobo_builder.py:245-248`).
- 지원면 inlier 점 · 평면 · 면 선택은 A8 그대로 (`pipeline.py` `_support_seed_evidence` · `_support_surface_under`).
- 겹침 보호 (`protect`) 는 조건 1 (평면 띠) + seed 만 보고 조건 2 (inlier 근거) 는 보지 않는다 — 보존에는 근거가 필요 없다.
