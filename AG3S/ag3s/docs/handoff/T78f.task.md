# T78f — 쥘 때 target 주변 접촉 여유: 손 층에서 target 표본 M mm 안의 장애물을 지운다

> writer: lead (세션 A) · 작성: 2026-11-01 KST · 상태: **구현 지시 + 결과 전 고정.** 구현: ag3s-implementer 1 개. 재생 · closed-loop · 집계: lead.
> 다른 세션 dev-07 이 같은 방향 ("손 층에서 target 표면 근처만 지우기") 을 이쪽에 넘겼다 (2026-11-01, 그쪽은 손 대지 않음).

## 0. 사용자 판정 (2026-11-01)

- "분할에 상관없이 실제 물체를 쥘 때는 좀 더 여유 있게 접촉을 허용해 놓고 합시다."
- "ATS 를 통해서 이 정도 객체 분할 성능을 보여 준다는 설명을 하고, 실제 데모 · 실험에서는 타겟에 대한 접촉 허용을 여유 있게 주는 방향으로 합시다."
- 목적: 타겟의 제거되지 않은 점과 충돌이 일어나지 않게 한다.
- 시나리오 가정: 실험은 "target 으로 가는 길의 장애물 피하기 · 물체를 집은 뒤 장애물 만나기" 다. target 을 집는 순간에는 장애물을 마주하지 않는다.

## 1. 근거

- 손가락 접촉 영역 (정답 쥠 순간 손가락–사과 접촉점 10 mm) 에 남은 사과는 표면 방식에서 중앙 0.09 · 평균 0.15, 공 방식에서 0 · 0.055 다 (T78c §7).
- 원인은 누적 표본 기억에서 "다른 표면" 표본이 더 가까운 옛 표면 · 후보 밖 · 손가락 mask 누락 pixel 이다 (T78c 진단, T78e).
- T78e (target 유지 기억) 는 중앙을 0 으로 만들었지만 평균은 0.116 으로 남는다.
- 지금 지우기 규칙 (`fields/curobo_builder.oracle_visible_split`) 은 seed 마다 가장 가까운 target 표본 (d_t) 과 다른 표본 (d_o) 을 비교해 d_t < d_o 일 때만 지운다. 그래서 target 근처의 애매한 seed 는 남는다.

## 2. 구현 (기본 꺼짐 flag, 꺼짐 = 지금과 bit 동일)

- `--surface-contact-allowance-mm M` (`esdf.surface_contact_allowance_mm: Optional[float] = None`).
  - 필요한 것: `--target-extent attention-surface`, `--surface-keep-last`.
  - 범위: 0 < M ≤ 후보 거리 (`oracle_max_dist_voxels` × fine voxel, 지금 30 mm). 넘으면 거절한다.
- `oracle_visible_split` 의 "표면" 길을 바꾼다.
  - 켜면: seed 중 d_t ≤ M 이고 지지면 guard (`z_floor`) 위인 것을 **d_o 와 상관없이** 지운다.
  - 지금 규칙 (d_t ≤ max_dist 이고 d_t < d_o) 으로 지워지는 것은 그대로 지운다 (합집합).
  - 띠 길 · hull 채우기 · 지지면 guard 는 바꾸지 않는다.
  - 부호 교정 후보 (`sign`) 에도 같은 seed 를 넣는다 (지금 표면 길과 같은 처리).
- 기록 (`target_exclusion.oracle` 아래 읽을 수 있는 JSON 위치):
  - `allowance_mm`.
  - 이번에 allowance 로만 더 지운 seed 수 (`n_allowance_extra`).
  - `esdf_stats.target_free` 는 chunk summary 에 문자열로 남으니 거기에 두지 않는다.
- 꺼짐 증명 test: 함수를 켜면 터지게 바꾸는 방식 (T78b · T78d 와 같음).

## 3. 평가 (결과 전 고정)

### 3.1 재생 (같은 487 요청, 독점 GPU lock)

- 구성:
  - S9 = S5 (T78 S2 − `--surface-split` + `--surface-hull-fill`) + `--surface-contact-allowance-mm 10`.
  - S10 = 같은 구성 + 15.
- 비교: 공 방식 · S5 · S7 (T78e).
- 주 구간: 떨어진 장면 쥐기 직전 (정답 pick · 쥐는 손바닥 ≤ 80 mm) 이다. 손가락 접촉 지표는 T78c §7 정의 (27 요청) 를 쓴다.
- 통과 (모두):
  1. 손가락 접촉 영역 잔여: 중앙 0 이고 평균 ≤ 공 방식 (0.055).
  2. 떨어진 장면 쥐기 직전에 지운 이웃 과일 · 장애물 · 바구니 voxel ≤ 공 방식 (29).
  3. 떨어진 장면 쥐기 직전에 지운 탁자 voxel ≤ 공 방식.
- 보고만:
  - 지운 voxel 의 정답 분류 (사과 · 이웃 · 탁자 · 로봇 · 없음).
  - 맞닿은 장면 같은 지표.
  - 표면 단계 시간.
  - 허들 850 (이웃 약 20 mm) 의 이웃 voxel.
- 두 M 이 모두 통과하면 작은 쪽 (10) 을 쓴다. 15 만 통과하면 15 를 쓴다. 둘 다 미통과면 숫자를 보고하고 멈춘다.

### 3.2 closed-loop (3.1 통과 뒤, 같은 10 run)

- 구성: 3.1 에서 고른 M. 비교 기준은 T74 Q1 (공 방식, 성공 8 / 10 · 금지 접촉 0 · 탁자 · 바구니 0) 이다.
- 통과 조건 (T78 §3.2 와 같음):
  - 금지 접촉 없는 성공 ≥ 7 / 10.
  - 금지 접촉 ≤ 1.
  - 탁자 · 바구니 접촉 0.
- 실패마다 원인 층 (ATS · HSR · LTE · CCR) 을 적는다.
