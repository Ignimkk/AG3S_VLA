1. **L8H2 유지. HSR 은 보조 구성 요소.** L12H4 가 우월하다거나 HSR 이 instruction 기반 단계 판단을 한다고 주장하지 않는다.
2. **장면 1800 실패 원인을 먼저 분석한다:** 명사 identity 판정 · 3D seed · 영역 확장 중 어디서 오류가 시작되는가 → T52.
3. **grounding 비교:** action 단독 (L8H2) / 명사 단독 / **명사로 identity 판정 + L8H2 로 3D seed**. L12H4 결합은 추가 ablation 으로만 한다.
   평가 지표는 identity, purity · coverage, 이웃 물체 혼입, 전체 처리 시간이다. **중심 거리만으로 성공을 판정하지 않는다** → T54.
4. **작업 의도와 실제 grasp 상태를 분리한다.** 잡은 뒤에도 apple 을 찾는 것은 grounding 성능이지 basket 단계 전환의 증거가 아니다.
   다음 조건에서 phase feature 와 `grasp_latch` strong rule 을 비교한다: 동일 이미지에서 instruction 변경, 비슷한 gripper 자세에서 물체 보유 여부 변경, empty grasp · slip.
   **strong rule 을 정답으로 쓰지 않는다** (정답 = 물리 predicate) → T55.
5. **self label 은 실제 품질을 예측하도록** 개선한다. 동률을 허용한다. 지표 개발에 GT 를 썼으면 완전한 label-free 와 구분한다 → T56.
6. **수정에 쓰지 않은 장면 · episode 에서 검증한다** (T53 의 16 episode). 연속 frame 상관을 반영한 불확실성 (episode / scene block bootstrap) 을 보고한다.
7. **offline 개선이 확인된 후보만 closed-loop** 에서 작업 성공 · 비허용 접촉 감소로 연결되는지 확인한다 → T57.
8. 완료 후 **채택 · 유지 · 기각 판단과 근거, 논문에서 주장 가능한 범위** 를 간결하게 보고한다.

- **최종 실패만** 보면 오류의 첫 단계는 거의 모두 seed 다 (장면 1800: L8H2 4 · L8H6 7 · L10H7 8 frame, 그중 2 frame 은 보이는 camera 가 없음). region 단계가 처음인 실패는 없다. 단 장면 1800 의 모든 실패에서 region flag 도 켜져 있다.

- **병합 기전이 측정으로 확인됐다** (장면 1800, `headfix`):
  - split trigger 와 15 mm 재군집은 세 source 모두 15/15 에서 동작했다.
  - 차이는 **attention 비율 ≥ 2 조건** 이다: L8H6 7/15 (median 1.91), L10H7 10/15 (2.29), **L8H2 15/15 (4.49)**.
  - → 명사 map 은 target 과 이웃에 고르게 퍼져 split 이 거부되고, 병합 cluster 가 남는다. L8H2 도 split 전 cluster 에는 바나나가 15/15 frame 섞여 있었지만 split 으로 분리됐다.
- **새로 드러난 사실:** L8H2 의 2D peak 가 target 밖인 14 frame (대부분 grasp 구간) 에서 3D 가 맞은 것은, **현재 frame attention 이 아니라 이전 frame 에서 확정한 target geometry 를 유지했기 때문** 이다 (`TargetConfirm`, 13/14). 3D peak 는 14/14 가 support 위였다.
  → T54 는 "현재 frame 만" 과 "시간 유지 포함" 을 나눠 평가해야 한다. 그렇지 않으면 attention source 의 효과와 temporal latch 의 효과가 섞인다.
- **T54 설계 근거:** 명사 = identity (2D identity 실패 0), L8H2 = seed · split ratio. 조합 arm 의 정의를 사전 고정할 때 split 에 쓰는 attention 이 어느 map 인지 명시한다.
