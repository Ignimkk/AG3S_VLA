## 무엇을 했나 (평이한 요약 먼저)

T47 의 run 을 그대로 다시 쓰는 study 하나를 새 파일로 만들었다. 이 study 는 네 가지 일을 한다.
(1) **B1:** 같은 head set 을 합치는 방식 세 가지 (`raw_sum` · `mass_norm_joint` · `mass_norm_per_camera`) 를
**GT-oracle top-3 · camera 별 top-3 · head-average** 에 적용한다. T47 이 실패한 공통 top-3 는 `raw_sum` 한 줄만
참고로 남겼다. (2) **B2:** chosen cluster 의 점마다 GT label 을 읽어 `identity_correct` · purity · target 잔여 ·
non-target 손실을 frame 별로 남기고, **record 단위**로 집계한다. (3) **B3:** attention 이 lifting 에서 grounding 까지
가는 길에서 값을 비교하는 곳 24 곳을 file:line 표로 만들고, 같은 frame 에 map 과 `k × map` 을 넣어 grounding 이
같은지 재는 수치 시험을 만들었다. (4) **#5 sink 진단:** 128 cell × camera 마다 "늘 같은 patch 에 몰리는가" 와
"넓은 한 덩어리인가" 를 가르는 다섯 수치를 모든 record · frame 에서 잰다.
head set 은 **T47 의 `select/selection.json` 과 `validate/oracle.json` 에서 읽기만 한다** (다시 고르지 않는다).
기존 파일은 하나도 고치지 않았다. MuJoCo replay / GPU 는 실행하지 않았다 (`e2e` · `b3` 는 verifier 가 돌린다).

**B3 결론 (코드 읽기):** default 경로에서 **raw attention 의 크기에 절대값을 비교하는 곳은 numerical guard 하나뿐**이다 —
`attention_lifting.py:278` 의 `hi - lo <= 1e-12` (`_EPS`, `:33`). 이 guard 는 map 의 percentile 폭이 1e-12 이하일 때만
켜진다. threshold 들 (`seed_percentile` · score · switch 0.1 · split ratio 2.0) 은 모두 **정규화된** 값이나 그 값으로 만든
score, 또는 비율을 읽는다. 그래서 공통 상수배 (×k) 에는 불변이다 (k 가 2 의 거듭제곱이 아니면 float 반올림 차이는 난다).
**변하는 곳은 camera 간 상대 크기**다: `multiview.py:384` 의 raw max fusion 과 그 뒤 `:399` 의 fused 정규화,
`target_grounding.py:1672` 의 raw argmax peak 가 여기에 해당한다. 기본값이 아닌 설정 셋은 raw 크기에 직접 의존한다:
`normalization='softmax'` (temperature), `normalization='none'` (모든 threshold 가 raw 를 읽음),
`attention_split_ratio_source='raw'` 일 때의 `1e-12` guard.

## 정의

### B1 합산 방식 (`t47b_aggregation.py`)

입력은 T47 `source_maps` 의 `block_c` 와 같은 축이다: `(frame, camera, layer, head, 16, 16)`, d0 · last.

| 방식 | 식 (head `h` 의 raw map `A_h[c]`, camera `c`) | 지위 |
|---|---|---|
| `raw_sum` | `Σ_h G_σ(A_h[c])` (= T47 `combine_maps`) | 참고 (논문 합) |
| `mass_norm_joint` | `Σ_h G_σ(A_h[c] / Σ_{c'} ΣA_h[c'])` — head 마다 768 token 질량이 1. head 안에서 camera 간 비율은 유지 | **사전 선언 secondary (oracle top-3)** |
| `mass_norm_per_camera` | `Σ_h G_σ(A_h[c] / ΣA_h[c])` — (head, camera) 마다 질량이 1. camera 간 비율은 사라짐 | exploratory |

- `G_σ` 는 T47 의 `gaussian_smooth` (reflect, 질량 보존) 다. 정규화를 smoothing 앞에서 하든 뒤에서 하든 float 반올림 안에서 같다.
- 질량이 0 인 head (또는 head × camera) 는 0 을 더한다. 그 수는 `zero_mass_counts` 로 보고한다. 음수 attention 은 예외로 거절한다.
- **camera 별 head set** (`camera3_*`): camera c 의 map 은 `combine_heads(block, cells_c, σ, mode)[c]` 다.
  `mass_norm_joint` 일 때 head 는 **세 camera 전체 질량**으로 나눈다 (그 head 의 c map 만 쓰더라도).
  `raw_sum` 은 T47 `topk_camera` 와 bit 단위로 같다.
- **head-average** (`headavg_*`): L2–17 의 128 cell 평균이다. `raw_sum` 은 T47 `head_average` 그대로이고 σ 를 적용한다.
  mass 모드는 cell 마다 질량을 1 로 만든 뒤 평균한다.
- σ 기본값은 **1** 이다 (T47 사전 고정). `--sigma 0` 이면 T47 e2e 와 같은 map 이 나온다 (아래 "T47 e2e 의 σ").

### B2 (`t47b_metrics.py`, frame 별 → record 별)

점 label 은 T47 e2e 와 같은 labeller 다 (`exclusion_e2.label_classes` `:221-237` + `gt_points` + `point_labeler` `:356`,
세 camera GT depth 점 중 3 mm 안의 최근접 점의 label). 이름만 바꿨다: `distractor → other_object`, `support → table`.
`robot` 에는 gripper 가 들어 있다 (`is_robot_body`). shelf · 바닥은 `other` 다.

`T_obs` 는 filtered cloud 에서 label 이 target 이고 support mask 밖인 점이다 (T47 seed recall 의 분모 `n_cloud_t` 와 같다).
세 층 X:

| 층 | X | 근거 |
|---|---|---|
| `cluster` (**주 지표**) | chosen cluster = `ConstraintSet.target.point_indices`. index 가 이 cloud 를 가리키지 않으면 (occluded · anchor) 5 mm proximity 로 대신하고 `chosen_membership` 에 기록 | exclusion ball / target-free layer 가 만들어지는 기하 (`pipeline.py:2598` `_target_ball(target_free_points, …)`) |
| `seed` | `GroundingResult.seed_indices` (attention seed) | T47 seed precision/recall 이 읽는 것 (`target_grounding.py:1679-1682`) |
| `ball` | cloud 점 중 `|p − centre| ≤ radius ∧ p_z ≥ z_min`. ball 은 `AG3S._target_ball(target.points, support_surfaces, voxel=0.005)` | T13 ball 이 점 수준에서 지우는 범위. offline AG3S (legacy ESDF) 는 실제로 파내지 않으므로 **사후 계산** |

| 지표 | 정의 |
|---|---|
| `identity_correct` | chosen cluster 의 **label 이 있는** 점 (`unlabelled` 제외) 에서 class 별 개수가 **엄격히 가장 많은** class 가 target 인가. 동점이면 거짓이다. target 이 없으면 거짓이다 |
| `chosen_cluster_purity` | target 점 ÷ cluster 의 모든 점 (`unlabelled` 도 분모에 넣는다). target 이 없으면 NaN |
| `chosen__<class>` | cluster 안 class 별 점 수 (other_object · table · destination · robot · other · shared · unlabelled) |
| `target_residual_n` / `_rate` | `|T_obs \ X|` 와 그것을 `|T_obs|` 로 나눈 값 (`T_obs` 가 비면 NaN). target 이 없으면 관측된 target 점이 전부 남는다 |
| `nontarget_seed_loss` (`__<class>`) | X 에 든, label 이 있는 non-target 점 (other_object · destination · robot · table · other · shared). 대표 class 는 `other_object` |
| `seed_*` · `ball_*` | 같은 지표를 seed · ball 층에서 |

**record 집계** (`record_level` · `summarize`): record 안에서는 frame 을 모은다 (비율은 frame 수로, 잔여 비율은
`Σ 잔여 ÷ Σ T_obs`). record 마다 값 하나를 내고, record 들의 **가중 없는 평균** (`record_mean`) 과 최소 · 최대 ·
per-record 값을 낸다. strata 는 `all` · `scene=same_scene|new_scene|selection` · `phase=pre_grasp|post_grasp` 와
그 교차다. post_grasp 는 `phase_for == "grasp"` 인 frame 이다 (t_step ≥ grasp 경계; transit · approach · pre_grasp 는 pre).
`on_target` 과 `identity_correct` 가 갈리는 수는 `on_target_not_identity` · `identity_not_on_target` 로 따로 센다.
`identity_failure_rate` 는 `has_target ∧ ¬identity_correct` 이다 (silent failure 의 label 판).

### T44 "distractor seed loss" 와의 대조 — **같은 정의가 아니다**

| | T44 `distractor_seeds_lost` | T47b `nontarget_seed_loss__other_object` |
|---|---|---|
| 무엇의 "seed" | **TSDF/ESDF 표면 seed voxel** (cuRobo fine layer 5 mm). ROI = ball + shell (`exclusion_e2.py:536` `roi_seeds`, `:731`) | **cloud 점** (grounding 이 쓴 fused filtered cloud) |
| label | voxel 다수결이다 (depth 점 + **mesh 전체 표면** + 과일 hull; 80 % 미만이면 `shared`) (`:732` `voxel_labels`) | 점마다 최근접 GT depth 점 (3 mm) 의 label 이다. mesh 와 hull 은 쓰지 않는다 |
| "빠지는" 것 | exclusion 방식 (`ball` · `ball_owned` · oracle) 이 target-free tier 에서 실제로 지운 seed (`:744` `exclusion_trace.removed_ijk`) | X 에 든 점: cluster (주) · seed · ball |
| identity | 대개 GT 로 강제한다 (`--identity gt`/`gt_label`, `choose_identity` `:376`) | **pipeline 이 고른 그대로** (VLA attention source 별) |
| 실행 | `.venv-openpi-live` + GPU (cuRobo) | CPU, legacy ESDF (ball 은 사후 계산) |
| 줄 | `exclusion_e2.py:758` `dis = labels == distractor`, `:765` `distractor_seeds_lost = (removed & dis).sum()` | `t47b_metrics.py:168` `frame_b2` |

가장 가까운 것은 T47b 의 **`ball` 층** (`ball__other_object`) 과 T44 의 `ball` 방식이다. 둘 다 같은 `_target_ball` 로 공을
만들고 z_min 위를 지운다. 그래도 단위 (cloud 점 대 5 mm TSDF seed voxel) 와 label 방식 (depth 최근접 대 depth+mesh+hull
다수결) 이 다르다. 그래서 **숫자를 직접 비교하지 않는다.** T47b 지표는 identity 를 바꾸는 attention source 사이의 비교용이다.

## B3 — raw amplitude 점검표

열의 뜻: **×k** = 모든 camera 를 같은 k > 0 배 (같은 head set 의 합 대 평균). **camera 별** = camera c 를 k_c 배
(`mass_norm_per_camera` 가 camera 간 비율에 하는 일). **head 재가중** = map 의 모양 자체가 바뀜.
"(float)" 은 실수 연산에서는 불변이지만, float32 곱셈이 k 가 2 의 거듭제곱일 때만 정확하므로 마지막 bit 가 다를 수 있다는 뜻이다.
"(퇴화만)" 은 절대 상수가 있지만 실제 값 범위에서는 켜지지 않는다는 뜻이다. 줄 번호는 2026-10-12 working tree 기준이다
(T46 의 uncommitted 변경 포함). `--stage audit` 가 지금 줄을 다시 찾아 `moved` 를 표시한다.

읽는 법:
- **default 경로에서 raw 크기에 절대값을 비교하는 곳은 L3 하나다.** L3 는 퇴화 guard 다. 16×16 softmax mass map 의
  percentile 폭은 1e-12 보다 훨씬 크므로, 상수 map (어느 배율에서든 0 이 됨) 이 아니면 켜지지 않는다.
- **G8 · D1 의 0.1 은 절대 threshold 이지만 raw 가 아니라 score 에 걸린다.** score 는 정규화 attention 으로 만든다 (G5).
  그래서 ×k 에는 불변이지만, head 재가중으로 정규화 분포의 모양이 바뀌면 score 의 수준이 움직이고 이 threshold 를 넘는지가 달라질 수 있다.
  head set 을 바꿀 때 다시 볼 곳이 여기다.
- **camera 간 상대 크기는 M2 → (M3, G2) 로 들어간다.** raw 합은 head 들이 camera 마다 질량을 다르게 나누므로 이 비율을 바꾼다.
  `mass_norm_per_camera` 는 그 비율을 없앤다. unit test `test_fusion_common_scale_invariant_per_camera_scale_variant` 가
  이것을 실제 `fuse` + `ground_target` 로 보인다: camera B 만 ×2 하면 target 이 다른 물체로 바뀐다. 공통 ×4 는 bit 단위로 같다.
- **수치 시험은 ×3 과 ×4 를 함께 돈다.** ×4 는 float 에서 정확한 대조군이라 bit-identical 이어야 한다.
  ×3 은 L1 · L4 의 float32 반올림 때문에 정규화 값의 마지막 bit 가 다를 수 있다. 그래서 출력은
  **`decision_identical`** (cloud · seed · peak · cluster 분할 · split 사유 · status · chosen) 과 **`bit_identical`**
  (그에 더해 `raw == float32(k·raw)` · 정규화 값 · score · centroid 가 bit 단위로 같음) 을 따로 세고,
  처음 달라진 지점 (`first_difference`, 파이프라인 순서) 을 frame 마다 남긴다. frame 이 이어지는 상태 (TargetConfirm,
  다음 frame 의 self-filter guard) 때문에 한 frame 의 차이가 뒤 frame 으로 번질 수 있다. 그래서 `cloud_equal` 을 첫 항목으로 둔다.
