## 무엇을 했나 (평이한 요약 먼저)

표본 기억 (`OracleMemory`) 은 2.5 mm 칸마다 표본 하나를 들고, 지금까지는 칸마다 **이번 frame 의 표본이 이긴다** (newest wins).
그래서 손이 사과 옆면을 가린 뒤 나중 frame 이 같은 칸을 "다른 표면 · 다른 물체" 로 보면 target 표본이 지워졌다 (T78c §7 진단 2).
새 flag `--surface-memory-target-sticky` 를 켜면 **한 번 target (code 1) 인 칸은 깎이기 전까지 target 표본 (위치 · code · frame) 을 유지** 한다.
나머지 병합은 그대로다. 깎기 (`_carve`, 광선이 표본 너머를 봄) 는 sticky target 표본도 지운다. 기본은 꺼짐이며, 꺼짐이면 지금과 bit 동일하다.
