## 2. 선택 protocol (T61 사전 고정이 정본, 여기서는 옮겨 적지 않고 항목만)

| 항목 | 내용 | 출처 |
|---|---|---|
| 입력 | prefix pass 의 attention (3 camera), action query (`last` · `mean` · `first`, denoise 0) + 명사 query (`noun_target`) × L2–17 × 8 head = 512 cell | `T61.task.md` "후보 집합 Ω" |
| label | 선택 (calibration) = sim GT `identity_correct`. 실물에서 GT 가 없을 때의 대체 = self label (T56, 유효성은 T56 결과에 따른다) | T61 · T56 |
| calibration data | `t2` · `ep1807` · `ep0` · `ep500` · `ep1200` (ep0 · 500 · 1200 = VLA 학습 episode, 일반화로 주장하지 않음). `long` · `ep1800` 은 입력 배선 문제 (X2 수정 전 head 0 녹화) 로 제외 | T61 판정 2 |
| 평가 창 | P (T60 placement 완료까지). 미도달 record 는 전체 | T61 |
| 단계 | P1 filter (label 없음, threshold 고정) → query 별 2D lift 상위 6 → 3D GT 순위 → k ∈ {1,2,3} 를 leave-one-scene-out CV one-SE 로 → 5 scene 전체 순위의 상위 k 합 | T61 |
| 선택 단위 | **query · denoise · aggregation · layer · head 전체** (예: `mean:L10H7` 이면 serving 도 mean) | T61 판정 4 |
| 실행 중 고정 | 선택 구성을 `T61.selection.json` (sha256) 으로 저장한 뒤 serving 에 고정, episode 중 바꾸지 않는다. 서빙 구현 · parity · closed-loop 은 별도 STEP (A) | T61 "serving 고정" |
| 보고만 | scene bootstrap 1 위 확률, query 별 최선, self label 선택, nested CV 점수 | T61 |

## 5. 적용 한계 (결과와 함께 갱신)

- calibration 5 scene → CV SE 가 크고 one-SE 가 작은 k 를 고르기 쉽다.
- held-out 에 (apple, left) 가 없다. 과일 × 팔로 일반화하지 않는다.
- 선택 label 은 sim GT 다. 실물에서 GT 없이 다시 고르려면 T56 의 self-label 결과가 유효한 범위 (cell · arm 중 어디) 안에서만 쓴다.
- "유의한 차이 없음" 을 동등성 입증으로 쓰지 않는다. 차이 · CI · 실패 양상 · 추가 비용 (명사 query 는 추가 prefix 연산) 을 함께 적는다.
