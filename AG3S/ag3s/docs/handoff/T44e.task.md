## A8 — coarse target-free 에서 support seed 제외 (implementer)

**측정 근거 (`T44dA.verify.json` Q1):** finger 최악 행이 `target_free_coarse` 인 chunk 50/72, 그 행의 88 % 가 support 위 20 mm 이내, distractor 20 mm 이내는 16 %.
target-free 거리의 zero level 이 ball 중심 아래에서 0 → 11.5 mm 로 올라가 TO 가 손을 들었다 (중앙 2.0 mm, C1b 가 7/7 짝에서 +1.7~+26.4 mm 높게 잡음).

**구현:**
1. Config `esdf.target_free_coarse_support: str = "keep"` (`"keep"` = A5–A7 그대로 / `"exclude"` = coarse target-free tier 를 만들 때 support seed 를 넣지 않음). CLI `--target-free-coarse-support {keep,exclude}`.
   **기본값 결정은 측정 뒤** — 우선 `keep` 기본 (bit-identical) 으로 두고, arm 은 명시 flag 로.
2. support seed 의 정의는 이미 있는 것을 재사용 (`support_mask` / support plane · `_support_plane_z` — 어느 것을 썼는지 `파일:줄`).
   table 외의 정적 장애물 (crate 등) 과 distractor seed 는 그대로 남긴다.
3. 합성식 `min(f, static, max(c, d), max(d, b))` 은 유지. `c` 에 table 이 없으므로 table 은 `f` (fine) 와 창 밖 `d` 가 답한다. 창 밖 · fine 미관측 table 영역에서
   **덜 보수적이 되는 점이 생기는지**를 harness 로 확인 (성질 `min(old, d) ≤ new ≤ old` 의 `old` = coarse off 기준) — 생기면 그 위치와 크기를 impl.md 에.
4. sign floor (`plane`) 와의 관계: support seed 를 뺐을 때 plane sign floor 가 여전히 필요한지 판단하고 근거를 적는다 (바꾸지 말고 측정으로).

## A9 — 비권한 link 의 target margin = 일반 obstacle margin (implementer, 같은 agent)

**측정 근거 (`T44dA` Q2):** `ClearancePolicy.lookup` (`ag3s/constraints/clearance.py:247-253`) 은 권한 없는 link 에 `full_margin(TARGET)` (= `safety_margin` 0.05 m) 을 준다.
`--links arms` 에서 `link_*_arm_5` 가 153 chunk / 17 run 에서 최악 행, 손–target 최소 거리 ≥ 50.4 mm.

**구현:**
1. Config `contact.nonauthorized_target_margin: str = "full"` (`"full"` = 지금 / `"obstacle"` = 일반 obstacle 행이 실제로 받는 clearance 와 같게). CLI `--nonauthorized-target-margin {full,obstacle}`.
2. "일반 obstacle 행이 실제로 받는 clearance" 를 **활성 설정에서 코드로 확인**해 같은 값을 쓴다 (V11AB: `--esdf-margin 0` + trajopt `--obstacle-margin 0.010` 이 obstacle 행에 붙는 경로 — `linearize._obstacle_rows` 등). AG3S margin matrix 값과 trajopt 의 obstacle_margin 이 어떻게 합쳐지는지 `파일:줄` 로 적고, target 행이 obstacle 행과 **같은 최종 clearance** 를 받게 한다 (이중 적용 · 누락 없이).
3. 권한 link 의 phase margin, I2/I2b strict 권한, carry 규칙은 바꾸지 않는다. 접촉 금지는 유지 (`allowed_contact` 의 `unauthorized_link`).
4. `--links gripper` (V11AB) 에서는 비권한 행이 반대손 gripper 뿐 — 그 영향도 test/기록으로.

**Tests (A8 · A9):** off/기본 bit-identical · support seed 가 coarse tier 에 없음 · table 위 finger 행의 target-free 거리 회복 (synthetic) · distractor 내부 음수 유지 ·
비권한 link target margin = obstacle 행 clearance (gripper / arms 모델) · `allowed_contact` 불변 · config/CLI 왕복. 전체 pytest (CPU env, worker ≤ 2).

**산출물:** `T44e.impl.md`. harness smoke (demo 64 frame 일부) 로 table band · grasp 직전 차단 · distractor 내부 숫자.

## A8b — 이웃 과일 아래 support 만 남기는 변형 (implementer, 2026-10-11 추가)

**사용자 판정 (2026-10-11):** "이웃 과일 아래 support 만 남김". A8 smoke (`T44e.impl.md`): exclude 는 zero level 8 → 3 mm, grasp 직전 차단 59/10 → 46/4 로 좋아졌지만
distractor 내부 ≥ margin frame 이 17 → 32 (늘어난 몫 전부 support 위 0–15 mm 띠).

- `target_free_coarse_support` 에 값 추가 (예: `"exclude_target"`): coarse target-free tier 에서 **target 아래 (target ball / target evidence 의 xy 발자국 아래) 의
  support seed 만 빼고**, non-target evidence (이웃 과일 · 기타 물체) 발자국 아래와 그 밖의 support seed 는 남긴다. 발자국 정의는 metre 로 (coarse voxel 에 맞춰
  dilation 근거를 적는다). target 과 non-target 발자국이 겹치는 support voxel 은 **남긴다** (obstacle evidence 보존 — 판정 1 조건 4 와 같은 원칙).
- 기존 `keep` / `exclude` 는 그대로 (비교용). 기본 `keep` bit-identical.
- smoke: A8 과 같은 표 (TA band · zero level · grasp 직전 차단 · distractor 내부 frame · 성질 위반) 를 keep / exclude / exclude_target / off 로.
- 같은 agent 가 `curobo_builder.py` 를 만진다 — T45 A10 (palm cover) implementer 는 그 파일을 건드리지 않는다.
