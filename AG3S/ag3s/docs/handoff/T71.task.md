## 0. 왜

- T70 (쥐기 전 꺾임 변화율 · 연속성 끔) 은 세 구성 모두 미통과였다: 최종 구성 2 / 8 → E1 3 · E2 3 · E3 4 (금지 접촉 3 · 0 · 1).
- T67 · T70 모두 같은 양상이다: 바꾼 구성이 실패 run 의 절반쯤을 살리고, 원래 성공하던 run (회귀 119 흔들림 1 등) 이나 접촉 없던 run 을 새로 잃는다.
- 이 "새로 잃음" 이 구성 탓인지, **같은 구성을 다시 돌려도 생기는 흔들림** (TrajOpt 시간 예산 50 ms · GPU 여러 초기값 · 실행 시점) 인지 아직 재지 않았다. VLA 는 같은 seed 면 bit 동일하지만 TrajOpt 는 아니다.
- 그래서 T71 은 **최종 구성 재실행을 대조군**으로 넣고, 단계별 (쥐기 전 / 쥔 뒤) 목적함수 조합을 기존 flag 만으로 시험한다.

## 1. 단계와 항

- 단계 구분 = grasp latch: **쥐기 전** (searching · latched · closing) / **쥔 뒤** (held: 들기 · 운반 · 놓기). 기존 flag 의 기준과 같다.
- 항: 꺾임 변화율 (B, 무게 20) · 연속성 (C, 무게 0.5). 나머지 항 (VLA 추종 1.0 · 부드러움 0.05 · 손목 추종 0.1 배 · 충돌 slack) 은 그대로.
- 기존 flag 로 만들 수 있는 조합: 각 항을 "모두 켬" · "쥐기 전만 끔 (`--*-after-grasp`)" · "모두 끔 (`--w-* 0`)". 쥐기 전에만 켜는 조합은 구현이 필요해 뺀다.

## 2. 구성 (4 개, 구현 없음)

| 구성 | 쥐기 전 B · C | 쥔 뒤 B · C | 최종 구성 서버 인자에 더하는 것 |
|---|---|---|---|
| **R0 대조군** | 켬 · 켬 | 켬 · 켬 | — (최종 구성 그대로 다시 돌림) |
| **R1** (= T70 E3 재실행) | 끔 · 끔 | 켬 · 켬 | `--deflection-rate-after-grasp --continuity-after-grasp` |
| **R2** | 끔 · 끔 | **끔** · 켬 | `--w-deflection-rate 0 --continuity-after-grasp` |
| **R3** | 끔 · 끔 | **끔 · 끔** | `--w-deflection-rate 0 --w-continuity 0` |

- R1 → R2 → R3 은 쥔 뒤 (운반 · 놓기) 에서 이력 항을 하나씩 더 뺀다. 쥔 뒤 단계에서 그 항이 허들 회피를 돕는지 해치는지 본다.

## 3. 장면 (10 run, 같은 장면 · seed)

| 종류 | run | 최종 구성 기록 |
|---|---|---|
| 쥐기 실패 6 (T70 과 같음) | 회귀 211 흔들림 없음 · 회귀 954 흔들림 없음 · 가림 122 흔들림 없음 · 허들 954 · 1345 · 211 흔들림 없음 | 실패 |
| 성공 유지 4 | 가림 121 흔들림 없음 · 회귀 119 흔들림 1 (T70 과 같음) · **허들 119 흔들림 없음 · 허들 850 흔들림 없음** (운반 중 허들 회피가 있는 성공 run) | 성공 |

- 4 구성 × 10 run = **40 run** (2 서버, 약 80 분). 회귀 kit 은 T70 의 kit 을 쓴다 (금지 flag 목록 · 로그 검사 · `bash -n` 을 띄우기 전에 확인).

## 4. 판정 (결과 전 고정)

- 주 지표: 금지 접촉 없는 성공 (T67 §4 정의, 허들 장면은 이웃 과일 재생 접촉 포함).
- **흔들림 크기** f = R0 에서 결과 (금지 접촉 없는 성공 여부) 가 최종 구성 기록과 달라진 run 수 (10 중).
- **통과 (R1 · R2 · R3 각각):**
  1. 금지 접촉 없는 성공 ≥ R0 의 값 + max(2, f + 1)
  2. 금지 접촉 run ≤ R0 의 값
  3. R0 에서 성공한 "성공 유지 4" run 을 잃지 않음
- 여럿 통과하면 성공이 많은 쪽, 차이 ≤ 1 이면 바꾼 것이 적은 쪽 (R1 > R2 > R3).
- 통과한 구성은 전체 32 run 으로 확인한다. 채택 (모두 충족): ≥ 23 / 32 · 금지 접촉 run ≤ 3 · 탁자 · 바구니 접촉 0 · 9 장면 ≥ 14 · 허들 ≥ 6.
- **f ≥ 3 이면** (같은 구성 재실행에서 10 중 3 run 이상 결과가 바뀌면) 단일 run 비교로는 구성 효과를 판정할 수 없다고 보고하고, 장면당 반복 (예: 3 회) 설계를 사용자에게 묻는다. 이때는 32 run 확인을 하지 않는다.
