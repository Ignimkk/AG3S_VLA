## 0. 근거 (T78 재생 기록, `outputs/2026-10-31_T78_표면추출_보정_GPU_재생평가/README.md`)

  - 전체 63 % (공 방식 77 %).
  - 맞닿은 장면 34 % (공 방식 50 %).
- 원인 1: 분할이 사과 표면 조각을 버린다.
  - 회귀 211 요청 15 에서 합쳐진 영역이 사과 355 점 · 바나나 236 점 · 작은 조각 38 점으로 나뉘었다.
  - 작은 조각은 중심이 사과 중심에서 약 35 mm 인 사과 표면이었는데, attention 이 낮아 버려졌다.
  - 손목 카메라에서 못 지운 사과 pixel 178 중 85 가 이 경우다.
- 원인 2: 보인 표면만 지운다. 보이지 않는 안쪽 · 뒷면과 앞선 요청의 "사과 아님" 기억이 남는다.
- 남은 사과는 손이 읽는 거리장에서 장애물이 된다.
  - closed-loop 회귀 211 · 허들 1345 에서 쥐기 직전 가장 큰 위반 지점이 사과였던 요청은 31 / 55 · 40 / 54 다.

## 1. 구현 (기본 꺼짐 flag, 꺼짐 = snapshot_t78 과 bit 동일)

1. **조각 다시 붙이기** (`--surface-reattach-hull MM`, 예: 10):
   - 분할이 target 덩어리를 고른 뒤, 버리려는 다른 덩어리의 중심이 target 덩어리 convex hull 을 MM 만큼 넓힌 부피 안에 있으면 target 에 다시 붙인다.
   - hull 밖에 따로 크기를 가진 덩어리 (바나나) 만 버린다.
   - 기록: 덩어리마다 붙임 / 버림과 hull 까지 거리.
2. **쥐기 직전 표면 경계 안 지우기** (`--surface-hull-fill`):
   - 쥐기 직전 구간에서 손 층 (미세 target-free 계층) 의 voxel 중 채택된 표면 영역 점의 convex hull (+1 voxel) 안에 있는 것을 모두 지운다.
     - 쥐기 직전 구간 = grasp latch 가 latched · closing 이거나, 쥐는 손바닥이 영역 중심 80 mm 안이다.
     - 쥐는 중 고정 구간 (A4) 에서는 마지막 채택 영역의 hull 을 쓴다.
   - 지우지 않는 것:
     - 분할에서 버린 덩어리 (hull 밖 다른 물체) 의 표본이 있는 voxel.
     - 지지면 + 5 mm 아래 (지금 A5 와 같은 guard).
   - 공은 쓰지 않는다.
   - 기록: hull 부피 · 추가로 지운 voxel 수 · 적용 여부와 이유.

## 2. 평가 — T76 · T78 과 같은 고정 입력 재생 (T74 Q1 기록 487 요청)

- 구성 S4 = 표면 + T78 보정 + GPU (S2) + 위 두 flag.
- 비교: 공 방식 (T76 BALL), S2 (T78).
- 지표: 제거 품질 (`t78_removal_quality` 정의).

  - 정밀도.
  - 이웃 과일 · 다른 물체를 지운 voxel.

### 판정 (결과 전 고정)

- **주 구간 = 쥐기 직전 요청:** 정답 단계 pick 이고 쥐는 손바닥이 사과 중심 80 mm 안인 요청.
- 통과 (모두):
  1. 사과를 지운 비율 (중앙) ≥ 공 방식.
  2. 이웃 과일 · 다른 물체를 지운 voxel ≤ S2 × 1.1.
  3. 정밀도 ≥ 95 %.
- 보조 (보고만):
