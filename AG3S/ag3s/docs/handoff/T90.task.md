## 1. 구현 (기본 꺼짐, 꺼짐 = 지금과 bit 동일)
1. **probe asset 내보내기:** `AG3S/ag3s/experiments/studies/t86_probe.py` 에 `--export NPZ` (기본 없음): T86 의 train 교차 검증으로 고른 설정 (카메라별 layer · C · raw/centred — head L8 raw, 왼손목 L12 raw, 오른손목 L8 raw; `t86_probe.json` `cameras.*.selected.raw`) 으로 train 전체에 다시 맞춘 표준화 평균 · 표준편차 · 계수 · 절편을 카메라별로 저장. asset 은 `AG3S/ag3s/asset/target_probe/t86_hidden_probe.npz` (+ `.json`: 출처 run · md5 · 설정).
2. **serving:** 새 attention source `--attention-source hidden_probe[:NPZ]` (기존 `noun_target:L10H7` 와 같은 자리, `AG3S/trajopt/attention_source.py` · `serve_safe.py`). 켜면 요청마다 VLA prefix forward 에서 카메라 3 대 image token 의 hidden (카메라별 layer) 을 꺼내 probe 점수 (로지스틱 logit 또는 확률) 를 patch 지도 16 × 16 × 3 으로 만들고, 지금 명사 attention 지도가 들어가는 곳에 그대로 넣는다 (뒤의 percentile 정규화 · seed · cluster · 표면 추출은 그대로).
   - hidden 은 `--hsr5` 가 이미 같은 forward 에서 꺼내는 경로 (`pi05_hidden` · `hsr5.py`) 를 재사용하고, 추가 forward 를 만들지 않는다. 추가 시간을 요청마다 기록 (`attention_source.ms`).
   - prompt 의 target 명사를 못 찾는 경우의 동작은 지금과 같게 (target 없음) — probe 는 prompt 를 hidden 으로만 본다는 점을 기록에 남긴다.
3. **기록:** `summary_json.attention_source` 에 `spec = hidden_probe`, 카메라별 layer, asset md5, 최대 점수.
4. **test:** 꺼짐 bit 동일 · asset 로드 · 알려진 hidden 에서 점수 = offline `t86_probe` 점수 (같은 입력 같은 값) · `--hsr5` 와 함께 / 따로 둘 다 기동.
5. GPU smoke 1 run (shared lock), 요청당 추가 ms 를 impl 에 적는다. 전체 closed-loop 은 lead.
