## 구현 (→ T46 세션, 사용자 판정: 서빙 코드는 T46 세션에 위임)

- policy server 에서 명사 attention 행 (`noun_target`, L10H7, raw σ0, k1) 을 추출해 AG3S 의 attention 입력으로 쓰는 **기본 off flag** 를 추가한다 (예: `--attention-source noun_L10H7`).
  - prompt 의 target 명사 token 위치를 찾는 방식은 T49 / `t49_noun_query_extract.lookup` 과 같다.
  - 추출은 서빙 policy 호출의 prefix pass 안에서 한다 (T53 noun parity 에서 sampler cache 와 bit 동일함을 확인했다).
- flag off 일 때 bit-identical: CL3 층 · wire digest · 회귀 기준선 (legacy · cuRobo).
- flag on 일 때 parity: T54c 기록 frame 몇 개에서, 서버가 낸 명사 map 이 `t54c_extract` 의 noun 추출과 같고 AG3S 결과가 `t54_arms` N 재생 행과 같아야 한다.
