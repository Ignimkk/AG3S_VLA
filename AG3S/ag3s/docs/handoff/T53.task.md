## 생성할 것 (rollout 후)

1. **action attention npz** — T47 형식 (denoise [0, 4, 9] × agg × 18 × 8 × 3 camera × 16 × 16, seed 0). `t51_extract` 경로 (`pi05_attention` CLI) 를 재사용한다.
2. **명사 attention** — T49 형식 (target 과일 · basket · last-text 행). `t49_noun_query_extract` / `t51b_noun_extract` 경로를 재사용한다.
3. **phase feature** — kv_L4 (HSR probe 입력, T48 경로). **명사 token feature** 도 함께 (T55 후보: 명사 token 의 hidden / V feature — 정의는 T55 task 에서 고정).
4. **GT cache** — T47 형식 (class · body coverage, label map, 물체 pose). CPU osmesa. 접촉 replay (`replay_contacts.py`) 로 frame 별 GT grasp 상태 (물리 predicate: 대상이 finger 사이 · table/crate 비접촉) 도 함께 만든다.
5. **closed-loop 기준값** — CL3 와 같은 분석 (`analyze_t42.py` · `agg_cl.py` · `replay_contacts.py`) 으로 success · `success_ct` · HOLD · 비허용 접촉. 이것이 T57 의 현재-서빙 기준선이다.
