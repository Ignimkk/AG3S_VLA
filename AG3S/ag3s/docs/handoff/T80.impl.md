### 평가 정의 (`t80_eval.py` docstring, 결과 전 고정)

- **target class:** target 점이 각 사과 GT 표면 8 mm 안에 몇 개 있나 (n1, n2) 로 정한다.
  - n1 + n2 = 0 → 없음
  - min(n1, n2) ≥ 0.25 × (n1 + n2) → 둘 다
  - 그 밖 → 많은 쪽
- **손이 가는 사과:** 쥐는 손은 run 중 어느 사과에든 손바닥이 가장 가까이 간 손이다. 요청 j → j+1 사이에 그 손 손바닥 거리가 가장 많이 (> 5 mm) 줄어든 사과를 고른다. 없으면 "없음".
- **일치율:** 처음 GT held (두 손가락 접촉 + 20 mm 들림) 전 요청 중 "없음" 이 아닌 요청만 센다.
- **지운 voxel class:** 처음 GT held 전까지 지운 voxel 이 있는 마지막 요청에서 손 층 `target_free_removed_ijk` 를 GT 8 mm class 로 나눈다.
- **C 지표:**
  - 새 중심: 이동 뒤 사과 GT 표면 중 depth 로 보이는 점의 중심.
  - 따라감: target 중심이 새 중심 20 mm 안에 들기까지의 요청 수.
  - 옛 자리: 이동 전 중심 반경 40 mm 안이면서 현재 사과 표면에서 8 mm 밖인 target 점 · 지운 voxel 수.
  - 지움: 위 두 수가 모두 0 이 되고 끝까지 0 이기까지의 요청 수.
