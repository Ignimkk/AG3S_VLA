## 1. 변경 (진단 전용, 기본 꺼짐)

- RB-Y1의 T46e "visible-target oracle"(`AG3S/ag3s/runtime/oracle_segmentation.py`, `--target-extent oracle-visible`, `--oracle-extent-identity gt`)을 Panda에 이식한다.
  - LIBERO · LIBERO-Safety client가 MuJoCo segmentation을 code 영상으로 요청에 싣는다.
    - 대상: 과제의 정답 target 물체 = BDDL의 집을 물체 = 1, 그 밖의 잡을 물체 = 3+, 정적 = 2, 로봇 = 0.
  - 서버는 그 표본으로 target을 지운다(물체 전체의 보인 면 + truncation 띠). target identity도 정답을 쓴다.
- 판:
  - `AG3S-final-panda-v3-e0to-pc-oraclegt` = pc판 + 위 flag
  - `…-pc-mi10-oraclegt` = mi10 + 위 flag
- SafeLIBERO는 이번에 하지 않는다. LIBERO 9 · LIBERO-Safety 10만 한다.

## 2. 기록할 숫자 · 판정 (결과 전 고정)

- **기제 (필수):** 실제 target bowl 부피(원기둥 r 45 mm, ±15 mm)의 target-free 층 점유가 접근 · 닫는 중 중앙값 ≤ 0.3이어야 한다(지금 0.99). 또 target identity가 맞는(정답 물체) call 비율이 ≥ 0.95여야 한다.
  - 아니면 "의도대로 동작하지 않음"으로 보고하고 멈춘다.
  - 측정은 `outputs/2026-11-05_SL11_통과판_무개입상한/scripts/target_free_check.py`의 정의로 한다.
- **진단 숫자 (판정 아님):**
  - LIBERO 9 · LIBERO-Safety 10 성공을 VLA 단독 · pc판 · 무개입과 비교한다.
  - mi10-oraclegt에서 찾는 중 + 접근 통과 비율(문턱이 열리는가)을 본다.
  - 구간별 표(`phase_map.py`)를 낸다.
  - 위반 주인 분류에서 target 몫이 줄었는지 본다.
- **읽는 법 (결과 전 고정):**
  - oraclegt 성공이 VLA 단독 −1 이내로 돌아오면 → 다음 작업 우선순위는 target 인식(ATS) · 지우기(LTE)다.
  - pc판 +2 이하에 머물면 → TO · latch(HSR · CCR)가 우선이다.
