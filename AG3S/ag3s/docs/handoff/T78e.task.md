## 1. 구현 (기본 꺼짐 flag, 꺼짐 = 지금과 bit 동일)

- `--surface-memory-target-sticky` (`esdf.surface_memory_target_sticky: bool = False`). `--target-extent attention-surface` 와 `--surface-keep-last` 가 필요하다.
- `runtime/oracle_segmentation.OracleMemory.update` 의 칸 (cell, 2.5 mm) 병합 규칙을 바꾼다. 지금은 "이번 frame 의 표본이 이긴다" (newest wins) 이다.
  - 켜면: 그 칸에 이미 code 1 (target) 표본이 있고 이번 frame 의 표본이 code 1 이 아니면 (다른 표면 2 · 다른 물체 ≥ 3) **target 표본을 유지** 한다.
  - 위치 · frame 은 유지한 target 표본의 것을 쓴다.
  - 그 밖의 경우는 지금과 같다 (target → target 갱신, 다른 표면 → 다른 표면 갱신, 다른 표면 → target 은 target 이 이김).
  - 깎기 (`_carve`, 광선이 그 표본 너머를 봄) 는 그대로 target 표본도 지운다. 물체가 옮겨 가면 기억이 따라 비워진다.
- 기록: `update` 의 `last` 에 `n_sticky_kept` (이번 frame 에서 target 을 지킨 칸 수) 를 더한다. 켰을 때만이다.
  - 서버 record 에서 읽을 수 있는 JSON 위치 (`target_exclusion.oracle.memory`) 에 나오는지 확인한다.
  - `esdf_stats.target_free` 는 문자열로 기록되니 거기에 두지 않는다.
- 띠 (`_update_band`) · `instance_of` · `evidence` 는 바꾸지 않는다.
