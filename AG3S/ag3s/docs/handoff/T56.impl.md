## 무엇을 했나 (평이한 요약 먼저)

T51 의 self label (S0) 과 새 self 점수 두 개 (S1 · S2) 를 같은 후보 집합에서 계산하는 study 를 만들었다. 각 점수로 cell 하나 또는 T54 arm 하나를 고르고, 고른 것이 GT 로 얼마나 손해인지 (regret) 를 잰다.
- **S1**: 0/1 과반 판정을 연속값 두 개로 바꿨다. 하나는 포함 비율 (chosen cluster 중 ball 안 점의 비율) 이고, 다른 하나는 ball coverage 다. event 는 `grasp_latch` 의 **HELD** 다.
- **S2**: S1 에 grasp 이후 frame 을 더한다. 손과 함께 움직인 점만 label 로 쓴다. latch 가 HELD 를 벗어나면 (release · slip · revoke) 더하기를 멈춘다.
- **HELD 를 얻는 곳**: test (T53) 는 server chunk 의 latch 기록이다. dev 는 기록된 실행 feedback 으로 `grasp_latch` 를 offline 으로 돌린다. 어느 쪽에서 얻었는지 record 마다 적는다.
- **선택 · tie-break**: 점수가 dev 해상도 안이면 동률이다. 동률이면 S1 coverage 성분이 큰 후보, 그다음 이름 사전순으로 고른다. 2D lift 는 어디에도 쓰지 않는다.
- **지표**: regret 은 두 가지를 낸다 (tie-break 로 고른 것, 동률 집합 평균). 동률 비율과 동률 크기, τ-b 도 낸다. τ-b 가 정의되지 않으면 `undefined:<사유>` 로 적고 0 으로 바꾸지 않는다.
- **보조 · 그 밖**: purity · coverage 손실, phase 별 분해, episode paired bootstrap (B 10000 · seed 5607), HELD label 오류율.
- **dev / test**: dev 단계가 `T56.prereg.json` 을 쓰고 멈춘다. test 단계는 그 파일을 읽기만 한다 (sha256 확인, parameter flag 를 받으면 거부).

이번 세션에서 앞 구현에 더한 것:
1. τ-b 가 정의되지 않은 사유를 따로 센다 (`no_event` · `self_all_tied` · `gt_all_tied` · `both_all_tied` · `fewer_than_2`). 평균이 정의되지 않으면 `mean_status = "undefined"` 로 적는다. 1e-12 이하 차이는 동률로 본다.
2. episode 단위 동률 비율 (`episode_ties`) 을 추가했다. bootstrap 동률 비율 (T51 의 rank-1 tie rate 와 같은 정의) 에서 event 가 없는 draw 를 분모에서 뺐다.
3. T55 재시뮬의 HELD label 오류율 (`--t55-run`, 선택 입력) 을 추가했다.
4. 그 밖의 보강:
   - test 단계에서 arm 을 평가하면 `--t54-run` 을 필수로 했다.
   - 이미 끝난 replay job 의 후보나 frame 이 다르면 거부한다 (resume 오염 방지).
   - prereg 에 탐색 범위 (`search_space`) 와 tie-break 규칙을 기록한다.
   - held summary 에 source 별 수와 event 없는 record 목록을 넣었다.

## 정의 (구현이 고정한 것)

| 항목 | 정의 |
|---|---|
| label cloud | 그 frame 의 저장 cloud 중 digest 가 가장 작은 것 (`current` 에서는 한 frame 의 모든 호출이 같은 cloud) |
| S0 | `both_contact` event (sim). ball 중심 = 그 손 두 pad 의 중점 (world 고정). 반경 = `object_radius` + 0.02 m. event 이전 frame 만 쓴다. frame 점수 = chosen 점 중 ball 안이 엄격한 과반이면 1, 아니면 0 (출력 없음 = 0) |
| S1 | HELD event. ball 중심 = HELD 손 pad 중점 (HELD frame, world 고정). 반경 = pad 간격으로 구한 물체 반경 + `margin`. HELD 이전 frame 만 쓴다. `inclusion` = chosen 점 중 ball 안 비율. `coverage` = ball 안 non-support 점 중 `cover_tol` 안에 chosen 점이 있는 비율. 둘 다 출력 없음 = 0 이고, ball 안에 점이 없으면 채점 불가 (NaN) 다. frame 점수 = `combine(inclusion, coverage)` → `normalize`. **이웃 음성 label 은 쓰지 않는다** |
| S2 | S1 + HELD 이후 frame. **latch 가 HELD 인 동안만** 더하고, 처음 HELD 가 아닌 frame 에서 멈춘 뒤 다시 시작하지 않는다. label 이 붙는 frame 의 조건: (a) 손 (pad 중점) 이 HELD 위치에서 `min_hand_motion` 이상 움직였다. (b) 손 ball 안 non-support 점 중 손 좌표 (finger 회전 · pad 중점 원점) 가 기준 집합 (`held` = HELD frame, `previous` = 직전 label frame) 의 `comove_tol` 안인 점이 `min_points` 이상이다. (b) 를 만족하지 못하면 `stop_on_lost` 에 따라 멈춘다. 손 근처라는 이유만으로는 양성이 되지 않는다 |
| episode 점수 | label 이 있고 채점 가능한 frame 의 평균. 변형의 label 이 없는 episode = event 없음 → 선택에서 빠진다 (GT 로 고르지 않음, 수와 목록을 보고) |
| 선택 | event episode 평균 점수 최대. 동률 = `max − resolution` 이상. tie-break = S1 coverage episode 평균 큰 것 (1e-12 비교) → 이름 사전순. 2D lift 없음 |
| GT | 후보의 episode 평균 `identity_correct` (target frame, 출력 없음 = 0) 를 episode 간 평균한 것. `all` = 모든 episode (주, 고른 설정은 모든 episode 에 쓰이므로), `event` = event episode 만 |
| regret | `regret` = GT 최선 − 선택. `tie_regret` = GT 최선 − 동률 집합 평균. 보조 손실은 purity · coverage 에 같은 방식이고, purity 는 선택 후보의 `no_target` 비율과 함께 낸다 |
| 동률 지표 | `tie_size` (선택의 동률 집합 크기) · `tie_set` · `tie_rate_boot` (draw 중 선택이 동률인 비율 = T51 rank-1 tie rate, event 없는 draw 제외) · `episode_ties` (episode 단위) |
| τ-b | event episode 마다 후보의 self episode 점수 대 GT episode 값으로 계산한다 (identity 주, purity · coverage 보조). 동률 허용, 1e-12. 정의되지 않으면 `null` + `episode_status = "undefined:<사유>"`. 평균은 정의된 episode 위에서만 내고, 하나도 없으면 `mean_status = "undefined"` 로 적는다 (0 아님). paired 차이에서 한쪽이 정의되지 않으면 `diff = null` 과 "compare by regret" 를 적는다 |
| bootstrap | episode 복원 추출 B 10000, seed 5607, percentile 2.5 / 97.5. 변형 · group · 조건 · phase 가 같은 draw 를 쓰고 (paired), draw 마다 선택을 다시 한다 |
| 기계적 판정 (`criteria_mechanical`) | group 마다 다음 숫자를 낸다: S1 의 `tie_regret` · `regret` ≤ `regret_tol`, S0 대비 regret 감소와 τ-b 증가 (정의 안 됨이면 regret 으로 판단한다고 적음), purity · coverage 손실 ≤ 허용폭. 해석은 하지 않는다 |
