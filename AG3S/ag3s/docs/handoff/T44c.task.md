### 판정 1 의 조건 (사용자 원문 요지 — 그대로 지킨다)
1. **fine 과 coarse 가 같은 target identity 와 같은 exclusion 의미**를 쓴다. 해상도가 다르므로 **voxel index 나 voxel 단위 threshold 를 그대로 복사하지 않는다** (ball 반경 · z_min · ownership 거리 등은 metre 로 정의하고 각 tier 의 voxel 에 맞게 적용).
2. 유효한 공통 영역에서 **target-free fine 과 target-free coarse 를 합성**하되, 기존 **static obstacle** 처리와 **window 경계** 처리를 유지한다.
3. 거리를 고른 **계층의 gradient 를 함께** 쓴다 (값과 gradient 가 같은 branch). 거리만 고치면 TO 가 잘못된 방향으로 움직일 수 있다.
4. target 과 obstacle 이 **coarse voxel 을 공유**하면 obstacle evidence 를 보존한다. 그 때문에 **target contact 가 과도하게 막히는지 측정**한다.
5. **flag** 를 두고 기존 방식과 **동일 입력으로 비교**한다.
6. 추가하는 것은 **target 을 제거한 coarse** 다. main coarse 를 그대로 min 에 넣으면 target 이 다시 장애물로 살아나 grasp 를 방해한다 — 금지.

## A5 — target-free coarse tier (implementer)

**현재 (코드 확인):** `curobo_field.target_free_distance` (`ag3s/fields/curobo_field.py:340-389`) 는 창 안에서 `min(f, max(d, b))`.
`b ≥ 0` 이라 `d < 0` (coarse 가 distractor 내부라고 답함) 이 지워진다. `f` (target-free **fine** tier, `curobo_builder` `only="fine"`, `tier_name="fine_no_target"`) 는
fine TSDF 가 관측하지 못한 내부에서 양수/0 이다 (`T44E2b.verify.json`: unobserved 23,807 / 65,445).
gradient 는 `target_free_gradient` → `_answer` (`curobo_field.py:421-482`), trajopt hot path 는 `linearize.py` `_esdf_clearance_core` (~903-918) · `_esdf_directions` (~734-753).

**소유 파일:** `ag3s/fields/curobo_builder.py`, `ag3s/fields/curobo_field.py`, `ag3s/config.py` (esdf 절), `ag3s/runtime/pipeline.py` (호출부만),
`trajopt/linearize.py` (target-free 값/gradient 조회 경로만 — I2/I2b 코드는 건드리지 않는다), `trajopt/serve_safe.py` (자기 block), `tests/ag3s/test_t44c_*.py`, `tests/trajopt/test_t44c_*.py`,
`ag3s/experiments/live/exclusion_e2.py` (새 tier 를 harness 에서 만들 수 있게).

**구현:**
1. Config `esdf.target_free_coarse: bool = False` + CLI `--target-free-coarse`. off 에서 bit-identical.
2. Builder: on 이면 coarse tier 도 target 제거판 (`coarse_no_target`) 을 만든다. 같은 integrator · 같은 identity · 같은 exclusion method
   (`ball` / `ball_owned` + 그 파라미터) 를 **metre 단위로** 적용한다. ownership 분류의 거리 (`owned_tie_voxels`, `owned_max_dist_voxels` 는 fine voxel 기준 정의) 는
   metre 로 환산해 coarse seed 에 적용하되, coarse voxel 이 그 거리보다 크면 어떻게 처리했는지 근거와 함께 impl.md 에 적는다.
   sign correction 도 같은 의미로 (제거된 target 쪽만). coarse voxel 하나에 target 과 non-target evidence 가 함께 있으면 **보존** (`n_shared_kept` 기록).
3. Query: 창 안에서 `min(f, c_free, ...)` 로 합성하는 새 branch. `c_free` = target-free coarse 답. static shapes (analytic) 는 지금처럼 min. 창 경계 `b` 의 역할은
   새 식에서 다시 정의한다 (target-free coarse 가 창 밖 표면을 직접 알므로 `max(d, b)` 하한이 필요한지 판단하고 근거를 적는다). 창 밖은 지금처럼 `d`
   (또는 `c_free` 가 유효한 곳은 그것 — 판단 근거를 적는다). **값과 gradient 가 같은 branch** — `target_free_gradient`/`_answer` 와 linearize hot path 를 함께 바꾼다.
   `answer_tier` 에 새 tier 이름.
4. Stats/record: `target_free.coarse{mode, n_seeds_in_ball, n_removed, n_shared_kept, build_ms}`, chunk npz 에 `esdf_free_coarse_*` (기존 키 이름 규약).
5. Tests: distractor 내부 점에서 새 query 가 음수 (old 는 양수) · target 내부/표면에서 새 query 가 old 와 같은 수준 (target 이 장애물로 살아나지 않음) ·
   shared coarse voxel 보존 · 값-gradient branch 일치 (finite difference, smooth 영역) · static shape 유지 · 창 경계 · off bit-identical · config/CLI 왕복.
   GPU 경로 smoke 1 frame (실제 cuRobo integration→seed→propagate→sign→query).

**산출물:** `T44c.impl.md`. 전체 pytest passed 수 (CPU env, worker ≤ 2).

## A6 — coarse target-free 의 target 바닥 잔류 수정 (implementer, 2026-10-10 추가)

**측정 근거 (`T44c.verify.json`, demo, gt_label):** coarse on 에서 target 내부 점 중 음수가 11,180 / 67,361 (off 2,021), 64/64 frame.
그중 11,057 점이 support + 20 mm 아래, 10,086 점을 `target_free_coarse` 가 답했다. coarse tier 는 support + max(5, 20) mm 위의 target seed 만
지우므로 target 아래쪽이 남는다 (coarse target recall 중앙 0.68). 이는 **사용자 조건 6 (target 이 다시 장애물로 살아나지 않음) 위반**이다.
안전 이득은 확인됐다: distractor 내부 finger 가 clearance ≥ margin 인 frame 54 → 17 (main composite 자체의 17 과 같다).

**원인 가설 (lead, 미검증):** coarse 의 **seed 제거 guard** (20 mm, 해상도 때문에 table seed 를 지키려는 것) 와 **부호 소유 판정** 이 한 값으로 묶여 있다.
table 과 target 바닥이 같은 coarse voxel 을 공유하면 table seed 는 지켜야 하지만, support plane **위** ball 안의 음수 (target 내부) 는 target 것이다.

**수정 후보 (implementer 가 비교하고 고른다 — 근거와 숫자를 impl.md 에):**
- (a) seed 제거 guard 는 그대로 두고, **부호 교정만** ball 안 · support plane (metre, guard 아님) 위 · target 쪽 (non-target evidence 가 더 가깝지 않은) coarse voxel 까지 넓힌다.
  table seed 는 남아 table 까지의 거리를 답하고, plane 아래 (table 내부) 음수는 그대로.
- (b) 창 안에서 coarse 는 **fine 이 관측하지 못한 voxel 에서만** 합성에 참여한다 (fine TSDF unobserved mask). fine 이 아는 곳은 coarse 해상도 편향이 들어오지 않는다.
- (a)+(b) 조합 가능.

**완료 조건 (D-sign2 와 같은 frame · 정의, 고정):**
1. target 내부 음수 점 수: coarse on ≤ coarse off (2,021) 수준 (ball · bo_d3 모두).
2. distractor 내부 clearance ≥ margin frame 수: ≤ 17 유지 (안전 이득 보존).
3. table 보호: support plane 아래 (table 내부) 점의 음수 수와 table 위 10 mm 이내 점의 target-free 거리가 coarse off 대비 커지지 않음 (낙관 방향 0).
4. grasp 직전 authorized 구: margin 아래로 내려간 query 수가 지금 (62 / 13 frame) 보다 줄어듦 — 값 보고.
5. 성질 `min(old, d) ≤ new ≤ old` 유지 (old 보다 덜 막는 점 0) — test 로.
6. off bit-identical, 값-gradient 같은 branch.

**소유 파일:** A5 와 같다. harness 로 위 1–5 를 직접 smoke 해서 impl.md 에 (verifier 가 따로 다시 잰다).
