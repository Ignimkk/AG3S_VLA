- 지금 분류기 (`kv_L4_v1` 3 단계, `hsr6_t64_kv_L4` 6 단계) 는 전문가 시연의 phase 라벨로 배웠다. 시연에는 "닫았지만 비었음" 이 없다.
- 단계마다 다른 제약 (lead 분석, 사용자 동의): 제약 묶음이 갈리는 수 = 5.

| 5 단계 | 제약 묶음 | 지금 3 단계 | 지금 6 단계 |
|---|---|---|---|
| 접근 | target 면제 · 이웃 = 장애물 · 목표 항 없음 · 새 대상 선택 가능 | pick | approach |
| 쥐기 | + 이웃 가벼운 접촉 허용 · 쥐기 목표 / 도달 제약 · held 허용 시작 | pick | grasp |
| 운반 | 쥔 물체 = 손의 일부 · 새 대상 선택 안 함 | place | lift · transport |
| 놓기 | + 바구니 접촉 허용 · 놓은 뒤 처리 | place | placement |
| 물러남 | 면제 없음 (놓은 사과 = 장애물) | home | retreat |

## 1. 정답 (라벨, 결과 전 고정)

- **전문가 데이터** (`$AG3S_STORAGE_ROOT/datasets/rby1/rby1_randomized_pick_place_16d_v1`, parquet `phase_index`): 0–2 · 20–22 → 접근, 3–4 → 쥐기, 5–6 → 운반, 7–9 → 놓기, 10–13 → 물러남 (T64 `MAP6` 에서 lift · transport 를 합친 것). 그 밖의 index 는 뺀다 (센다).
  - frame: SUBTASK-b 와 같은 표본 — train = episode 0–1599 중 8 개마다 1 개 × 6 frame 마다 1 개, val = 1600–1799 중 4 개마다 1 개 × 6 frame 마다.
- **closed-loop 기록** (요청 단위, MuJoCo 물리 정답 = 같은 요청의 client step qpos 를 장면 XML 에 넣어 계산; `module_eval.py` 와 같은 정의):
  - held = 쥐는 손 두 손가락이 사과에 닿음 ∧ 사과가 처음보다 20 mm 이상 올라감.
  - **물러남** = 한 번 held 였다가 지금 held 아님 (놓은 뒤 · 떨어뜨린 뒤).
  - **놓기** = held ∧ 사과 중심이 바구니 바닥 xy 범위 안 (바구니 = 장면의 destination body, xy 는 그 body 의 collision geom 범위).
  - **운반** = held ∧ 놓기 아님.
  - **쥐기** = 아직 held 였던 적 없음 ∧ 쥐는 손 손바닥 site–사과 중심 ≤ 60 mm (A6 창과 같은 값). 빈손으로 닫은 요청도 여기.
  - **접근** = 아직 held 였던 적 없음 ∧ 60 mm 초과.
- 두 데이터의 "쥐기" 정의가 다르다 (시연 = phase index, closed-loop = 60 mm). 차이는 한계로 적는다.

## 3. feature (비교 대상)

| feature | 차원 | 비고 |
|---|---|---|
| **기준:** `kv_L4` | 512 | 지금 serving 분류기와 같은 feature (V cache layer 4, [text 평균 | image 평균]) |
| hidden layer l (l ∈ {0, 2, 4, 6, 8, 10, 12, 14, 16, 17, 18}) × pooling | 2048 × k | pooling = 카메라별 image token 평균 (3) · 유효 text token 평균 · 마지막 유효 text token. 비교는 `img3+last` (8192) 와 `last` (2048) 두 가지 |

- 모든 feature 에 같은 분류기 (StandardScaler + multinomial logistic regression, `t64_phase6.fit` 과 같은 꼴).
- 층 · pooling 선택은 train CV 만으로 한다 (test 를 보지 않음). 선택한 하나를 test 에서 기준과 비교한다. 다른 층 값은 그래프로만 보고.
