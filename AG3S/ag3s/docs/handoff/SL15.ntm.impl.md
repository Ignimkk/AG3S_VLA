# SL15 (NTM) -- 구현: 비권한 link 의 target 여유 두 판 (`-pc-ntm`, `-pc-openrule-ntm`)

> writer: ag3s-implementer · 읽는 쪽: verifier, scribe, lead · 2026-11-05 · branch `wip/sl15-ntm` (base 816f7aa4)
> 새 flag 없음 (기존 T44e A9 `--nonauthorized-target-margin`), 새 판 두 개. 기본 꺼짐: 기존 판의 argv · 기록 키 불변.

## 무엇을 했나 (평이한 요약)

Panda 서버 판 두 개를 등록했다. `AG3S-final-panda-v3-e0to-pc-ntm` = `-pc` flag + `--nonauthorized-target-margin obstacle`,
`AG3S-final-panda-v3-e0to-pc-openrule-ntm` = `-pc-openrule` flag + 같은 flag.

이 flag 는 RB-Y1 서버에만 배선되어 있었고 **Panda 서버는 거절했다** (`server.UNPORTED_FINAL_CONFIG_DESTS` 에 있었고 `profile.UNPORTED_BUILD_KEYWORDS`
에 `contact` 가 있었다). 그래서 판 등록만으로는 서버가 시작하지 못한다. Panda 이식을 같이 했다: config 에 `contact.nonauthorized_target_margin`
을 넣는 한 줄 (`build_ag3s` 와 같은 모양), 키 생존 확인, 기록 (`info["contact"]`, 켰을 때만). TrajOpt · AG3S 핵심 코드는 건드리지 않았다 (공유 코드).

## 의미 (코드 근거)
- 비권한 행 = `to_adapter.py:261-266`: `str(n) not in authorized` (`authorized = clearance.authorized_links(perm_ctx)`, `clearance.py:214-223` = `contact.contact_links` 의 합집합 - `PROTECTED_LINKS`).
  Panda: `contact_links = {"left": (panda_hand, panda_leftfinger, panda_rightfinger)}` (`profile.panda_overrides`, `model.PANDA_CONTACT_LINKS`).
  pc flag 는 `--links arms` + palm shell on 이므로 구 170개 중 `panda_link1..7` 의 **37개** (4+4+4+4+13+3+5) 가 비권한. 권한: `panda_hand` 129 (palm shell 111 포함), 손가락 2+2.
- 조건 (`to_adapter.py:264`): `manipulated_link_margin is not None` (조작 대상이 있음) 이고 쥔 것이 없을 때만 (`attached is None`). 쥔 뒤 (carry) 는 None.
- `full` (기본): 최근접 표면이 target 인 행 (`|d - d_object| <= voxel`, `linearize.py:1042-1058`) 은 `manipulated_link_margin` 의 그 행 값 =
  `full_margin(TARGET)` = `geometry.safety_margin` = 0.05 m (`config.py:930`, `clearance.py:196-211, 253`).
- `obstacle`: 그 행을 target 판정에서 뺀다 (`linearize.py:1053-1057` `is_object &= ~nonauth`, `_obstacle_rows` 의 `contact &= ~nonauth` 1481-1485) → 기본 `esdf_margin` (0, `--esdf-margin 0`) 에
  obstacle class 의 `max(margin, obstacle_margin)` (`linearize.py:1059-1067`) = **0.010 m** (`--obstacle-margin 0.010`). (palm shell 행은 `palm_shell_margin` 5 mm 이지만 권한 행이라 이 flag 와 무관.)
- 안 바뀌는 것: 접촉 금지 (verdict `unauthorized_link`), 권한 행의 phase 여유, `target_permission_strict` 의 look-ahead · sweep target 판정, 쥔 뒤 규칙, `target_field_policy exclude-authorized` (권한 행만 target-free 계층).
