## 무엇을 했나 (평이한 요약 먼저)

논문의 label-free head 선택 절차 (attention sum `S_img` 의 knee `τ` 로 걸러 낸 뒤 spatial entropy 가 낮은
head 를 sample 마다 10 개 고르고, 고른 빈도로 top-k 를 정해 Gaussian smoothing 후 합산) 를 16D npz 의
**camera 3 대** 에 맞춰 순수 numpy 로 구현했고, 그것을 돌리는 CLI 를 `gt · select · validate · e2e` 네 stage 로
만들었다. `select` 는 GT 를 전혀 읽지 않는다. `gt` 는 MuJoCo replay 를 **한 번만** 해서 class 별 16×16 patch
coverage 를 캐시하고, `validate` · `e2e` 는 그 캐시와 attention npz 만 읽는다 (e2e 는 depth 가 필요해서 replay 를
다시 한다). `e2e` 는 live 서빙 경로 (`wire.pack_request → strip_request → unpack_camera_observations(attention=…)
→ AG3S.process_multi_debug`, AG3S 는 `serve_safe.build_ag3s` 기본값) 를 그대로 조립했고 attention source 만 바꾼다.
**기존 파일은 하나도 고치지 않았다.** MuJoCo replay / rendering 은 실행하지 않았다 (승인 대기).

## 고른 정의 (논문이 열어 둔 것)

| 항목 | 정의 | 어디 |
|---|---|---|
| spatial entropy | `B = ReLU(A − mean A) > 0` → **8-connectivity** 성분 → `P(C)=|C|/Σ|C|` (pixel 수, attention 질량 아님) → `H = −Σ P ln P` (raw nats). 정규화 변형은 만들지 않았다 | `t47_head_metrics.py:83` |
| entropy edge case | **성분 0 개** (상수 map: 평균을 넘는 pixel 없음) → `H = NaN`, 그 sample 에서 그 cell 은 **선택 불가**. 상수 map 의 평균이 반올림으로 원소와 bit 단위로 안 같은 경우를 막으려고 `A − mean ≤ 1e-9·max|A|` 는 0 으로 본다 (`BINARIZE_REL_EPS`, `:39`). 한 성분 → 0. NaN/inf map → 예외 | `:69` · `:83` |
| τ (max curvature) | 오름차순 정렬 곡선을 단위 정사각형으로 정규화 (`x=i/(n−1)`, `y=(v−min)/(max−min)`). **primary = Kneedle** (Satopää 2011): `argmax(x − y)` (chord 아래로 가장 먼 점 = 볼록 증가 곡선의 최대 곡률 근사). **variant = curvature**: `κ = |y''|/(1+y'²)^{3/2}`, `np.gradient` 중앙차분, 양 끝점 제외. 퇴화 (n<3, 상수, Kneedle 에서 chord 아래 점 없음) → `knee_found=False`, `τ = min` (= 모두 eligible). eligible = `S ≥ τ` (τ 점 포함). Kneedle 을 primary 로 둔 이유: 이산 2 차 차분은 128 cell 의 평평한 구간의 잡음에 걸린다 (1/h² 배율) | `:154` |
| τ 를 어디서 | **sample (frame, camera) 마다** 그 sample 의 128 cell `S_cam` 으로 τ (primary, `tau_source=cam`). variant `img` = frame 마다 `S_img` (3 camera 합) 으로 τ, eligible 을 3 camera 에 공유. 두 τ 정의 (kneedle/curvature) 는 둘 다 결과에 남기고 선택에는 `--tau-method` 하나만 쓴다 | `t47_head_selection.py:387` |
| selection frequency | sample 마다 (eligible ∧ entropy 유한) 중 entropy 최저 `N=10` (부족하면 전부). 동점은 cell index 순 (stable sort). 분모 = **모든** sample (후보 0 인 sample 포함, 그 수를 따로 보고) | `t47_head_metrics.py:223` |
| sample 정의 | 공통 head set = 모든 selection record 의 모든 (frame, camera). camera 별 head set = 그 camera 의 모든 frame | `t47_head_selection.py:387` |
| 순위 | 빈도 내림차순 → (동점) eligible 일 때의 평균 entropy 오름차순 → 평균 `S` 내림차순 → index. top-k = 앞 k 개 (k=1..5) | `t47_head_metrics.py:256` |
| 제외 layer | L0 · L1 (논문 §4). cell = L2–17 × h0–7 = 128 | `:35` · `:322` |
| query | primary `denoise 0` × agg {last, mean, first}; `denoise 4, 9` 도 같은 계산 (`--denoise`). setting 이름 `d{denoise}_{agg}` | `t47_head_selection.py:427` |
| smoothing 경계 | `scipy.ndimage.gaussian_filter(mode="reflect", truncate=4)` — half-sample 대칭 반사라 밖으로 나간 kernel 무게가 안으로 접혀 **map 마다 질량 보존** (unit test 가 모서리 delta 로 확인, rtol 1e-12). σ=0 은 복사. 합산은 **raw** element-wise 합 (head 별 정규화 없음) | `t47_head_metrics.py:274` · `:293` |
| head-average (c) | L2–17 전체 128 cell 평균 (σ=0) | `:314` |
| GT patch mask | target coverage ≥ **0.5** (primary), **0.25** 변형. coverage = 480×640 render 의 30×40 px patch 안 target pixel 비율 (`policy_record.patch_coverage`) | `:332` |
| IoU | mean-binarized map (entropy 와 같은 `binarize_above_mean`) vs GT mask. **GT mask 가 비면 NaN** (0 으로 채점하지 않고 `iou@t_n_gt_empty` 로 개수 보고). 상수 map (uniform) 은 binarized 가 비어 IoU 0 | `:332` |
| peak_on_target · lift | step-01 그대로: argmax patch 의 target coverage > 0.05 · `target mass ÷ (Σ coverage/256)`. 상수 map 의 argmax = patch (0,0) (step-01 과 같이 결정적이지만 의미 없음) | `:332` |
| 2D 제외 | target 이 그 camera 에서 `< 200 px` (480×640) 인 (frame, camera) 은 모든 2D 평균에서 제외, record × camera 별 제외 수 보고 (`excluded_lt_min_target_px`) | `t47_head_selection.py:664` |
| GT-oracle (e) | **selection record 의 GT** 로, 같은 setting (denoise, agg) 안 128 cell 을 3 camera pooled `peak_on_target` 로 순위 (동점 = 평균 lift) → top1 · top3. 상한 참고용 — held-out 에서만 채점, selection record 의 e2e 에서는 CLI 가 거절 | `:624` · `:801` |
| Spearman | cell 마다 selection 빈도 (그리고 순위 위치, 1 = best) vs held-out pooled 지표 (IoU@0.5 · IoU@0.25 · lift · peak · target mass). 공통 순위 ↔ pooled, camera 별 순위 ↔ 그 camera. `rank` 의 ρ 는 음수가 정렬 일치 | `:664` |

## verifier 가 실행할 명령

```bash
cd /mnt/dev/AG3S_VLA-development
source scripts/setup/env.sh
export AG3S_RUN_DIR="$(.venv-openpi-live/bin/python -m common.run_output)"      # 한 번
T47="env MUJOCO_GL=osmesa PYTHONPATH=${AG3S_PROJECT_ROOT} ${AG3S_PROJECT_ROOT}/.venv-ag3s/bin/python -m AG3S.ag3s.experiments.studies.t47_head_selection"

# 1) select — GT 없음, MuJoCo 없음. 3 record 전 frame × denoise {0,4,9} × agg 3 × tau {cam,img} + LORO.
$T47 --stage select                                   # ≈ 20 s (smoke 로 잰 시간), RAM < 2 GB

# 2) gt — MuJoCo replay (osmesa, CPU). 사용자 승인 후. 7 record = 340 frame × 3 camera (depth+seg 640×480)
#    + record 당 3 frame RGB 자가 점검. 캐시가 있으면 건너뛴다 (--force 로 다시).
$T47 --stage gt --workers 4                           # 추정 5–15 분 (render 를 재지 않았다 — 추정치)

# 3) validate — 캐시만 읽는다. held-out 4 record, oracle 은 selection 3 record 의 GT.
$T47 --stage validate                                 # ≈ 12 s × 9 setting ≈ 2 분 (가짜 GT 로 잰 plumbing 시간)
#    빠르게: --denoise 0 --aggs last

# 4) e2e — MuJoCo replay + AG3S (CPU legacy ESDF). 사용자 승인 후. ms 를 쓰려면 --workers 1.
$T47 --stage e2e                                      # held-out 4 record × 5 source (#6)
#    추정: build_ag3s 12.6 s × 20 ≈ 4 분 + 60 frame × 5 source × process_multi (재지 않음, 1–3 s 로 보면 5–15 분)
$T47 --stage e2e --records long t2 ep1807 --sources l8h2 topk_common topk_camera head_avg   # #7, oracle 제외
#    추정: 200 frame × 4 source → 15–40 분
#    smoke: --max-frames 2
```
