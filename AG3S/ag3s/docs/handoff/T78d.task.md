## 1. 구현 (기본 꺼짐 flag, 꺼짐 = 지금과 bit 동일)

### 1.1 오목 꺾임 끊기 (`--surface-crease-cut`, `esdf.surface_crease_cut: bool = False`)

- 표면 선택 (`runtime.attention_surface.select_target_surface`, 그리고 같은 일을 하는 `runtime.attention_surface_gpu.select`) 의 graph 를 다음과 같이 바꾼다. study script `run_variant(voxel=0.0025, cut=True)` 와 같은 결과여야 한다.
  1. 노드 크기 `surface_crease_voxel_mm` (기본 2.5).
     - 확대는 seed 관심 영역 (`roi_radius` 150 mm) 안에서만 해도 된다. 전체 장면을 2.5 mm 로 만들 필요가 없으면 그렇게 해서 시간을 줄인다.
     - 그 경우 결과가 study (전체 2.5 mm graph) 와 같은지 §2.1 동등성으로 보인다.
  2. 관심 영역 안 노드의 normal 은 반경 PCA 로 구한다 (반경 = max(2 × 노드, 7.5 mm)). 관측 카메라 쪽으로 향하게 한다 (study `normals_pca` + view 합).
  3. edge (i, j) 는 오목하고 ((n_i − n_j)·(x_i − x_j) < 0) 두 normal 사이 각이 `surface_crease_angle_deg` (기본 20) 이상이면 끊는다.
  4. 그 뒤 선택은 지금과 같다 (`g_and_top1`: seed 질량 최대 연결 영역, m ≥ 0.5).
- code 영상 (`codes`) 은 2.5 mm 노드에서 pixel 로 칠한다. 노드 크기가 바뀌어도 pixel → node 대응 (`_pixel_nodes`) 이 맞아야 한다.
- 다음 단계 (A2 겹침 검사 · keep_last · hull 등) 는 code 영상과 `region_from_codes` 를 쓴다. 이때 `voxel` 을 5 mm 로 고정해 쓰는 곳이 있으면 영향을 확인하고 impl.md 에 적는다.

### 1.2 작은 조각 다시 붙이기 (`--surface-crease-reattach-ratio R`, `esdf.surface_crease_reattach_ratio: Optional[float] = None`, `--surface-crease-cut` 필요)

- 끊긴 edge 로만 선택 영역과 이웃한 연결 성분 (끊은 graph 의 성분, 관심 영역 안, 지지면 아님) 을 본다. 노드 수가 선택 영역의 R 배 이하이면 선택 영역에 붙인다. 권장 R = 0.25.
  - 의도: 꼭지 · 잎 · 손잡이처럼 몸통에 오목하게 붙은 작은 부분은 붙인다. 맞닿은 바나나 (사과의 약 0.6 배) 같은 큰 이웃은 붙이지 않는다.
  - 붙인 성분도 그 성분 전체를 붙인다. m ≥ 0.5 문턱은 다시 걸지 않는다.
  - 한 번만 한다 (붙인 뒤 다시 확장하지 않는다).
- 기록: 성분마다 노드 수 · 비율 · 붙임 여부. 한계 (선택 영역의 R 배보다 작은 맞닿은 이웃은 붙는다) 를 impl.md 에 적는다.

### 1.3 기록 · 거절

- record 에 `crease` 블록을 둔다: 노드 크기 · 각 · 끊은 edge 수 · 관심 영역 노드 수 · 시간 · reattach 기록.
- 거절 (fail loudly):
  - `--target-extent attention-surface` 가 아님.
  - 각 · 노드 · R 이 범위 밖 (음수 · NaN · 0).
  - reattach 를 crease 없이 켬.

## 2. 검증 (결과 전 고정)

### 2.2 영역 판정 (lead, T78c §8 과 같은 487 요청 · 정답 · 지표)

- 구성 C1 = 2.5 mm + 오목 끊기 + 작은 조각 붙이기 (R = 0.25). 서빙 코드 (CPU 경로) 로 계산한다.
- 통과 조건 (모두):
  1. 맞닿은 장면 (간격 < 5 mm, 쥐기 전) 정밀도 중앙 ≥ 0.95.
  2. 맞닿은 장면 사과 덮음 중앙 ≥ 0.90.
  3. 떨어진 장면 (사과 위) 덮음 중앙 ≥ 지금 (5 mm) − 0.02.
