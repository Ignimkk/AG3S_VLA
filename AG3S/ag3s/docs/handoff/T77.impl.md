## 무엇을 했나 (평이한 요약 먼저)

1. **hidden 추출 도구에 GPU 와 요약 저장을 넣었다.** `pi05_hidden.py` 에 `--device gpu` (JAX_PLATFORMS 강제 없음, gpu_lock 안에서 실행) 와 `--pool summary` 를 추가했다. summary 는 frame 마다 layer 별 5 행 — 카메라 3 개 평균 · 유효 text 평균 · **마지막 유효 text token** — 을 float32 로 저장하고, 같은 frame 의 `kv_L4` (SUBTASK-b 정의 그대로, 512-D) 를 함께 쓴다. pooling 은 jit 안에서 해서 `[L, 5, 2048]` 만 host 로 온다. 입력은 전문가 dataset (`--dataset --episodes`, SUBTASK-b frame 표본 그대로) 또는 closed-loop 기록 (`--spec` / `--records`). episode / run 마다 npz 하나, 있으면 건너뛴다 (재개 가능). 아무 새 option 도 주지 않으면 T73 의 CPU 경로 그대로다.
2. **closed-loop 정답 라벨 도구 `t77_labels.py`.** `spec` 은 다섯 kit root (CORE-EVAL · PT · T71 · T74 · T72b) 에서 AG3S run 427 개를 찾아 server chunk 와 짝짓고 §2 장면 나누기를 붙인다. `labels` 는 요청마다 client qpos 를 장면 XML 에 넣어 §1 의 5 단계 정답과 지금 serving 의 3 단계 · HSR6 예측을 쓴다.
3. **학습 · 평가 `t77_probe.py`.** §3 · §4 그대로: feature 23 개 (`kv_L4` + 11 층 × {img3+last, last}), 같은 분류기 (`t64_phase6.fit`), train CV 로만 C · 층 · pooling 선택, test 지표 (거짓 운반률 · 정확도 · macro-F1 · 경계 지연), 전문가 val macro-F1, serving 참고값, §4 판정을 json 하나로 쓴다.

발견 하나 (구현 중): **server chunk 의 `t_step` 은 요청 번호 (1, 2, 3 …) 이고 client step 의 `t_step` 은 제어 step (0, 8, 16 …) 이다.** 427 run 모두 그렇다. 그래서 요청 짝짓기는 `module_eval.py` 처럼 **순서** (i 번째 chunk ↔ t_step 으로 정렬한 i 번째 client step) 로 한다. 같은 숫자의 t_step 끼리 짝지으면 틀린다 (요청 8 ↔ 요청 1). test 로 고정했다 (`test_label_run_pairs_requests_by_order`).

## verifier 가 알아야 할 것

- 새로 생긴 flag · 기본값: `pi05_hidden --device {cpu,gpu}` (기본 cpu), `--pool summary`, `--dataset`, `--episodes`, `--frame-stride 6`, `--spec`, `--only`, `--out-dir`. 기본 인자의 동작 · 출력 key 는 T73 그대로. serving 은 이 도구를 쓰지 않는다.
- 재생산이 필요한 산출물: 없음 (새 산출물만).
- 옛 기록과 호환이 깨지는가: 없음.
- 제한:
  - summary 의 카메라 평균은 유효 image token 만 (T73 `--pool mean` 과 같음), kv_L4 의 image 평균은 768 token 전부 (SUBTASK-b 그대로). 이 모델에서는 image mask 가 항상 참이라 같다.
  - closed-loop prompt 는 기록된 `"Place the apple into the basket."` (전문가와 문장이 다르다 — 그때 serving 이 본 그대로).
  - 라벨의 HSR6 참고값은 HSR6 이 기록된 kit 에서만 계산된다 (PT · CE 일부 run 에는 없음, 개수는 json 에 남는다).
  - 이 STEP 의 process 는 모두 끝냈다. reclaim: `reclaim: ws 34.1->34.0 GiB | cache 6.0->0.0 GiB, 38 files, 2 paths` (`python3 scripts/setup/reclaim_cache.py $T77 <checkpoint 29999>`)
