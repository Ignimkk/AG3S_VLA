> 사용자 지시 (2026-11-03): "아이디어에서 방향을 A → B → C 순서로 수행해 보라." A = 이 STEP, B = T94 (chunk 단위 CBF), C = T95 (멈춤이 이어질 때 경유점 계획). 번호는 2026-11-03 13:2x KST 에 다른 세션에 알렸다.

## 0. 왜
- 지금 TrajOpt 는 VLA chunk 를 chunk 안에서만 조금 고치고, 고칠 수 없으면 멈춘다 (HOLD). 경로를 막는 장애물 (허들 막대) 앞에서 VLA 가 모르는 우회를 TrajOpt 가 만들어도 다음 chunk 의 VLA 계획은 다시 막대로 간다 (T85 허들 954: HOLD → 떨어뜨림).
- pi0.5 는 flow matching 으로 action chunk 를 만든다. 학습 없이 생성 단계마다 충돌 비용의 gradient 를 넣으면 **VLA 자신의 분포 안에서** 장애물을 피하는 chunk 가 나온다. 근거: constrained flow matching (arXiv 2607.01378, SafeLIBERO 충돌 회피 82.8 % · 성공 81.6 %), VLS (2602.03973, 고정 flow 정책을 학습 없이 유도), SafeDiffuser.
- 비용 함수는 이미 있다: TrajOpt 가 쓰는 같은 거리장 (target 제외 ESDF) · 같은 구 모델 · 같은 접촉 허용 · 같은 clearance 바닥의 위반 행과 그 Jacobian (`AG3S/trajopt/linearize.py`).

## 1. 동작 (기본 꺼짐 flag, 꺼짐 = 지금과 bit 동일)
`serve_safe --fm-guide` (+ 아래 수치 인자). 요청마다:
1. 지금처럼 VLA 를 한 번 샘플링한다. **켜졌을 때만** noise 를 SafePolicy 가 명시적으로 만들어 (`policy.infer(obs, noise=...)`, 요청 seed 가 있으면 그 seed 로) 기록한다.
2. 지금처럼 장면 · 거리장을 짓고 TrajOpt 가 reference (VLA chunk) 의 위반 `reference_violation` 을 잰다 (`sqp.py` 944–947 줄).
3. **위반 > 0 일 때만** (요구 clearance 포함, lookahead 이면 실행 구간 기준 — `reference_violation` 과 같은 정의) 같은 관측 · **같은 noise** 로 VLA 를 다시 샘플링하되, flow 단계마다 충돌 비용으로 유도한다 (§2). 위반 ≤ 0 이면 아무것도 하지 않는다 (do-no-harm: 그 요청은 P0 와 bit 동일).
4. 유도된 chunk 의 위반을 같은 함수로 다시 잰다. **유도 chunk 의 위반 < 원래 위반** 이면 유도 chunk 를 새 reference 로 삼아 TrajOpt 를 그대로 돌린다 (TrajOpt · HOLD 판정 · gripper 열은 지금과 같다). 아니면 원래 reference 로 돌린다.
   - gripper 열은 유도하지 않고 원래 chunk 값을 쓴다 (쥐기 · 놓기 시점을 바꾸지 않는다).
5. 기록 `to.metrics.fm_guide = {applied, violation_before_m, violation_after_m, used, max_joint_change_rad, guide_ms, steps}` (켰을 때만). 시작 log 한 줄 `VLA flow guidance (T93): ON scale=… steps=…`.

## 2. 유도 (구현 지시)
- openpi 의 `Pi0.sample_actions` 는 이미 `guidance_fn(x_next, t_next)` hook 이 있다 (SEAM 이 씀, `Baseline/seam_vla/integration/openpi_jax.py`). x0 예측 (`x̂0 = x_t − t·v_t`, openpi 규약 t = 1 noise → 0 data) 에 gradient 를 걸려면 v_t 가 필요하므로 **새 선택 인자** 를 더해도 된다 (예: `guidance_xv_fn(x_t, v_t, t, x_next, t_next)`). 조건: 인자 없음 = 지금과 bit 동일, SEAM 경로 무변경 (기존 test 통과).
- 비용: `C(x̂0) = ½ Σ_rows max(0, −clearance_row)²` — TrajOpt 가 이 요청에 쓰는 **같은 linearizer · scene · 행 (접촉 허용 · 바닥 띠 포함)**. gradient = Jacobian^T · (−clearance)⁺. 이 계산은 host (numpy) 에 있으므로 `jax.pure_callback` 또는 Python 수준 loop (prefix KV 1 회 + jit 한 1 단계 함수 반복) 중 지연이 작은 쪽을 고른다. 고른 이유와 측정 지연을 impl 에 적는다.
- 사상: model 출력 x (정규화 · 32 차원 padding) → output transform (unnormalize · delta→absolute · 16 차원 slice) → 물리 chunk (TrajOpt reference 와 같은 배치). 이 transform 이 차원별 affine 인지 확인하고 (finite difference test), gradient 를 그 대각 scale 로 x 공간에 되돌린다. gripper 차원 · padding 차원은 gradient 0.
- 갱신: `x_next ← x_next − λ · clip(g)` (λ = `--fm-guide-scale`, clip = 단계당 관절 변화 상한 `--fm-guide-max-step-rad`, 적용 단계 = 마지막 `--fm-guide-steps` 개 flow 단계, 기본 전체 10). 기본값은 §3 smoke 로 한 번 고르고 impl 에 고정한다 (그 뒤 closed-loop 전에 바꾸지 않는다).
- 이미 실행 중인 앞부분 (RTC inpainting) 은 이번 STEP 에서 하지 않는다. TrajOpt 연속성 항이 그대로 맡는다. 필요하면 다음 STEP.

## 4. closed-loop (결과 전 고정, lead)
- 기준 구성 = T92 가 통과하면 P0m (P0 + `--subtask-from-latch`), 아니면 P0. **T93 구성 = 기준 + `--fm-guide`**.
- 장면: **놓는 곳 허들 7 장면 × 2 에서 허들 211 × 2 를 뺀 12 run** (VLA 단독 0 / 14, 2026-10-29 최종 구성 6 / 14 — 우회가 필요한 장면) + 기존 9 run (해 없음 확인). 기준과 T93 은 같은 장면 · 같은 seed.
- 주 지표: 금지 접촉 없는 성공 (T88 §2 새 정의, 옛 정의 함께).
- 통과 (T93 채택, 모두):
  1. 허들 12 run 금지 접촉 없는 성공 ≥ 기준 + 2.
  2. 9 run 성공 ≥ 기준 − 1, 전체 금지 접촉 run ≤ 기준, 탁자 · 바구니 0.
  3. 기전 확인: 유도가 돈 요청 중 유도 chunk 위반 < 원래 위반 ≥ 70 %, 유도 chunk 를 쓴 요청의 HOLD 비율 < 기준 같은 상황의 HOLD 비율.
  4. 지연: 유도가 돈 요청의 추가 시간 중앙값 기록 (기준 없음, 보고만). 독점 lock 에서 잰다.
- 차이 ≤ 2 run 은 "구분 못 함". 실패마다 원인 층을 T85 진단 도구로 적는다.
