## 무엇을 했나 (평이한 요약 먼저)

T78d 오목 끊기 위에 기본 꺼짐 flag 두 개를 넣었다.

- `--surface-crease-protrusion` (+ `--surface-crease-protrusion-area ρ`, 기본 0.15): 끊긴 edge 로만 선택 영역과 이웃한 성분 (T78d 다시 붙이기와 같은 후보) 을 세 조건을 모두 만족할 때만 통째로 붙인다. 세 조건은 받침면 위로 영역 꼭대기보다 솟음, 영역 투영 면적의 ρ 배 이하, 영역 투영 convex hull 과 겹침이다. CPU · GPU 경로가 같은 host 함수 하나 (`attention_surface_crease.protrude`) 를 같은 입력으로 부른다.
- `--surface-crease-hand-freeze-mm D` (권장 80): latch 가 searching · latched · closing 일 때 쥐는 손바닥 점이 직전 채택 영역 중심에서 D mm 안이면 그 요청은 영역을 새로 고르지 않는다. A4 (`--surface-grasp-hold`) 와 같은 규칙으로 깎기만 하고 fold 는 하지 않는다. 그래서 손 층은 손이 멀 때 고른 마지막 채택 영역 (memory) 을 그대로 쓴다.

결과 (자세한 것은 아래 절):
- **꺼짐 = 지금과 bit 동일:** T97 함수를 부르면 터지게 만든 test 로 보였다. 기록 키도 같다.
- **합성 장면:** 원기둥 몸통 + 위 꼭지 + 옆에 2 mm 눌려 맞닿은 같은 높이 원기둥에서 꼭지는 붙고 옆 원기둥은 붙지 않는다.
- **CPU · GPU 동등성 · GPU 시간:** 487 요청에서 쟀다 (아래 표).

## 규칙의 정확한 뜻

### 1.1 돌출 보존 (`attention_surface_crease.protrude`, 한 번, 성분 통째)

| 양 | 정의 (ROI sub-graph, 2.5 mm node) |
|---|---|
| 후보 C | 끊기지 않은 ROI edge 로 만든 비지지면 연결 성분 중, 선택 node 가 없고 선택 영역 R 과 **끊긴 edge** 로 닿는 것. `reattach` 와 같은 후보다 (`_cut_candidates`, test 로 같음을 확인) |
| 받침면 | ROI 의 지지면 node 에 서빙 RANSAC `stages.support_surface.fit_plane_ransac` 을 돌린다. 같은 seed · 가설 · 8 mm inlier 문턱 · +z 방향 · SVD refit 을 쓰고, 크기 문턱만 30 node 다. 평면이 없으면 아무것도 붙이지 않는다 (`why = no_support_plane`) |
| 높이 h | `n · p − d` (normal 방향 거리) |
| `h_R` | R node 높이의 0.9 분위 (상위 10 % 경계) |
| `h_C` | C node 높이 중앙 |
| 투영 면적 a | 받침면에 투영한 node 가 차지하는 2.5 mm 칸 수 × (2.5 mm)² (`a_C` · `a_R`) |
| 겹침 | C node 투영 중 R 투영 convex hull (2-D) 안에 든 비율. R 의 hull 이 퇴화하면 0 이다 (`hull_why`) |
| **붙임** | `h_C ≥ h_R` ∧ `a_C ≤ ρ · a_R` ∧ 겹침 > 0 |

- `--surface-crease-reattach-ratio` 와 같이 주면 거절한다 (config · CLI · `CreaseParams` 모두).
- 투영 면적을 convex hull 넓이가 아니라 칸 수로 잰 이유: 1–2 node 조각의 hull 넓이는 0 이 된다.
- 겹침을 "> 0" 으로 둔 것은 task 문구 ("겹침") 를 그대로 따른 것이다. 기록에는 비율을 남긴다.

### 1.2 손 가까울 때 영역 유지 (`pipeline._t97_freeze_check`)

| 조건 | 값 |
|---|---|
| latch 창 | 붙은 물체 없음 ∧ PLACED 안 봄 ∧ HELD 아님. HELD = `grasp_active` ∧ ¬`grasp_latched`. 그래서 searching · latched · closing 이다. closing 은 `--surface-grasp-hold` 가 켜져 있으면 A4 가 먼저 잡는다 |
| 기준 영역 | 이 episode 의 마지막 채택 요청 (A2 통과, codes 있음) 의 영역 중심. A1 이 켜져 있으면 A1 뒤 영역, 아니면 A2 가 본 영역 (`post.region`), 둘 다 없으면 `selected_centroid` |
| 손바닥 점 | T78b `_grasp_palm_points(robot_state, contact_context)`. 이 요청의 값을 `process` 가 넘긴다 |
| 적용 | 손바닥 중 하나라도 기준 중심에서 D mm 안. 적용된 요청은 기준 영역을 바꾸지 않는다 (손이 멀 때 고른 영역이 계속 기준이다) |

- **추가 전제 (task 와 다른 점):** `--surface-keep-last` 를 필요로 하고, 없으면 거절한다.
  - 영역을 고르지 않은 요청에서 손 층이 마지막 채택 영역을 쓰는 길은 keep_last memory 하나뿐이다. keep_last 가 없으면 그 요청은 IFG-CL1 규칙으로 기권한다 (= 추정 범위). P0m 에는 keep_last 가 있다.
- 쥔 뒤 (closing · held · attached) 는 지금 `--surface-grasp-hold` 그대로다.
