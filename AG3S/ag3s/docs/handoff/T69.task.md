## 1. A 단계 — offline 진단 (B, 고칠 값을 정하기 전에)

### A1. 손 자기 잔상의 출처

- 대상: 최종 구성 기록 (FIN_k0 · FIN_k1 · OCC_FIN · hurdle/ag3s) 과 T67 S1 · S2 기록에서, 마지막 60 mm · 쥔 첫 요청 중 초기 위반 ≥ 30 mm 인 요청 전부.
- 각 요청의 손 표면 잔상 voxel (손 실제 표면 6 mm 안, 다른 물체보다 손에 가까움, 서버 규약) 을 셋으로 나눈다.
  1. **자기 필터 누락**: 거리장을 만든 영상 시점 (geometry frame) 의 자세에서도 손 표면 위에 있다 → 그때 손이 그 자리에 있었는데 걸러지지 않았다.
  2. **시점 어긋남**: geometry frame 자세에서는 손 표면에서 멀고, 지금 자세 (pipeline frame) 에서만 손 표면 위다 → 거리장이 한 요청 늦어, 손이 움직여 들어간 자리에 남은 다른 표면 · 이전 손 자리.
  3. **누적 잔상**: 더 이전 frame 의 손 자세 표면 위다 → 지나간 손이 지워지지 않고 쌓였다.
- 보고: 요청별 개수와 비율, 대표 요청의 단면 그림 (손 · 잔상 voxel · 사과).

### A2. 954 손가락–바나나: 구 모델 여유

- 회귀 954 흔들림 없음 t13–15, 허들 954 × 2 의 같은 구간. VLA 계획 행마다 손가락 충돌 구 (서버 구 모델) 와 손가락 실제 mesh 의 바나나까지 거리 차 (구 덧댐) 를 잰다.
- 보고: 구 덧댐 중앙 · 90 %, VLA 계획이 실제로 지나가는 최소 거리 (mesh 기준).

## 2. 고치는 방법과 값을 정하는 규칙 (지금 고정 — A 단계 숫자로 값만 채운다)

| 항목 | 규칙 | flag (기본 꺼짐) |
|---|---|---|
| **D1 손 부피 비우기 (LTE)** | TrajOpt 가 읽는 손 쪽 거리장 (target-free 계층) 과 본 계층에서, **지금 자세 로봇 손 (손바닥 · 두 손가락) 의 충돌 부피 + d 안의 점유 voxel 을 지운다.** 근거: 지금 로봇이 차지한 공간은 정의상 장애물일 수 없다 (닿아 있는 물체 표면은 손 부피 밖에 있다). d = A1 에서 잰 잔상 voxel 의 손 표면 거리 90 % 값 (mm, 올림), 상한 1 voxel (5 mm) | `--carve-hand-volume-mm d` |
| A1 의 주원인이 "시점 어긋남" 이면 | D1 대신 / 함께, 거리장 시점의 손 자세 (geometry frame) 로 자기 필터를 다시 거는 방식을 A 단계 결과와 함께 사용자에게 묻는다 (지금 고정하지 않는다) | — |
| **D2 손가락–이웃 정밀 여유 (CCR)** | 쥐는 순간 창 (HSR ④ 창과 같음: latch ∈ {LATCHED, CLOSING}, 손바닥 ≤ 60 mm) 안에서 **손가락 구 ↔ 이웃 과일 행의 요구 여유 = −(구 덧댐 90 % 값)**. 즉 구 모델이 mesh 보다 뚱뚱한 만큼만 겹침을 허용하고, 실제 mesh 끼리는 겹치지 않게 한다. 여유 10 mm 는 이 행에서만 뺀다. 기둥 · 허들 · 탁자 · 바구니는 그대로 | `--finger-neighbour-exact` (값은 A2 숫자) |

## 3. B 단계 — closed-loop (A)

- **기준 구성** = T68 구성 (최종 구성에서 A4 · G1 인자를 뺀 것. T67 2 단계에서 C2 는 채택되지 않았다). T68 V1 이 통과하면 기준 구성의 성능 = 최종 구성 기록 (32 run: 성공 20 · 금지 접촉 3 · 탁자 · 바구니 0) 으로 본다.
- 구성: **D1** = 기준 + 손 부피 비우기 · **D12** = D1 + 손가락–이웃 정밀 여유.
- **1 단계**: 최종 구성이 쥐지 못한 8 run (T67 1 단계와 같은 집합: 회귀 211 k0 · 211 k1 · 954 k0, 가림 122 k0, 허들 954 k0 · 954 k1 · 1345 k0 · 211 k0) × D1 · D12, 같은 장면 · seed. 기준 금지 접촉 run = 1.
  - 통과: 금지 접촉 없는 성공 ≥ 그 run 수의 절반 (올림) 이고 금지 접촉 run ≤ 기준 구성의 그 run 들 값.
  - 둘 다 통과하면 성공이 많은 쪽, 차이 ≤ 1 이면 D1 (바꾼 것이 적음).
- **2 단계**: 고른 구성 × 전체 32 run (9 장면 × 2 + 허들 7 × 2).
  - 채택 (모두 충족): 금지 접촉 없는 성공 ≥ **23 / 32** (기준 20 + 3) · 금지 접촉 run **≤ 3** · 탁자 · 바구니 접촉 run **0** · 9 장면 ≥ 14 · 허들 ≥ 6.
- 주 지표 · 접촉 정의는 T67 §4 와 같다.
- 기전 지표 (보고만): 마지막 60 mm 손바닥 밀림 · 닫기 시작 거리 (`t67_mech.py`), 초기 위반 ≥ 30 mm 요청 수, 손 표면 잔상 voxel 수, 쥔 첫 요청의 관절 변화.
