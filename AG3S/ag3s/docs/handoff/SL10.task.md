## 0. 지금까지 확인한 것 (기존 기록)

- VLA 자체 action은 포화 성분이 0이다.
- 실행 action의 포화 성분은 쥐기 전 0.05–0.08이다. 쥐는 중과 쥔 뒤에는 0.12–0.52로 는다.
- TrajOpt 계획 − 변환 C 포화 뒤 실현 가능 경로의 차이(p90)는 쥐기 전 약 10 mm이고, 쥔 뒤 42–156 mm다.
- **기제:** 변환 C는 TrajOpt 수정을 1/β(위치 14배, 회전 32배)로 키운다. TrajOpt는 그 action 한계를 모른다.
- **계기 후보:**
  - (a) 쥐는 중 target이 거리장에 남는다(표면 추출의 `grasp_hold` 유지, 손가락 예외 0행).
  - (b) 쥔 뒤 연속성 · 꺾임 변화율 항이 켜진다(w 0.5 / 20).
  - (c) 쥔 물체를 부착 구 하나로 근사한다.

### 1.3 계기 판정 규칙 (결과 전 고정)

- 계기 X가 "주 계기"가 되는 조건: 변형 X로 J1 대상 call의 편차 > 0.1 rad 비율이 절반 아래로 준다. 아니면 "부 계기" 또는 "아님"이다.
- 여러 계기가 각각 일부만 설명하면, 그 비율을 그대로 적는다. 하나로 묶지 않는다.
- 원인 층: (a) = LTE, (b) = CCR(비용항), (c) = LTE / CCR(부착 모델), 포화 = CCR + Panda adapter.

- 충실도 검사가 실패하면 결과 JSON에 `"valid": false`를 적고 멈춘다.

### 2.2 action 한계 제약 (worktree `wip/sl10-actionbox`)

- 새 flag `--to-action-box`(기본 꺼짐, Panda만). 거절 목록은 RB-Y1 서버에 둔다.
  - TrajOpt QP에 행마다 선형 부등식을 넣는다. 변환 C가 돌려줄 action이 `[-1, 1]`(여유 `--to-action-box-margin`, 기본 0.05) 안에 들게 하는 것이다.
  - 식: `Dx_k = (Dy_k − α Dy_{k−1}) / β`, `|a_k + Dx_k / scale| ≤ 1 − margin`. 위치 · 회전 성분별이고, `Dy`는 EE Jacobian으로 선형화한다.
  - 상수는 `robots/panda/description/osc_response_fit.json`과 `action.py`의 것을 그대로 쓴다.
- 이 제약 때문에 충돌을 못 피하면, 기존 규칙대로 HOLD / 위반으로 남는다. 안전 쪽 규칙은 바꾸지 않는다.
- 기록: `to.action_box = {on, n_rows, active_rows, max_pred_abs_action}`.
- 테스트:
  - 꺼짐이면 bit 동일.
  - 합성 chunk에서 켬이면 변환 C 뒤 포화 0.
  - RB-Y1 서버는 거절.
- 판: `AG3S-final-panda-v3-e0to-pc-abox`, `-pc-surface-abox`.

## 3. action 한계 제약 closed loop 판정 규칙 (결과 전 고정, J2에서 포화가 사라지는 것을 본 뒤 돈다)

- 장면 · 지표: SL9와 같다(LIBERO 9 · SafeLIBERO 11 · LIBERO-Safety 10, 한계 표시 포함).
- 비교: 기준 판과 짝으로 비교한다(pc판 → `-pc-abox`, pc판 + 표면 → `-pc-surface-abox`).
- **기제 확인 (필수):** 쥐는 중 · 쥔 뒤 실행 action 포화 성분 ≤ 0.08(쥐기 전 수준)이다. 아니면 구현이 의도대로 동작하지 않은 것이므로 보고하고 멈춘다.
- **기준을 대신할 후보:** SL9 §5 규칙 그대로다. 세 벤치마크 모두 주 지표 ≥ 기준, 금지 접촉 ≤ 기준이고, 적어도 하나에서 주 지표 차이 > 2 episode다.
- 2 episode 이하 차이는 "구분 못 함"이다. 실패마다 원인 층을 적는다.
