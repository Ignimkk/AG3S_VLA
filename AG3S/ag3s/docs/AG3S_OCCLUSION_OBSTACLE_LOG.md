## 용어

| 용어 | 뜻 |
|---|---|
| **가림 장애물** (occlusion obstacle) | 카메라와 target(사과) 사이에 두어 target 의 일부를 가리는 물체. 이번 실험은 기둥(cylinder)과 가로 막대 |
| **head camera** · **왼손목 camera** | 로봇 머리 위치의 camera 와 왼손목에 달린 camera. VLA 는 두 영상을 입력으로 받는다 |
| **가림률** | 장애물이 없을 때 보이는 사과 pixel 중 장애물 때문에 가려진 비율 (head 는 640×480 렌더 기준) |
| **VLA 단독** | AG3S 없이 VLA 가 낸 action chunk 를 그대로 실행하는 구성 (기준선) |
| **AG3S** | 이 프로젝트의 전체 시스템. 이 문서에서는 "현재 서빙 구성" (target 분할 · 거리장 · TrajOpt 수정이 모두 켜진 구성) |
| **케이스 1** | head camera 만 가리고, VLA 단독 경로와는 떨어진 배치 (장애물이 손 경로를 막지 않는다) |
| **케이스 3** | head 와 왼손목 camera 를 둘 다 가리고, VLA 단독 경로도 막는 배치 |
| **케이스 2** | head + 손목 가림이면서 경로는 막지 않는 배치. 가능한 배치가 없어 사용자 판정으로 뺐다 (라운드 2–3) |
| **단계** (1 · 2 · 3 단계) | 같은 케이스 안에서 가림 정도를 올린 3 단계. 라운드 4 에서 정의 (아래 표) |
| **seed 3 개** | 장면 1345 에서 seed 13453 · 23453 · 33453 세 번 |
| **ATS** | Attention-based Target Segmentation — VLA attention 으로 target 을 분할 · 추적 |
| **HSR** | Hidden-state Sub-task Recognition — VLA hidden state 로 작업 단계(쥠 판단 등)를 읽는 부분 |
| **LTE** | Link-specific Target Exemption — 링크마다 target 을 충돌 대상에서 제외하는 거리장 |
| **CCR** | Constrained Chunk Refinement — TrajOpt 가 VLA 의 action chunk 를 제약 아래서 수정 (+ HOLD) |
| **성공** | place 에 이르러 접촉 정지 없이 끝난 episode. 실패 양상: 접촉(장애물과 닿아 정지), 못 쥠(no_grasp), 들었다 놓침(slip) |
| **기록 길이** | 최대 600 step = 40 s. place 판정 2.5 s 뒤 종료 규칙. 8 step = 0.53 s |

- **공통 문제.** 장애물이 target 가까이 있을 때, 충돌을 피하려는 TrajOpt 수정이 **쥐는 접근 자체를 바꾼다** (쥐는 위치 밀림, 손목 camera 시점 변화). 관측 (target 구분) 은 문제가 아니었다.

| 안 | 구성 요소 | 내용 |
|---|---|---|
| A. 쥐기 목표 유지 | CCR | 쥐기 직전 구간에서 손가락 중점 · 손 방향을 target 기준 VLA 가 의도한 쥐기 자세에 묶고, 장애물 회피는 그 자세를 바꾸지 않는 관절 방향으로 하거나 target 근처에서만 clearance 를 줄인다 (예: 10 mm → 3–5 mm). 핵심 평가 세션의 TO 실험 (grasp goal 유지 E0–E5) 이 이 장면들을 기준선으로 쓰기로 했다 |
