# agents map — 누가 무엇을 내는가

역할 **정의**는 `.claude/agents/*.md`, 소유권 **차단**은 `.claude/roles/*.settings.json`,
띄우기는 `launch.sh`. 이 파일은 **남은 게이트에서 누가 무엇을 산출하는가** 하나만 답한다.

## 산출물 계약

```
A0 lead ──<G>.task.md──► A1 ──<G>.impl.md──► A2 ──<G>.verify.json──► A3 ──► 로그 + PLAN
         무엇을 왜          코드가 뭐가 바뀌었나   수치 · figure          확정된 것만
```

**A3 는 `verify.json` 의 `numbers` 에 없는 숫자를 쓰지 않는다.** A1 이 스크립트를 돌리다
흘린 숫자도 쓰지 않는다 — 그건 측정이 아니라 부수물이다.

| 역할 | 모델 | 산출 | 절대 안 하는 것 |
|---|---|---|---|
| **A0** lead | opus | `<G>.task.md` · PLAN · 판정 진행 · **긴 실행 직접 기동** | 코드·문서·figure 를 직접 고치기 |
| **A1** 구현 | opus | `benchmark/**/*.py` · `tests/**` · `<G>.impl.md` | 측정, 로그 쓰기 |
| **A2** 검증 | sonnet | `docs/figures/**` · `<G>.verify.json` · `outputs/verify/**` | 코드 수정, 해석·판정 쓰기 |
| **A3** 기록 | haiku | `docs/*.md` · `papers/**` | 코드, 실험, figure |

## 남은 게이트 — 누가 붙나

| 게이트 | 무엇을 묻나 | 주 담당 | 앞서 필요한 것 |
|---|---|---|---|
| **T1** 연속 프레임 AG3S | 지각이 쓸 만한가 (target 중심·지지면·카메라 정렬 오차, 로봇 마스크, completeness, frame card) | **A2** | 없음 — 기록·attention 준비됨 |
| **T2** pick-place 상태 전이 | 9 개 사건이 어느 프레임인가 | **A2** | 파지 포함 긴 기록 |
| **T3** 전 프레임 TSDF/ESDF | 모든 프레임에서 필드가 서나. `max_field_age_sec` 를 정한다 | **A2** | T1 |
| **T4** fail-closed 주입 | 고장을 넣으면 정말 닫히나 | **A1** → A2 | 주입 지점을 코드로 열어야 한다 |
| **T5** shadow 루프 | 판정만 하고 실행은 안 하는 루프가 서나 | **A1** → A2 | AG3S 를 클라이언트 in-process 로 |
| **T6** 실기 닫힌 루프 | 예산 안에서 도나 | **A1** → A2 | T5 · 실시간성 |
| **R** 재측정 | 16D 에서 이 수치들은 얼마인가 | **A2** | T1 (미세 계층이 붙어야 R4·R5 가 잰다) |
| — 실시간성 | 청크 예산 533 ms 안에 드나 | **A1** → A2 | T6 전에 닫아야 한다 |

**T1~T3 은 측정이 본체라 A2 가 끌고 간다.** T4~T6 은 코드를 먼저 열어야 해서 A1 이 앞선다.

## 규칙 — 오늘까지 값을 치르고 배운 것

- **긴 실행은 agent 안에 넣지 않는다.** A0 가 `python -u` + `nohup` 으로 띄우고, agent 는
  떨어진 파일만 소비한다. agent 는 세션과 함께 죽지만 프로세스는 산다.
- **한 agent = 한 산출 파일.** 호출당 100k 토큰을 넘으면 일이 너무 큰 것이다 — 쪼갠다.
- **브리핑에 숫자를 박고 "이 밖은 쓰지 마라"를 명시한다.** 그래야 haiku 로도 오염이 0 이다.
- **A1 과 A2 를 한 사람에게 몰지 않는다.** 고친 사람이 스스로 재면 기대한 것이 보인다.
- **세션 후반에 새 agent 를 띄우지 않는다.** 중단되면 그 조각을 통째로 잃는다.
