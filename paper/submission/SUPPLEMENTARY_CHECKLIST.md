## 현재 scaffold

- [x] Main과 분리된 anonymous supplementary entry와 1페이지 PDF를 구성했다.
- [x] 같은 official working style bytes를 사용하고 source/protocol pending 상태를 명시했다.
- [x] 새 개선 method 결과·수정 main PDF·외부 demo/code 링크를 추가하지 않았다.

## 최종 supplementary

- [ ] 핵심 contribution·main result·필수 ablation이 main에서 이해되는지 확인한다.
- [ ] Supplementary의 각 analysis·figure/table·video를 registered result와 source key로 연결한다.
- [ ] 추가 tuning/training으로 개선한 method 결과나 corrected main PDF를 포함하지 않는다.
- [ ] Optional이며 reviewer가 읽을 의무가 없다는 점을 고려해 주장을 구성한다.
- [ ] 모든 file·video·code·metadata·archive entry에 [anonymity 검사](ANONYMITY_CHECKLIST.md)를 적용한다.
- [ ] Content-expansion/review 우회·tracking 링크를 확인하되 정상 citation/third-party 자료 예외를 구분한다.
- [ ] 공개 package에서 내부 경로·source sidecar·불필요한 대용량/개인 자료를 제외한다.
- [ ] 최신 2027 upload type·size·video 제한과 actual deadline timestamp를 확인한다.
- [ ] 실제 uploaded/downloaded package hash와 completeness를 확인한다.

현재 추가 실험·영상·code package는 없다. 해당 검사를 완료로 표시하지 않는다.
