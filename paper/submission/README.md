# Submission preparation

Updated: 2026-10-05 23:52 KST

현재 원고 상태: `DRAFT_SCAFFOLD`; 제출 준비 상태: `NOT_READY`.
Workspace 구성이 끝나도 아래 제출 항목은 별도의 근거가 있어야 완료할 수 있다.

| 문서 | 역할 |
|---|---|
| [SUBMISSION_CHECKLIST](SUBMISSION_CHECKLIST.md) | Conference·OpenReview·과학적 근거·최종 package |
| [ANONYMITY_CHECKLIST](ANONYMITY_CHECKLIST.md) | 본문·metadata·link·supplementary·영상·code |
| [PAGE_LIMIT_CHECKLIST](PAGE_LIMIT_CHECKLIST.md) | Main/references 경계·style·rebuttal·page count |
| [REFERENCES_CHECKLIST](REFERENCES_CHECKLIST.md) | Primary-source bibliography·citation·prior art |
| [SUPPLEMENTARY_CHECKLIST](SUPPLEMENTARY_CHECKLIST.md) | 별도 PDF·내용·파일 제한·익명성 |
| [FINAL_AUDIT](FINAL_AUDIT.md) | 실제 검사 결과·제출 blocker·미확인 범위 |
| [WORKSPACE_VALIDATION](WORKSPACE_VALIDATION.json) | Step 6 구성 검증의 재현 가능한 machine-readable 결과 |

Checkbox는 해당 파일·시각·검사 범위가 확인됐을 때만 체크한다. `[x]`가 붙은 scaffold 검사는
최종 제출물 검사로 이전하지 않는다. `NOT_CHECKED`는 검사하지 않은 상태이고 `UNKNOWN`은
정책/사실을 확인하지 못한 상태다. `BLOCKING`은 현재 제출 준비를 막는 항목이며 학회 위반 판정과 구분한다.

규정은 [STATUS](../guidelines/CVPR_2027_STATUS.md)와 [SOURCES](../guidelines/SOURCES.md)를 따른다.
`CONFIRMED_2027`, `PROVISIONAL_2026`, `UNKNOWN` 및 `PROJECT_POLICY`를 구분한다.
[최종 audit](FINAL_AUDIT.md)의 보고서와 실제 uploaded package identity를 확인한 뒤 제출 준비를 판단한다.
OpenReview 등록·업로드·제출은 이 Step에서 수행하지 않았다.
