\caption{Link-specific allowed collision (schematic). Dashed rings mark the clearance a link must keep.
(a) In the shared field the target (T) and a distractor (O) both repel the finger, so the grasp
is forbidden. (b) The field is unchanged for every query except those of the palm and
fingers of the grasping hand, which read the target-free ESDF: the target no longer repels them, but it still repels
any other link (faint ring), and the distractor still repels everyone.}
