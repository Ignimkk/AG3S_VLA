## 4. How the label is used downstream
- Probe fed once per REQUEST (= one policy chunk request), not per control step: SafePolicy calls ag3s.set_subtask(...) + set_placed(...) each request (LOG:4728). SubtaskDebounce (subtask_probe.py:153-200): confirmed label changes only after N consecutive identical argmaxes; N = clustering.subtask_confirm_frames, default None -> target_confirm_frames = 3 (config.py:173,320). So "3 consecutive chunk requests". Missing label (None) x3 resets label to None (ungated behaviour).
- Gate (target_grounding.py:1124 `subtask_gated = self.subtask.gated and not self.frozen`; GATED_LABELS={place,home}, subtask_probe.py:50): if gate on and confirmed label in {place,home} and not frozen (no grasp in progress): (a) when nothing manipulated yet -> first adoption blocked, grounding status `subtask_gated`, no target (:1130-1135); (b) challenger frames for `switch` are treated as gaps, not counted (:1204-1209). Label pick or None = unchanged behaviour. Label can only BLOCK a new carve, never add. Does not touch the currently manipulated object, admissibility, destination registry, latch, attach/detach. While frozen (grasp in progress) the latch decides, whatever the label (:1122-1123 comment).
- B3 release (target_grounding.py:959-968): gate on AND latch reached PLACED this episode (`_placed_seen`, sticky until reset) AND confirmed label home AND not frozen AND something manipulated -> manipulated object forgotten (no carve from it). Carve->attach transition for the held object is by latch HELD (physical evidence), not label (LOG:4715).

## 5. Limitations stated in files
- Only 3 coarse classes; mapping from 14 scripted dataset phases; phase 9 never sampled; class counts train pick 4000/place 3200/home 3201 (roughly balanced by construction: pick has 4 phases) -- no class-imbalance caveat stated for training; closed-loop is imbalanced (pick 85/place 57/home 272 of 414) and place recall is the weakest (0.86 closed246/0.8596 closed414) (SUBTASK-b.verify).
- Val is "easy": dataset phase_index is scripted, frame_index alone gives 1.000 on val; closed-loop 0.93-0.97 is "more honest" (LOG:4700).
- Closed-loop GT is gripper-defined => rule = 1.000 by definition; probe not shown to beat rule; slip case unmeasured (LOG:4701, 5004ish).
- Held-out closed-loop = ep1807 only (3 other recorded episodes are in the VLA's training range; ep0, ep1200 also in probe train) (LOG:4702).
- Single checkpoint (16D LoRA 29999), single scene family (apple/left arm/crate pick-place; 4 fruits in recordings), sim only (headless MuJoCo on GPU server; local-PC/real not measured: LOG:5000 "로컬 PC 실행"). Obstacle scenes not used for probe training/eval.
- Gate usefulness: "gate did not raise success rate (28/48 vs 29/48, p=1.0); its use on this task is carving consistency (lead's judgement, not measured)" (LOG:4990). Destinations not size-separable (bowl, plate, stacking) -- unmeasured; the whole motivation (crate excluded by size rule today) is a code reading (LOG:4595).
- Label is a CLASSIFIER OUTPUT, no causal link to attention: "text subtask would be only the VLM's scene reading with no causal guarantee about what the AG3S attention (layer 8 head 2) is for" (LOG:4653); probe route also "text 아님, 인과 보장 없음" (audit §5 table C). Option B (subtask co-training -> same causal guarantee as pi0.5) NOT done.
- Probe-label hidden: "home" means "after-release / retreat / return-to-ready / terminal hold" (dataset phases 9-13: RELEASE_VERIFY, RETREAT, TARGET_SETTLE, RETURN_TO_READY, TERMINAL_HOLD), not a place to go; "place" = from GRASP_VERIFY (phase 4) through RELEASE (8) i.e. includes lifting & transport & lowering (and grasp-verify); "pick" = INITIAL_HOLD..GRIPPER_CLOSE.
- Robustness to prompt paraphrase / unseen task text / obstacles / other objects: NOT measured (probe trained only on the 12 training instructions' prompts; features include text-token mean). Layer choice by val max with tie (kv_L4 vs kv_L17); all layers L0..L17 ~0.98 => not a specific "subtask neuron/layer".

## 6. Overstatement risks for 'the VLA outputs a sub-task'
1. The VLA does not output a subtask: 16D checkpoint was fine-tuned with action flow-matching loss only; zero-shot text decode fails (30/36 held frames emit FAST action tokens, object name 0/71, AUROC 0.50-0.85, 3-way argmax = home 246/246). The label is produced by an EXTERNAL logistic-regression probe (512-D -> 3) trained on frozen kv_L4 features with scripted dataset phase labels. Honest wording: "a linear probe on frozen VLA prefix KV-cache features recovers the manipulation phase (3 classes)".
2. Closed label set of 3 (pick/place/home), no object, no free text, no "pick up the pear". Target identity comes from attention clustering, not from the label.
3. Supervised on a scripted dataset's phase_index from the same 1600 training episodes the VLA was fine-tuned on (same distribution/scene); a frame-index-only baseline scores 1.000 on val; closed-loop 0.959 (397/414) with 1 held-out episode. Probe accuracy on genuinely out-of-distribution scenes is unknown.
4. Information is linearly readable at every layer including layer 0 (val 0.980) -> shows prefix contains phase cues (image + state text), not that the VLA internally "plans" a subtask; masking gripper (state[7],[15]) leaves 0.98, arm joints alone only 0.70 -> from images (but other state digits remain in prompt text).
5. No causal claim: unlike pi0.5 (action expert conditioned on generated subtask text), here the action expert does not consume the label; the label only gates AG3S target adoption; the label is not fed back to the VLA.
6. Closed-loop effect is neutral on task success (28/48 vs 29/48, p=1.0); benefits shown only as carving consistency (switch after PLACED 21 runs->0), not safety/success gains; all gate-on numbers are UNREGISTERED; T39 registered evidence (EXP001) is gate-OFF; later obstacle experiments (T40, T43) ran gate OFF.
7. Label timing: confirmed-label lags 0-6 chunks (pick->place) and 2-3 chunks (place->home); `place` is often confirmed during CLOSING/LATCHED (before physical grasp confirmation) and `home` sometimes appears when latch not PLACED (245 chunks) -> label follows scripted-phase appearance, so under failures/re-grasp it can be wrong relative to the real task state; the system therefore keeps latch (physical evidence) as the authority for attach/detach and requires PLACED for the B3 release.
8. Doc inconsistency to avoid copying: LOG:300/4661 and audit §117 give phase->class mapping 0-5/6-9/10-13; code/asset use 0-3/4-8/9-13.
