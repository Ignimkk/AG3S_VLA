# Supplementary scaffold

[supplementary.tex](supplementary.tex)는 main과 별도의 PDF를 생성한다.
Official working style을 이 폴더에도 byte-for-byte 보존해 compiler가 동일한 `cvpr.sty`를 읽게 한다.
내용·file size·format의 2027 세부 요구는 아직 UNKNOWN이며
[SUPPLEMENTARY_POLICY](../guidelines/CVPR_SUPPLEMENTARY_POLICY.md)를 따른다.
Main의 필수 결과를 이곳으로 밀어내지 않는다. 개선 method 결과와 수정 main PDF도 추가하지 않는다.
빌드 방법은 [LaTeX README](../latex/README.md)에 있다.
