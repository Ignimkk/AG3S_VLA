# CVPR Submission Policy

Target venue: CVPR 2027

Last verified: 2026-10-05 19:21 KST

## 확인된 2027 규정 — `CONFIRMED_2027`

| 항목 | 적용 사항 |
|---|---|
| Platform | OpenReview; [일정](CVPR_2027_DEADLINES.md) 참고 |
| Reviewer service | 초청받으면 reviewer/AC/SAC로 참여; 예외는 사전 disclosure와 PC 승인 필요 |
| Dual submission | 2026-11-16–2027-02-22에 substantially similar paper를 다른 conference/workshop에 제출하지 않음 |
| Contemporaneous work | 2026-09-15 이후 온라인 공개 work에 일반적으로 적용 |
| 인용·비교 | contemporaneous work도 cite/discuss하고 가능한 범위에서 비교; 영향을 준 work는 날짜와 무관하게 prior work |

Dual-submission review period 종료일과 final-decision 날짜(2027-02-25)는 서로 다르다.
Contemporaneous-work 판단은 arXiv와 conference/journal paper를 구별하지 않는다.

[2027 CFP: Submission Requirements / Contemporaneous Work](https://cvpr.thecvf.com/Conferences/2027/CallForPapers).

## OpenReview 준비 — `CONFIRMED_2027`

- 모든 co-author는 완전하고 최신이며 organizer가 볼 수 있는 profile을 갖춘다.
- Abstract registration 마감 후 저자 추가·삭제는 허용되지 않는다.
- 불완전한 author registration은 desk rejection 대상이다.
- 공식 profile 안내의 email, career history, relations/conflicts, expertise, publications,
  개인정보 등 해당 항목을 완료한다. 개인별 완료 상태를 이 workspace에서 확인한 것은 아니다.

[2027 OpenReview profile 안내](https://cvpr.thecvf.com/Conferences/2027/CompleteYourORProfile).

## 2026에서 임시 참고 — `PROVISIONAL_2026`

2026에는 overlap 20% 기준과 journal 등을 포함하는 dual-submission 세부 설명이 있다.
이를 2027의 확정 threshold나 허용 범위로 단정하지 않는다. 저자 순서 변경과
OpenReview 등록 세부 절차도 최신 2027 안내를 재확인한다.

[2026 Author Guidelines: Dual submissions / Author FAQs](https://cvpr.thecvf.com/Conferences/2026/AuthorGuidelines).

## 아직 확인하지 못한 2027 항목 — `UNKNOWN`

Overlap 정의, journal 관련 상세 적용 범위, author-order 변경 시점, 별도 profile deadline,
submission 파일 제한 등은 2027 Author Guidelines/OpenReview 안내가 필요하다.

## Workspace 운영 — `PROJECT_POLICY`

Submission 전에 evidence·citation·anonymity·compliance를 점검한다.
`/cvpr-compliance` 등 7개 skill 정의는 Step 4에서 생성했다. 호출과 완료 조건은
[CLAUDE_WORKFLOW](../notes/CLAUDE_WORKFLOW.md)를 따른다. 정의 생성과 정적 검증은
실제 원고의 compliance audit나 submission 완료를 뜻하지 않는다.
