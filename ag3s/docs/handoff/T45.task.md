# T45 — 손 (palm · finger) 충돌 구 coverage audit → 필요한 수정만

> writer: lead (A0) · 읽는 쪽: verifier (audit, Opus), 이후 implementer (수정이 필요하면)
> 사용자 판정 (2026-10-11): T44d 의 palm 구 문제는 **별도 STEP** 으로 — audit 후 필요한 수정만.
> 공통 규칙은 `T44.task.md` 와 같다 (env, pod 한도, `.venv-ag3s`/8123 금지, 다른 세션 파일 금지, 커밋 금지).

## 왜
`T44dA.verify.json` Q4: C1a 의 palm–이웃 과일 접촉 3 event 에서 이웃 과일은 field 에 남아 있었고 (표면 91–93 %), TO 예측 clearance 는 −1.1~6.7 mm 였지만
실제 sphere 모델 gap 은 9–16 mm 였다. **palm 구 반지름 6.2 mm 대 URDF capsule 33 mm.** 추적 오차 7–15 mm 도 겹친다.
즉 접촉을 막지 못한 원인 일부가 exclusion 이 아니라 **로봇 손 기하의 과소 근사**일 수 있다.

## Audit (verifier, Opus) — 수정하지 않는다
1. 서버 constraint model (`--links gripper` 와 `--links arms`, `--finger-cover both`, `--capsule-radius-scale 0.05`, `--sphere-spacing 0.4`, `--max-spheres-per-capsule 32`) 의
   손 link 별 구 (이름 · 반지름 · 개수 · 위치) 를 뽑는다. 이 구들이 어디서 만들어지는지 (`capsule-radius-scale` 등의 경로) `파일:줄`.
2. 같은 link 의 **MJCF collision geom** (MuJoCo 가 실제 접촉을 계산하는 기하 — 왼손 finger 이름 MJCF/URDF 뒤바뀜 주의) 과 URDF collision 을 같은 frame 에 둔다.
   지표: geom 표면 점 중 구 합집합 밖에 있는 비율 · 밖 거리 (median / p95 / max), 구가 geom 밖으로 나간 과잉 부피. 손가락 개도 몇 개 (열림 · 반 · 닫힘).
3. T44d 접촉 event (C0 · C1a 의 hand–fruit_other, `outputs/verify/T44/CL/replay/`) 에서 실제 접촉한 MJCF geom 이 어느 것이고, 그 지점이 구 coverage 밖인가.
4. `--capsule-radius-scale 0.05` 가 무엇을 줄였는지 (T27 등 과거 결정의 근거 — 로그에서 찾아 인용) 와, 손 구를 실제 기하로 키우면 영향받을 것 (TO 시간 · grasp 시 target 과의 관계 — 권한 행이라 target 에는 예외).
5. 결론: 수정 필요 여부와 최소 수정안 후보 (예: palm 만 실제 반지름 · finger-cover 처럼 palm-cover) — 구현 안 함.

산출: `T45.verify.json`, `figures/t45/t45-*` (실제 scene: 손 geom + 구 overlay · graph · table + sidecar), raw `outputs/verify/T45/`.

## A10 — palm cover 5 mm (implementer)
- **기존 coverage 생성 코드 재사용:** T43 FC/FR 의 finger cover (`--finger-cover`, 손가락 mesh 를 구로 덮는 경로) 를 palm body (`ee_left` / `ee_right`, MJCF `EE_BODY_collision_*`) 에 적용.
  새 coverage 알고리즘을 만들지 않는다. audit 의 후보 (b) 계산 (`outputs/verify/T45/p/`) 과 같은 결과가 나오는지 대조.
- Flag 기본 off: 예 `--palm-cover {off,on}` + overflow 5 mm (값은 config 로, 기본 5.0 mm). off 에서 bit-identical.
- **구 수 확인:** palm cover 로 추가되는 구가 **전체 466 개** (audit (b)) 인지 — 다르면 이유를 impl.md 에.

- Tests: off bit-identical · 구 수 · coverage (audit 의 palm 접촉점 35 개가 구 안) · 권한 행 포함 · config/CLI 왕복. 전체 pytest (GPU 허용, `XLA_PYTHON_CLIENT_PREALLOCATE=false`).
